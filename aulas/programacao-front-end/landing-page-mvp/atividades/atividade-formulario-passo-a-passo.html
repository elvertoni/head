O que você vai fazer. Construir do zero o formulário de lista de espera da figura. Na frente está o HTML; no verso, o CSS.

Como fazer. Digite o código, sem copiar e colar. A cada passo: salve (Ctrl+S), atualize o navegador (F5) e só marque a caixa ☐ quando vir o resultado na tela. Travou? Compare com a folha letra por letra antes de chamar o professor.

Antes de começar. Crie a pasta formulario e, dentro dela, dois arquivos vazios: index.html e estilo.css. Abra o index.html no editor e no navegador.

<!DOCTYPE html>

  <title>Lista de espera</title>
  <link rel="stylesheet" href="estilo.css">
</head>
<body>
  <h1>Entre na lista de espera</h1>
  <form>
    <!-- os campos dos passos 2 a 6 entram aqui -->
  </form>
</body>
</html>

Passo 2. O primeiro campo: nomeindex.html · dentro do <form>

    <label for="nome">Seu nome</label>
    <input type="text" id="nome" name="nome" required>

<label> é o rótulo, <input> é o campo. O for de um tem de ser igual ao id do outro: é o que liga os dois. required = obrigatório.

  • Clico em “Seu nome” e o cursor entra no campo.

Passo 3. O e-maillogo abaixo do passo 2

    <label for="email">Seu e-mail</label>
    <input type="email" id="email" name="email"
           placeholder="voce@exemplo.com" required>

Com type="email" o navegador confere sozinho se o texto tem cara de e-mail. O placeholder é o exemplo em cinza, que some quando a pessoa digita.

  • O exemplo em cinza aparece dentro do campo.

Passo 4. A lista de escolhalogo abaixo do passo 3

    <label for="perfil">Você é</label>
    <select id="perfil" name="perfil" required>
      <option value="">Escolha uma opção</option>
      <option value="estudante">Estudante</option>
      <option value="professor">Professor(a)</option>
      <option value="outro">Outro</option>
    </select>

<select> é a lista e cada <option> é uma linha dela. O texto entre as tags é o que a pessoa lê; o value é o que o sistema recebe. A primeira opção tem value vazio de propósito: quem não escolher nada é barrado pelo required.

  • A lista abre e mostra as três opções.

Passo 5. O campo de texto longologo abaixo do passo 4

    <label for="dor">Sua maior dificuldade hoje</label>
    <textarea id="dor" name="dor" rows="4"></textarea>

<textarea> é para respostas de várias linhas. Tem tag de fechamento e nada entre as duas, nem espaço.

  • Consigo escrever mais de uma linha no campo.

Passo 6. O botão de enviarúltimo item antes do </form>

    <button type="submit">Quero entrar na lista</button>

Dentro do <form>, o botão type="submit" é quem envia.

  • Clico no botão com tudo vazio e o navegador reclama.
Tudo grudado na mesma linha? Está certo. O HTML só diz o que cada coisa é. A aparência é trabalho do CSS, no verso.

Agora o CSS. Tudo desta página vai no estilo.css, um bloco embaixo do outro. Mesmo ritmo: salvar, atualizar, conferir, marcar.

Passo 7. A página e a caixaestilo.css

body {
  max-width: 420px;
  margin: 32px auto;
  padding: 0 16px;
  font-family: "Segoe UI", Arial, sans-serif;
  background-color: #eef1f4;
  color: #1f2933;
}

form {
  padding: 24px;
  background-color: #ffffff;
  border: 1px solid #d9dee3;
  border-radius: 8px;
}

max-width limita a largura e margin: 32px auto centraliza. Com fundo, borda e cantos arredondados, o form vira um cartão.

  • O formulário virou um cartão branco no meio da tela.

Passo 8. Rótulos e camposestilo.css

label {
  display: block;
  margin-top: 16px;
  margin-bottom: 4px;
  font-weight: 600;
}

input, select, textarea {
  width: 100%;
  padding: 10px;
  border: 1px solid #7b8794;
  border-radius: 6px;
  font: inherit;
  box-sizing: border-box;
}

display: block põe cada rótulo na própria linha. font: inherit manda o campo usar a fonte da página, o que ele não faz sozinho. Com box-sizing: border-box, os 100% já incluem padding e borda.

  • Cada campo ocupa a largura toda, um embaixo do outro.

Passo 9. Onde estou digitando?estilo.css

input:focus, select:focus, textarea:focus {
  outline: 3px solid #2f6f4e;
  outline-offset: 2px;
}

:focus é o estado do campo que está ativo. Quem usa só o teclado depende desse contorno para saber onde está.

  • Aperto Tab e o contorno verde passa de campo em campo.

Passo 10. O botãoestilo.css

button {
  width: 100%;
  margin-top: 20px;
  padding: 12px;
  border: 0;
  border-radius: 6px;
  background-color: #2f6f4e;
  color: #ffffff;
  font: inherit;
  font-weight: 700;
  cursor: pointer;
}

button:hover {
  background-color: #245a3f;
}

:hover é o estado de quando o mouse está em cima. cursor: pointer troca a seta pela mãozinha.

  • O botão ficou verde e escurece quando passo o mouse.
