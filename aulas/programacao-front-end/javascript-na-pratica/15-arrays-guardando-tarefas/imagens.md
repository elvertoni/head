# Brief de imagem — Tarefas em um array

## Capa

- **perfil:** capa
- **objetivo:** distinguir posições, quantidade e acréscimo de dados da apresentação em itens HTML.
- **alt:** Um array reúne os textos das tarefas. O primeiro índice é 0, push acrescenta ao final e length informa a quantidade. Cada envio válido acrescenta um texto ao array e cria um item HTML; atualizar reinicia os dados e a lista desta versão.
- **prompt:**

Índices e quantidades são ensinados por exemplos de código com saídas exatas. Sem infográfico no corpo.
