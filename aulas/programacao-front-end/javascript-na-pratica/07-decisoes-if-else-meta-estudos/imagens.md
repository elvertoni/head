# Brief de imagem — Escolhas com if e else

## Capa

- **perfil:** capa
- **objetivo:** mostrar a escolha exclusiva entre dois blocos e a continuação após a decisão.
- **alt:** A condição pergunta se o tempo estudado é menor que a meta. Se verdadeira, o if mostra Ainda falta estudar; se falsa, o else mostra Meta atingida, incluindo a igualdade e o valor acima. Depois do bloco escolhido, a mensagem Conferência encerrada aparece nos dois caminhos.
- **prompt:**

O fluxo é explicado com programas completos, previsões e saídas em texto. Sem infográfico no corpo.
