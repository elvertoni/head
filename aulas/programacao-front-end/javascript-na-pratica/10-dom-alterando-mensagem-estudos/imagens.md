# Brief de imagem — Alterando uma mensagem

## Capa

- **perfil:** capa
- **objetivo:** relacionar o id do HTML, a localização do elemento e a mudança de texto no documento carregado.
- **alt:** O parágrafo tem id mensagem; document.getElementById localiza esse elemento; textContent permite ler e trocar o texto. Uma função reúne a ação e sua chamada altera o parágrafo na página carregada, preservando o texto inicial no arquivo HTML salvo.
- **prompt:**

O HTML, o JavaScript e os resultados visíveis estão descritos integralmente na canônica. Sem infográfico no corpo.
