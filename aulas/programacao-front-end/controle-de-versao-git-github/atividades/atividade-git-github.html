Exercício 3. Questões objetivas2,0

Marque com X a única alternativa correta.

3.1 Qual é a diferença principal entre guardar projeto-v1.html, projeto-v2.html, projeto-final.html e usar Git?

  1. a) Não há diferença: os dois guardam histórico do mesmo jeito.
  2. b) Git guarda o histórico dentro do próprio projeto, com data, autor e mensagem, sem multiplicar arquivos.
  3. c) Git só funciona se o projeto estiver publicado no GitHub.
  4. d) Arquivos com nome de versão abrem mais rápido no navegador.

3.2 Por que existe o comando git add antes do git commit?

  1. a) Porque o Git exige dois comandos para tudo, sem motivo real.
  2. b) Porque git add é quem realmente grava o histórico.
  3. c) Para permitir escolher exatamente quais mudanças entram na próxima fotografia.
  4. d) Para liberar memória do computador antes de salvar.

3.3 O que uma branch é, por dentro do Git?

  1. a) Uma cópia completa de todos os arquivos do projeto.
  2. b) Um rótulo móvel apontando para um commit, que anda independente das outras branches.
  3. c) Um backup automático feito na nuvem.
  4. d) Uma pasta separada criada dentro do repositório.

3.4 Você quer trazer para o seu computador um projeto que já existe no GitHub e do qual você ainda não tem nenhum arquivo local. Qual comando usar?

  1. a) git init
  2. b) git push
  3. c) git switch
  4. d) git clone

3.5 Qual é a principal diferença entre um merge direto e um Pull Request?

  1. a) Não existe diferença técnica nenhuma.
  2. b) O Pull Request cria um espaço de revisão e conversa antes de o merge acontecer.
  3. c) Pull Request só existe em repositórios privados.
  4. d) Merge direto é mais rápido porque não usa Git.

3.6 Uma imagem aparece certinho no seu computador, mas fica quebrada depois de publicada no GitHub Pages. Qual é a causa mais provável?

  1. a) O GitHub Pages não suporta imagens .jpg.
  2. b) A imagem é pesada demais para a internet do celular.
  3. c) Diferença entre maiúscula e minúscula no nome do arquivo — o servidor Linux diferencia, o Windows não.
  4. d) O GitHub Pages só publica arquivos que estejam numa branch chamada gh-pages.
