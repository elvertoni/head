Os três pilares do [[scrum]] explicam por que o framework funciona: **transparência** (todos enxergam o mesmo — os backlogs são abertos), **inspeção** (o time examina com frequência o produto e o processo) e **adaptação** (com base no que inspecionou, ajusta o rumo).

## Em uma frase

Transparência para enxergar, inspeção para olhar com frequência, adaptação para ajustar o rumo.

## O que precisa saber

É o mesmo ciclo — mostrar, olhar, corrigir — que sustenta as [[cerimonias-do-scrum|cerimônias]] e os artefatos: eles são o corpo, os pilares são a alma. Uma [[sprint-retrospectiva]] que aponta problemas mas nunca gera mudança quebra especificamente o pilar da adaptação.

## Erros comuns

- Inspecionar sem adaptar: ver o problema na Retrospectiva e não mudar nada na sprint seguinte anula o ciclo.
- Achar que adotar o Scrum resolve tudo sozinho. O framework só funciona se o time abraçar os pilares de verdade.
