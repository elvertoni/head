Release é uma entrega de uma versão do produto com um conjunto de funcionalidades prontas e funcionando, disponibilizada ao usuário. Em vez de uma entrega única no fim, o [[scrum]] faz entregas incrementais: várias releases ao longo do projeto, cada uma somando valor à anterior.

## Em uma frase

Uma fatia do produto entregue ao usuário — reduz o risco de descobrir um erro só no final.

## O que precisa saber

Cada release é construída em uma ou mais [[sprint|sprints]]. Planejar releases envolve definir o objetivo de cada uma, dividir em sprints, [[estimativa-de-esforco|estimar]] esforço e capacidade, e ajustar o cronograma conforme o projeto avança — que é sempre uma estimativa viva, nunca uma promessa fixa.

## Erros comuns

- Tratar o cronograma de releases como uma promessa de pedra. No ágil, mudar o plano com base em novas informações é maturidade, não fracasso.
