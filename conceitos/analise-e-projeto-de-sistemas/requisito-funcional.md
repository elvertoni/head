Requisito funcional é o que o sistema faz: "o cliente pode acompanhar o pedido em tempo real", "o cliente paga com Pix". Regra prática: se dá para desenhar uma tela para ele, é funcional.

## Em uma frase

Se dá para desenhar uma tela, é funcional.

## O que precisa saber

Requisito funcional é o par do [[requisito-nao-funcional|requisito não-funcional]]: um descreve a ação, o outro descreve a qualidade com que essa ação acontece. Levantar os dois tipos a partir de um produto pronto é parte central da [[engenharia-reversa-de-requisitos|engenharia reversa de requisitos]].

## Erros comuns

- Confundir requisito funcional com requisito não-funcional só porque os dois descrevem o sistema — o teste é simples: dá para desenhar a tela, ou é um advérbio sobre como o sistema se comporta?
