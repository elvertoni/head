É a categoria de [[software]] cuja função é controlar o [[hardware]] e dar suporte aos demais programas. O [[sistema-operacional]] é o principal software de base: todo software de aplicação — navegador, jogos, editores — roda em cima dele. Sem o software de base, os softwares de aplicação não têm onde funcionar.

## Em uma frase

A categoria de software que controla o hardware e sustenta todos os demais programas.

## O que precisa saber

A distinção madura entre hardware e software ganha aqui uma terceira peça: hardware é a parte física que processa e armazena dados; software é o conjunto de instruções que forma as aplicações; software de base é o software especial que fica entre os dois, controlando o hardware e sustentando o que roda por cima. O [[sistema-operacional]] é o exemplo canônico de software de base — mas o rótulo é sobre a função na pilha (controlar hardware, dar suporte), não sobre um produto específico. Reconhecer essa camada evita o erro comum de tratar qualquer programa pré-instalado como parte do sistema operacional.

## Erros comuns

- Classificar qualquer programa que "já vem instalado" na máquina (navegador, editor de fotos) como software de base: só o software que controla o hardware e sustenta as aplicações — o SO — ocupa essa camada; os demais são software de aplicação, mesmo vindo pré-instalados.
- Achar que "software de base" é sinônimo de "software simples" ou "básico" no sentido de pouco sofisticado: o termo descreve a posição na pilha (perto do hardware), não a complexidade do software.
