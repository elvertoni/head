É a forma de comandar o [[sistema-operacional]] por meio de janelas, ícones e toques ou cliques — a interface visual e amigável que a maioria dos usuários emprega no dia a dia, em contraste com a [[interface-de-linha-de-comando]], que recebe comandos digitados em texto.

## Em uma frase

O jeito de dar ordens ao sistema operacional por janelas, ícones e cliques, em vez de digitar comandos.

## O que precisa saber

É uma das duas formas principais de interação com o [[sistema-operacional]], ao lado da [[interface-de-linha-de-comando]] — a última das funções que, junto com escalonamento de [[processo|processos]], [[gerencia-de-memoria]], [[sistema-de-arquivos]] e [[driver|drivers]], completa o que o SO oferece ao usuário. A interface gráfica é mais fácil para o uso comum: é o que a maioria das pessoas associa a "usar um computador" (arrastar arquivos, abrir janelas, tocar ícones). O ponto pedagógico é que ela não é a única via nem a mais poderosa para tudo — para tarefas técnicas, a linha de comando costuma ser mais direta.

## Erros comuns

- Achar que a interface gráfica é sempre superior à linha de comando: ela é mais amigável para o uso comum, mas menos direta para tarefas técnicas — são ferramentas diferentes para contextos diferentes, não uma hierarquia de qualidade.
- Confundir a interface gráfica com o próprio sistema operacional: ela é apenas a camada de interação visual; o SO continua gerenciando processos, memória, arquivos e dispositivos por baixo, gráfica ou não.
