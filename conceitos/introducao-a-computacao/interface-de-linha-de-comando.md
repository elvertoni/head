É a forma de comandar o [[sistema-operacional]] recebendo instruções digitadas em texto, como no terminal ou prompt. É mais direta e poderosa para tarefas técnicas do que a [[interface-grafica]], e por isso é bastante usada por programadores e profissionais de TI.

## Em uma frase

O jeito de dar ordens ao sistema operacional digitando comandos de texto, em vez de clicar em ícones.

## O que precisa saber

É uma das duas formas principais de interação com o [[sistema-operacional]], ao lado da [[interface-grafica]] — juntas, elas são o modo como o usuário efetivamente opera a máquina, a última das grandes funções do SO. Em desenvolvimento de sistemas, boa parte do trabalho passa pela linha de comando: rodar um programa, instalar ferramentas, usar controle de versão. Não é uma interface "ultrapassada" nem exclusiva de especialistas raros — é a forma mais direta de pedir algo ao sistema operacional, sem passar por menus, e costuma ser mais rápida para quem a domina.

## Erros comuns

- Achar que a linha de comando é "coisa de hacker de filme" ou obsoleta: ela continua sendo a via mais direta e poderosa para tarefas técnicas, amplamente usada no desenvolvimento de sistemas.
- Achar que a interface gráfica substitui completamente a linha de comando: são formas complementares de comandar o mesmo sistema operacional, cada uma melhor para um tipo de tarefa.
