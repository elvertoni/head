Carrinho de compras é uma aplicação didática que combina dados de produtos, arrays, funções, eventos, cálculos e atualização de interface para representar uma seleção de itens. Ele funciona como síntese prática dos fundamentos da trilha.

## Em uma frase

Carrinho de compras integra dados, regras e interface em um fluxo web interativo.

## O que precisa saber

O projeto usa [[arrays-em-javascript]], [[funcoes-em-javascript]], [[operadores-javascript]], [[manipulacao-do-dom]] e [[integracao-javascript-html]]. A aplicação precisa definir uma fonte de verdade para itens e total, validar entradas e separar cálculo de apresentação.

## Erros comuns

- Calcular o total a partir de texto exibido sem validar dados.
- Duplicar estado entre array, variáveis e DOM.
- Tratar projeto didático como arquitetura pronta para produção.
