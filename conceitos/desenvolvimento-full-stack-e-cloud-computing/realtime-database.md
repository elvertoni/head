Realtime Database é um banco gerenciado orientado a uma árvore de dados JSON, com sincronização quase em tempo real entre clientes autorizados.

## Em uma frase

Realtime Database sincroniza dados estruturados em JSON com baixa latência.

## O que precisa saber

Modelagem, regras, índices, offline e concorrência afetam a solução. Ele tem modelo diferente do [[cloud-firestore]] e deve ser escolhido pela forma de acesso.

## Erros comuns

- Modelar uma árvore profunda sem considerar consultas.
- Liberar leitura e escrita globalmente.
