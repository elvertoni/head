Metamodelo de dados é uma linguagem ou estrutura formal que define como modelos de dados e seus elementos podem ser especificados, relacionados e interpretados. Enquanto um [[modelo-de-dados]] descreve um domínio, o metamodelo descreve as regras e tipos de construção permitidos para criar esse modelo.

## Em uma frase

Metamodelo define a linguagem com que modelos de dados são construídos.

## O que precisa saber

Entidades, atributos, relacionamentos e restrições podem ser elementos de um modelo cuja forma é delimitada por um metamodelo. MER e UML são notações e linguagens relacionadas, mas o metamodelo trata a estrutura da própria linguagem. Essa distinção ajuda a separar domínio, representação e regras de modelagem.

## Erros comuns

- Confundir metamodelo com o esquema de uma aplicação.
- Tratar uma notação visual como descrição completa do domínio.
- Misturar regras da linguagem de modelagem com dados concretos.
