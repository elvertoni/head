Express.js é um framework minimalista para construir aplicações Web e APIs sobre Node.js. Ele organiza requisições, respostas, rotas e middleware, permitindo compor uma aplicação conforme necessidades.

## Em uma frase

Express.js fornece uma camada composicional para serviços Web em Node.js.

## O que precisa saber

[[nodejs]], [[roteamento]], endpoints e middleware formam a base de uma aplicação Express. O framework não define sozinho autenticação, validação, observabilidade ou arquitetura; essas decisões precisam ser explícitas.

## Erros comuns

- Colocar toda regra de negócio dentro do handler da rota.
- Aceitar entrada sem validação ou tratamento de erros.
- Confundir middleware com autorização completa.
