CSS3 é a linguagem de folhas de estilo usada para definir a apresentação de documentos HTML. Regras CSS associam seletores a declarações que controlam propriedades como cor, tipografia, espaçamento, dimensões e posicionamento.

## Em uma frase

CSS3 define como a estrutura HTML deve ser apresentada em diferentes contextos.

## O que precisa saber

Uma regra começa por um [[seletores-css]] e aplica declarações aos elementos correspondentes. O [[box-model]] explica como conteúdo, padding, borda e margin participam das dimensões. Frameworks como [[bootstrap]] oferecem classes reutilizáveis, enquanto [[media-query]] permite adaptar a apresentação a diferentes larguras.

CSS organiza apresentação, mas não deve carregar o significado estrutural do documento. A combinação com [[html5]] e [[html-semantico]] separa conteúdo, semântica e aparência.

## Erros comuns

- Usar estilos inline em excesso e dificultar manutenção.
- Ajustar dimensões sem considerar o box model.
- Tratar responsividade como uma coleção de tamanhos fixos.
