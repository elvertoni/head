Usabilidade Web é a facilidade com que pessoas aprendem, navegam, operam e recuperam erros em uma interface para alcançar seus objetivos. Ela depende de clareza, feedback, consistência, prevenção e acessibilidade.

## Em uma frase

Usabilidade torna uma interface aprendível, eficiente e tolerante a erros.

## O que precisa saber

Testes com pessoas, observação de tarefas e métricas revelam problemas que a opinião do time não detecta. UX é mais ampla, enquanto usabilidade foca a qualidade de uso.

## Erros comuns

- Confundir interface familiar para a equipe com interface fácil para o público.
- Esconder mensagens de erro ou usar linguagem técnica.
- Testar só o caminho feliz.
