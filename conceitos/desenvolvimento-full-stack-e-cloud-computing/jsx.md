JSX é uma sintaxe que permite descrever elementos de interface com aparência semelhante a HTML dentro de código JavaScript. Um processo de transformação converte JSX em chamadas que o React pode executar; o navegador não interpreta JSX diretamente.

## Em uma frase

JSX aproxima marcação e lógica de renderização em componentes React.

## O que precisa saber

JSX usa expressões JavaScript, exige regras de atributos e retorna uma árvore que pode ser composta por [[componente-react]]. Ele é sintaxe de [[react]], não uma nova linguagem de marcação independente.

## Erros comuns

- Esquecer que expressões JSX precisam ser válidas em JavaScript.
- Inserir dados não confiáveis sem entender escape e contexto.
- Confundir JSX com HTML puro.
