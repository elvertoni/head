Core Web Vitals é um conjunto de métricas para observar carregamento, responsividade e estabilidade visual da experiência Web, como LCP, INP e CLS. Elas aproximam desempenho técnico da percepção do usuário.

## Em uma frase

Core Web Vitals mede dimensões centrais da experiência de carregamento e interação.

## O que precisa saber

As métricas devem ser analisadas com distribuição de usuários, não apenas médias. Melhorar uma métrica sem entender o fluxo pode prejudicar conteúdo, acessibilidade ou funcionalidade.

## Erros comuns

- Tratar limiar como garantia de boa experiência.
- Medir apenas em laboratório e ignorar dados reais.
- Otimizar CLS, LCP ou INP isoladamente do produto.
