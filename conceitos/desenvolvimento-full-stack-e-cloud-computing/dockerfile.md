Dockerfile é um arquivo declarativo com instruções para construir uma imagem Docker reproduzível.

## Em uma frase

Dockerfile transforma código e dependências em uma imagem versionável.

## O que precisa saber

Base, camadas, contexto, comandos e usuário afetam segurança e tamanho. A imagem resultante roda como [[conteinerizacao]] com configuração explícita.

## Erros comuns

- Copiar segredos para a imagem.
- Usar base mutável sem fixar versão ou verificar origem.
