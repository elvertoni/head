API de geolocalização é uma interface que permite solicitar localização aproximada de um dispositivo mediante contexto, permissão e consentimento. A aplicação deve tratar precisão e disponibilidade como variáveis.

## Em uma frase

Geolocation API fornece localização autorizada do dispositivo.

## O que precisa saber

Permissão, HTTPS, privacidade, precisão, fallback e retenção são partes do desenho. A API não garante que o usuário concederá acesso ou que o sinal será exato.

## Erros comuns

- Solicitar localização sem explicar finalidade.
- Armazenar coordenadas além do necessário.
- Tratar localização como verdade precisa e permanente.
