Pages Router é o sistema de rotas do Next.js que deriva caminhos de arquivos no diretório `pages` e oferece convenções de páginas e API routes.

## Em uma frase

Pages Router transforma arquivos de `pages` em rotas navegáveis.

## O que precisa saber

Ele convive com aplicações existentes e tem convenções próprias de dados e renderização. [[app-router]] é a alternativa mais nova, não um sinônimo.

## Erros comuns

- Misturar APIs de roteadores diferentes.
- Migrar sem mapear comportamento de dados e layouts.
