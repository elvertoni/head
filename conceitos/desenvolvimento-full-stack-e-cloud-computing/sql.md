SQL é uma linguagem declarativa usada para definir estruturas, consultar dados e controlar operações em bancos relacionais. Seus comandos expressam o que deve ser obtido ou alterado; o SGBD decide como executar.

## Em uma frase

SQL é a linguagem declarativa para trabalhar com estruturas e dados relacionais.

## O que precisa saber

Categorias frequentes incluem [[ddl]], [[dml]], [[dql]], [[dcl]] e [[dtl]]. SQL opera sobre o [[modelo-relacional]] e é implementado por um [[sgbd]], com diferenças de dialeto entre produtos. A consulta não elimina preocupações de segurança, transação ou custo.

## Erros comuns

- Confundir SQL com um único produto de banco.
- Montar comandos com entrada não confiável e permitir injeção.
- Ignorar transações, planos de execução e permissões.
