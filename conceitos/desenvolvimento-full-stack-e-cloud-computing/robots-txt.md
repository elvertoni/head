robots.txt é um arquivo que comunica a rastreadores quais caminhos eles devem ou não solicitar segundo regras do site. Ele orienta rastreamento, mas não é controle de acesso nem segredo.

## Em uma frase

robots.txt orienta robôs Web sobre caminhos rastreáveis.

## O que precisa saber

O arquivo precisa estar na origem correta e usar sintaxe compatível com os rastreadores. Bloquear um caminho não impede que uma URL seja conhecida ou acessada diretamente.

## Erros comuns

- Usar robots.txt para proteger informação privada.
- Bloquear CSS e JavaScript necessários à renderização.
- Esquecer de revisar regras após mudanças de rotas.
