Koa é um framework Web para Node.js que oferece uma camada minimalista baseada em middleware para construir servidores e APIs. Ele deixa mais decisões de composição para a aplicação.

## Em uma frase

Koa fornece uma base minimalista para APIs em Node.js.

## O que precisa saber

O desenho de rotas, validação, erros, autenticação e observabilidade precisa ser composto pelo projeto. A escolha de Koa deve ser comparada com [[expressjs]] e [[framework]].

## Erros comuns

- Confundir minimalismo com segurança ou arquitetura pronta.
- Esquecer tratamento centralizado de erro.
- Criar middleware com ordem e efeitos implícitos.
