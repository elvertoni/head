CSS Modules escopa classes CSS por módulo de componente, reduzindo colisões de nomes em aplicações frontend.

## Em uma frase

CSS Modules mantém estilos locais sem abandonar CSS.

## O que precisa saber

Build transforma nomes locais em identificadores seguros; composição, temas e estilos globais ainda precisam de estratégia. Integra [[react]] e [[css3]].

## Erros comuns

- Supor que todo estilo global desaparece.
- Esquecer convenções de composição e especificidade.
