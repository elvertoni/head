Componentes de cliente Next.js são componentes React enviados ao navegador para lidar com estado, eventos e APIs disponíveis no ambiente do usuário.

## Em uma frase

Componentes de cliente executam a interação que depende do navegador.

## O que precisa saber

O limite de cliente deve ser intencional; componentes de servidor podem compor a árvore. [[react]], [[nextjs]] e [[state]] ajudam a separar renderização e interação.

## Erros comuns

- Transformar a aplicação inteira em cliente sem necessidade.
- Passar valores não serializáveis entre servidor e cliente.
