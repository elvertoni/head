Bootstrap é um framework front-end que fornece classes CSS, componentes e convenções para construir interfaces web responsivas. Ele acelera prototipação, mas suas classes não substituem a compreensão de [[css3]] e do [[box-model]].

## Em uma frase

Bootstrap oferece uma base reutilizável de estilos e componentes para interfaces web.

## O que precisa saber

O framework normalmente é carregado por [[cdn]] ou instalado no projeto. Classes de layout e componentes combinam HTML e CSS; scripts opcionais acrescentam comportamento. A responsividade depende da composição de classes e pode ser refinada com [[media-query]].

## Erros comuns

- Usar classes sem entender a estrutura HTML que elas esperam.
- Presumir que o framework resolve acessibilidade e conteúdo.
- Sobrescrever estilos em excesso até criar um framework acidental.
