As regras de Codd são critérios propostos para avaliar quanto um sistema se comporta como um sistema de gerenciamento relacional. Elas tratam representação, acesso, tratamento de valores, independência, integridade e outras propriedades do modelo.

## Em uma frase

As regras de Codd são uma referência para avaliar a relacionalidade de um SGBD.

## O que precisa saber

As regras ajudam a discutir o [[modelo-relacional]], mas não são uma receita de projeto nem substituem requisitos do domínio. Um [[sgbd]] pode oferecer recursos relacionais sem cumprir todos os critérios de forma estrita; a análise precisa distinguir marketing, implementação e comportamento.

## Erros comuns

- Tratar as regras como checklist suficiente para escolher um SGBD.
- Confundir suporte a SQL com conformidade total.
- Aplicar os critérios sem definir o que será avaliado.
