SDK do Firebase é o conjunto de bibliotecas que inicializa e integra uma aplicação aos serviços Firebase, como autenticação, banco e hospedagem. Ele oferece APIs de cliente, mas não elimina regras de segurança.

## Em uma frase

Firebase SDK conecta código da aplicação aos serviços Firebase.

## O que precisa saber

Configuração, versão, ambiente, regras de acesso e tratamento offline precisam ser controlados. A configuração visível no cliente não deve ser confundida com segredo.

## Erros comuns

- Usar SDK sem configurar regras de segurança.
- Misturar projetos de desenvolvimento e produção.
- Atualizar biblioteca sem testar mudanças de API.
