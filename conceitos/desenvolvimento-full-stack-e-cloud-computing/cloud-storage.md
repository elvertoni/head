Cloud Storage é um serviço de armazenamento de objetos para arquivos, mídia e outros blobs acessíveis por APIs e regras de permissão.

## Em uma frase

Object storage guarda arquivos com escala e acesso controlado por serviço.

## O que precisa saber

Nomeação, metadados, ciclo de vida, custos de transferência e políticas de acesso precisam ser definidos. Banco de documentos e storage resolvem necessidades diferentes.

## Erros comuns

- Guardar segredo em arquivo público.
- Usar storage como banco transacional sem necessidade.
