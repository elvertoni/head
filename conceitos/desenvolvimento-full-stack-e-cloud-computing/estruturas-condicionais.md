Estruturas condicionais escolhem um caminho de execução conforme uma expressão lógica. Em JavaScript, if, else e o operador ternário permitem executar alternativas quando uma condição é verdadeira ou falsa.

## Em uma frase

Uma condicional transforma uma decisão lógica em caminhos diferentes de execução.

## O que precisa saber

A condição normalmente é construída com [[operadores-javascript]] e pode combinar variáveis e entradas. if-else atende ramificações explícitas; o operador ternário é uma forma compacta para expressões simples. Muitas alternativas podem ser organizadas com [[switch-case]].

## Erros comuns

- Confundir atribuição com comparação.
- Criar condições com efeitos colaterais difíceis de testar.
- Usar ternário aninhado quando if-else seria mais legível.
