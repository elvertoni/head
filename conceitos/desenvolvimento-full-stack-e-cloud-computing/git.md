Git é um sistema distribuído de controle de versão que registra snapshots de arquivos e permite ramificar, integrar e compartilhar históricos. Seu modelo local favorece trabalho offline e colaboração por repositórios remotos.

## Em uma frase

Git registra e integra históricos distribuídos de mudanças.

## O que precisa saber

Git implementa [[controle-de-versao]]; branches, commits e merges precisam de convenções de equipe. Pull requests e automações podem conectar histórico a [[integracao-continua]] e [[pipeline-ci-cd]].

## Erros comuns

- Reescrever histórico compartilhado sem coordenação.
- Usar branch como substituto de revisão e testes.
- Fazer merge sem entender conflitos ou origem das mudanças.
