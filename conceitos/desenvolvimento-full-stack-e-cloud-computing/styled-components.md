styled-components é uma biblioteca que associa regras CSS a componentes JavaScript, permitindo estilos condicionais e escopo gerado.

## Em uma frase

styled-components coloca estilo e componente no mesmo modelo de composição.

## O que precisa saber

Temas, custo de geração, SSR, acessibilidade e tamanho do bundle influenciam a escolha. CSS-in-JS é uma estratégia, não requisito do [[react]].

## Erros comuns

- Gerar componentes estilizados dentro de cada renderização.
- Ignorar CSS global, semântica e performance.
