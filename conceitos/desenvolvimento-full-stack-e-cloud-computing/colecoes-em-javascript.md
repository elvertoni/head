Coleções em JavaScript são estruturas usadas para agrupar, consultar e transformar conjuntos de valores. Arrays são a forma introdutória mais comum, mas a organização adequada depende do tipo de acesso e das relações entre os dados.

## Em uma frase

Uma coleção organiza múltiplos valores para que o programa possa consultá-los e transformá-los.

## O que precisa saber

[[arrays-em-javascript]] atendem sequências indexadas; funções de iteração ajudam a filtrar, mapear e reduzir dados. A escolha da estrutura deve considerar identidade, ordem, duplicidade e operação dominante. [[funcoes-em-javascript]] tornam as transformações composicionais.

## Erros comuns

- Escolher uma coleção só por familiaridade.
- Misturar atualização e leitura de dados sem definir mutabilidade.
- Confundir uma coleção com o modelo de domínio que ela representa.
