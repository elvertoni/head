Componente React é uma unidade reutilizável que recebe entradas, produz uma parte da interface e pode coordenar estado e efeitos. A composição de componentes organiza a aplicação por responsabilidades e relações de dados.

## Em uma frase

Componente encapsula uma parte da interface e suas regras de renderização.

## O que precisa saber

[[props]] entram no componente; [[state]] representa dados que podem mudar; [[jsx]] descreve a saída. Bons componentes têm contrato claro, evitam estado duplicado e podem ser compostos por outros componentes.

## Erros comuns

- Criar componente monolítico com regra de negócio e infraestrutura misturadas.
- Usar state para dados derivados que poderiam ser calculados.
- Alterar props ou objetos compartilhados diretamente.
