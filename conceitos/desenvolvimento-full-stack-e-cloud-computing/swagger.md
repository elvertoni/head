Swagger é um ecossistema de ferramentas que trabalha com contratos OpenAPI, incluindo visualização interativa, edição e geração de código. O formato atual do contrato é governado pela especificação [[openapi]].

## Em uma frase

Swagger oferece ferramentas para documentar e explorar contratos OpenAPI.

## O que precisa saber

Swagger UI pode apresentar endpoints e exemplos; outras ferramentas geram clientes ou validam descrições. A interface exibida não substitui autenticação nem testes de comportamento.

## Erros comuns

- Usar Swagger como sinônimo de qualquer API documentada.
- Publicar console interativo sem proteger operações.
- Gerar código e não revisar incompatibilidades.
