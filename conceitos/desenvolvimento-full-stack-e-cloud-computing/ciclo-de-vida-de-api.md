Ciclo de vida de API reúne concepção, contrato, implementação, testes, publicação, observação, evolução e retirada de uma API. Ele trata a interface como produto consumido por outros sistemas.

## Em uma frase

Ciclo de vida governa uma API desde o desenho até a desativação.

## O que precisa saber

[[openapi]], versionamento, compatibilidade, métricas, documentação e comunicação de mudanças são partes do ciclo. A retirada precisa considerar consumidores ativos e uma janela de migração.

## Erros comuns

- Considerar deploy o fim do ciclo.
- Alterar contrato sem medir consumidores.
- Depreciar uma versão sem plano, prazo e alternativa.
