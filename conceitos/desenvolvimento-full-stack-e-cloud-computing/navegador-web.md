Navegador Web é o software que solicita recursos, interpreta HTML, CSS e JavaScript, e apresenta uma interface ao usuário. Ele também aplica políticas de segurança e oferece APIs para interação com o dispositivo.

## Em uma frase

Navegador solicita, interpreta e apresenta recursos da Web.

## O que precisa saber

O browser integra [[motor-de-renderizacao]], [[runtime-do-navegador]] e [[web-apis-do-navegador]]. A origem, o armazenamento, a rede e o foco de teclado influenciam o comportamento observado.

## Erros comuns

- Tratar o navegador como simples tela para o servidor.
- Assumir que todo browser implementa recursos de forma idêntica.
- Confiar no cliente para impor autorização.
