Web APIs do navegador são interfaces oferecidas pelo ambiente Web para rede, documentos, eventos, armazenamento, mídia e dispositivos. Elas ampliam JavaScript sem fazer parte do núcleo da linguagem.

## Em uma frase

Web APIs conectam JavaScript às capacidades controladas do navegador.

## O que precisa saber

DOM, [[fetch-api]], FormData e eventos são APIs com contratos próprios. Permissões, origem, compatibilidade e tratamento assíncrono precisam ser considerados.

## Erros comuns

- Confundir API do navegador com API do servidor.
- Usar recurso sem fallback ou verificação de compatibilidade.
- Ignorar segurança e consentimento ao acessar dados do dispositivo.
