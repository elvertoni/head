kubectl é o cliente de linha de comando usado para consultar e operar objetos de um cluster Kubernetes pela API.

## Em uma frase

kubectl é a interface operacional humana para a API do cluster.

## O que precisa saber

Contexto, namespace, credenciais, comandos declarativos e inspeção de eventos são parte do uso seguro. Automação deve controlar permissões e reprodutibilidade.

## Erros comuns

- Executar comando destrutivo no contexto errado.
- Tratar a saída local como observabilidade completa do cluster.
