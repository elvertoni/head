Suspense React permite declarar um fallback enquanto parte da árvore aguarda recurso ou código necessário para renderizar.

## Em uma frase

Suspense torna espera de interface uma fronteira explícita.

## O que precisa saber

Fronteiras podem ser combinadas com [[streaming-web]] e carregamento progressivo. Suspense coordena renderização; não é por si só uma estratégia de cache ou retry.

## Erros comuns

- Usar fallback que esconde erro permanente.
- Colocar uma única fronteira e bloquear toda a interface.
