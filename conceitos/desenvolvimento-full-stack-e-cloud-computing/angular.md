Angular é um framework de desenvolvimento de interfaces e aplicações Web baseado em JavaScript e componentes. Ele oferece uma estrutura mais opinativa para organizar telas, serviços, rotas e comunicação com dados, complementando bibliotecas focadas na camada de visualização.

## Em uma frase

Angular é um framework estruturado para construir aplicações Web componentizadas.

## O que precisa saber

A organização por componentes e serviços favorece separação de responsabilidades e aplicações de maior porte. Ao comparar Angular com [[react]] e [[vue]], considere ecossistema, convenções e necessidades do projeto. O framework participa da camada [[frontend]] e continua dependendo de APIs e contratos do backend.

## Erros comuns

- Escolher um framework só por popularidade, sem considerar equipe e ecossistema.
- Confundir framework de interface com uma solução completa de backend.
- Misturar convenções de Angular, React e Vue sem entender seus modelos.
