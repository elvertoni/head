Teste de API verifica contratos, entradas, respostas, erros e efeitos de endpoints independentemente da interface que os consome.

## Em uma frase

Testar API protege o contrato entre clientes e backend.

## O que precisa saber

Casos devem cobrir autenticação, validação, idempotência, status HTTP e persistência. Testes de contrato e integração complementam unitários.

## Erros comuns

- Verificar apenas status 200 e ignorar corpo e efeitos.
- Usar dados compartilhados que tornam os testes dependentes da ordem.
