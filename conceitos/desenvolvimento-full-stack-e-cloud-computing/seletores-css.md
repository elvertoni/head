Seletores CSS são padrões que determinam quais elementos HTML recebem uma regra de estilo. Eles podem selecionar por tipo de elemento, classe, identificador, relação estrutural e estados como pseudoclasses.

## Em uma frase

Um seletor CSS escolhe o conjunto de elementos ao qual uma regra será aplicada.

## O que precisa saber

Seletores fazem parte do [[css3]] e conectam a regra ao documento [[html5]]. Seletores de classe favorecem reutilização; identificadores devem representar elementos únicos; seletores por relação permitem expressar contexto, mas aumentam a dependência da estrutura. Especificidade e ordem de declaração ajudam a explicar conflitos entre regras.

## Erros comuns

- Usar id para todos os estilos e perder reutilização.
- Criar seletores excessivamente longos e frágeis.
- Resolver conflito apenas com !important sem entender especificidade.
