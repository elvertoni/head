Banco de dados é uma coleção organizada de dados relacionados, mantida para permitir armazenamento, consulta, atualização e compartilhamento controlados. Seu valor depende tanto dos dados quanto do modelo, das regras e dos mecanismos que preservam sua qualidade.

## Em uma frase

Banco de dados organiza dados relacionados para uso persistente e controlado.

## O que precisa saber

Dados representam fatos; informação é uma interpretação útil desses dados. O desenho do banco passa por [[modelagem-de-dados]], [[modelo-conceitual]], [[modelo-logico]] e [[modelo-fisico]]. Um [[sgbd]] oferece serviços de armazenamento, consulta, segurança e concorrência.

## Erros comuns

- Tratar banco de dados como simples arquivo sem regras de consistência.
- Projetar tabelas antes de compreender entidades e relações.
- Confundir volume de dados com qualidade ou utilidade.
