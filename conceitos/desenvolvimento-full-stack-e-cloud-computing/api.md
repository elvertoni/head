API é um contrato de interação que define operações, dados, regras e limites para que um software use capacidades de outro. Uma API pode existir dentro de uma biblioteca, processo ou serviço de rede; sua qualidade depende de contrato, evolução e operação.

## Em uma frase

API é um contrato que permite a um software usar capacidades de outro.

## O que precisa saber

APIs Web normalmente usam [[http]], [[json]] e estilos como [[rest]] ou [[api-rest]]. Métodos, erros, autenticação, versionamento e documentação fazem parte do contrato. API não é apenas endpoint nem sinônimo de CRUD.

## Erros comuns

- Documentar apenas URL e omitir regras e erros.
- Quebrar consumidores sem versionar ou comunicar mudança.
- Expor operação interna como contrato público sem estabilidade.
