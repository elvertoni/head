React é uma biblioteca para construir interfaces por componentes declarativos. A aplicação descreve a UI a partir de dados e estado; o runtime calcula atualizações e coordena a renderização.

## Em uma frase

React organiza interfaces como componentes declarativos que respondem a estado e propriedades.

## O que precisa saber

[[jsx]], [[componente-react]], props e state formam o vocabulário básico. React não é automaticamente uma aplicação completa: roteamento, dados, autenticação e renderização dependem de bibliotecas e arquitetura, como [[nextjs]].

## Erros comuns

- Mutar estado diretamente e esperar renderização previsível.
- Criar componente sem responsabilidade clara.
- Confundir renderização declarativa com ausência de custo.
