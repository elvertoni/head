JavaScript é uma linguagem de programação usada para implementar comportamento em páginas web e também em ambientes fora do navegador. No navegador, ela pode ler e alterar a árvore HTML, reagir a eventos e coordenar dados e apresentação.

## Em uma frase

JavaScript transforma páginas HTML estáticas em experiências programáveis e interativas.

## O que precisa saber

A lógica pode ser planejada com [[algoritmo]], [[fluxograma]] ou [[pseudocodigo]]. A linguagem oferece [[variaveis-em-javascript]], [[estruturas-condicionais]], [[lacos-de-repeticao]], arrays e funções. No navegador, [[manipulacao-do-dom]] e [[integracao-javascript-html]] conectam o programa à interface; bibliotecas e frameworks como [[bootstrap]] podem complementar a apresentação.

## Erros comuns

- Confundir JavaScript com HTML ou CSS.
- Presumir que código executado no navegador é confiável para regras de segurança.
- Criar scripts acoplados a uma estrutura HTML instável.
