Algoritmo é uma sequência finita, ordenada e não ambígua de instruções para transformar entradas em uma solução ou saída. Ele descreve o procedimento de resolução antes de ser traduzido para uma linguagem de programação.

## Em uma frase

Algoritmo é um procedimento finito e definido para resolver um problema.

## O que precisa saber

Um algoritmo pode ser comunicado por [[fluxograma]], [[pseudocodigo]] ou código executável. Variáveis, entradas, decisões e repetições tornam o procedimento operacional; [[javascript]] é uma das linguagens que pode implementá-lo. A qualidade do algoritmo depende do problema e dos critérios de correção, não da linguagem escolhida.

## Erros comuns

- Confundir uma ideia vaga com uma sequência executável.
- Omitir casos de entrada, condição de parada ou saída.
- Escrever código antes de definir o problema e os passos.
