MySQL é um sistema gerenciador de banco de dados relacional que implementa SQL e oferece armazenamento, consulta e transações para aplicações.

## Em uma frase

MySQL é um SGBD relacional usado para persistir dados de aplicações.

## O que precisa saber

Uma aplicação acessa o servidor por um driver ou [[orm]], executando comandos [[sql]]. Esquema, índices, transações, permissões e backup continuam sendo decisões de projeto.

## Erros comuns

- Confundir o servidor MySQL com a linguagem SQL.
- Usar credenciais administrativas na aplicação.
- Ignorar transações, índices e migrações de esquema.
