Firebase CLI é a ferramenta de linha de comando para autenticar, configurar, testar e publicar recursos de um projeto Firebase. Ela transforma configuração local em ações de deployment reproduzíveis.

## Em uma frase

Firebase CLI automatiza configuração e publicação de projetos Firebase.

## O que precisa saber

Conta, projeto, ambiente, arquivos de configuração e permissões precisam ser explícitos. O pipeline deve revisar regras e artefatos antes de publicar.

## Erros comuns

- Publicar no projeto errado.
- Guardar token de CI sem rotação ou escopo.
- Confundir deploy bem-sucedido com aplicação segura.
