Rotas de API Next.js são endpoints definidos dentro do projeto para receber requisições, executar lógica de servidor e devolver respostas.

## Em uma frase

Rotas de API aproximam endpoints do código que renderiza a aplicação.

## O que precisa saber

Método, validação, autenticação, erros e limites precisam ser tratados como em qualquer [[api]]. A rota pode ser serverless ou parte de um runtime persistente.

## Erros comuns

- Aceitar entrada sem validação de schema.
- Colocar credenciais ou regras de autorização no cliente.
