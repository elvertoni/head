Modelo de dados é uma linguagem de conceitos e regras usada para descrever a estrutura, os relacionamentos e as restrições de um domínio. Ele funciona como uma ponte entre entendimento do negócio e implementação no banco.

## Em uma frase

Modelo de dados é a gramática usada para descrever dados e relações.

## O que precisa saber

Os níveis [[modelo-conceitual]], [[modelo-logico]] e [[modelo-fisico]] representam diferentes compromissos com detalhes. O modelo escolhido deve tornar regras importantes explícitas e permitir verificar se o banco responde às necessidades.

## Erros comuns

- Tratar modelo como desenho sem semântica.
- Misturar decisões físicas no modelo conceitual.
- Omitir regras porque não cabem no diagrama.
