Atributo é uma propriedade usada para descrever uma entidade ou, em alguns casos, um relacionamento. Ele define que informação deve ser conhecida sobre cada ocorrência, como nome, data ou valor.

## Em uma frase

Atributo descreve uma propriedade relevante de uma entidade ou relação.

## O que precisa saber

Atributos podem ser [[atributo-simples]], [[atributo-composto]], [[atributo-derivado]] ou [[atributo-multivalorado]]. Cada um possui domínio e regras; a transformação para o [[modelo-logico]] deve decidir como representar essa variedade.

## Erros comuns

- Criar atributo para cada detalhe de uma tela.
- Armazenar múltiplos valores em um campo simples sem modelar a regra.
- Confundir atributo derivado com dado que precisa ser persistido.
