React Router é uma biblioteca para mapear URLs a componentes React, controlar navegação e transportar parâmetros de rota.

## Em uma frase

React Router conecta URL, estado de navegação e árvore de componentes.

## O que precisa saber

Rotas aninhadas, parâmetros, loaders, redirecionamento e proteção devem ser coerentes com [[react]] e [[protecao-de-rotas]]. Roteamento não substitui autorização no backend.

## Erros comuns

- Tratar navegação client-side como segurança.
- Perder estado ou acessibilidade ao trocar de rota.
