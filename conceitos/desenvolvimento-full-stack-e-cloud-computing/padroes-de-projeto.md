Padrões de projeto são soluções nomeadas e recorrentes para problemas de design em determinado contexto. Eles comunicam estrutura e trade-offs, mas não são código pronto nem garantem qualidade por si só.

## Em uma frase

Padrões de projeto dão vocabulário para decisões recorrentes de design.

## O que precisa saber

[[mvc]], [[flyweight]] e [[proxy-pattern]] resolvem problemas distintos. O padrão deve ser escolhido pelo problema, pelas forças e pelo custo de introduzi-lo.

## Erros comuns

- Forçar um padrão para parecer arquiteturalmente sofisticado.
- Confundir nome do padrão com entendimento de suas consequências.
- Criar indireção antes de existir necessidade.
