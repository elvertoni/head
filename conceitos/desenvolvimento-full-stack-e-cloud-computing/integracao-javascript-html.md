Integração JavaScript-HTML é a combinação entre estrutura HTML, eventos, dados e funções para produzir uma interface web dinâmica. O script observa ações, transforma estado e atualiza elementos da página por meio do DOM.

## Em uma frase

Integrar JavaScript e HTML é conectar estado e comportamento à estrutura visível da página.

## O que precisa saber

O fluxo combina [[manipulacao-do-dom]], [[arrays-em-javascript]], [[funcoes-em-javascript]] e eventos. O projeto de carrinho de compras mostra uma aplicação concreta dessa integração: dados de produtos, cálculo e renderização precisam permanecer coerentes. [[html-semantico]] e [[css3]] continuam responsáveis pela estrutura e apresentação.

## Erros comuns

- Duplicar o estado em variáveis e no DOM sem definir uma fonte de verdade.
- Misturar cálculo com manipulação visual e dificultar testes.
- Confiar em ids fixos sem tratar ausência ou repetição.
