OpenAPI é uma especificação declarativa para descrever endpoints, parâmetros, respostas, esquemas e segurança de uma API HTTP. O documento pode alimentar documentação, validação e geração de clientes.

## Em uma frase

OpenAPI transforma o contrato de uma API em uma descrição legível por ferramentas.

## O que precisa saber

O contrato deve refletir comportamento real, incluindo erros e autenticação. A especificação ajuda testes e descoberta, mas não implementa autorização, regras de negócio ou disponibilidade.

## Erros comuns

- Documentar somente o caminho feliz.
- Deixar o contrato divergir da implementação.
- Expor exemplos com credenciais ou dados reais.
