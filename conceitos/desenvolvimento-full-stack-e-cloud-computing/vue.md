Vue é um framework progressivo de JavaScript para construir interfaces Web com componentes e reatividade. Ele pode ser adotado gradualmente em uma página ou usado como base de uma aplicação maior, conforme as necessidades de arquitetura e equipe.

## Em uma frase

Vue é um framework progressivo para interfaces Web reativas e componentizadas.

## O que precisa saber

Vue organiza a interface em componentes e atualiza a apresentação quando os dados mudam. Compare-o com [[react]] e [[angular]] por modelo de componentes, convenções e ecossistema. Como solução de [[frontend]], integra-se a [[api]] e a outras camadas.

## Erros comuns

- Tratar reatividade como substituta para modelagem de estado.
- Escolher Vue sem avaliar bibliotecas e práticas da equipe.
- Confundir framework de frontend com uma API de backend.
