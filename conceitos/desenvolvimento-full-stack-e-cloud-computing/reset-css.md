Reset CSS é um conjunto de regras que neutraliza ou normaliza estilos padrão aplicados pelos navegadores para que o projeto comece com uma base previsível. Ele não cria um design: apenas reduz diferenças de margem, tipografia e comportamento que precisam ser redefinidas conscientemente.

## Em uma frase

Reset CSS cria uma base previsível ao reduzir estilos padrão do navegador.

## O que precisa saber

Um reset pode ser amplo ou seletivo; normalizadores preservam algumas convenções e corrigem diferenças específicas. Depois dele, o projeto ainda precisa definir tipografia, foco, estados e responsividade com [[css3]] e [[seletores-css]]. A escolha deve considerar acessibilidade e compatibilidade.

## Erros comuns

- Aplicar reset sem reconstruir estilos de foco e elementos semânticos.
- Copiar uma folha antiga sem saber quais diferenças ela corrige.
- Confundir reset com sistema de design ou framework visual.
