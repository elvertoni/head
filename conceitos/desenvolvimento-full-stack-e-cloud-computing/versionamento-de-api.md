Versionamento de API é a estratégia para evoluir contratos de integração sem quebrar consumidores existentes.

## Em uma frase

Versionar uma API torna mudanças de contrato previsíveis para clientes.

## O que precisa saber

Versionar por URL, cabeçalho ou compatibilidade de schema exige política de depreciação, documentação e testes. [[api-rest]] não define sozinho a estratégia.

## Erros comuns

- Quebrar campos ou semântica sem anunciar.
- Manter versões indefinidamente sem medir consumidores.
