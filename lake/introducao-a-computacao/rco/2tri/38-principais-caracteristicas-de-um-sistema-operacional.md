Questão 1

Consideramos que Sistemas Operacionais são uma categoria específica de software de computadores que possuem a função de controlar o hardware computacional e permitir a interação do usuário com o sistema e seus dispositivos interconectados. Dessa forma, consideram-se exemplos de sistemas operacionais

a) Microsoft Word, Google Maps e WhatsApp.

b) Linux Fedora, Android e Microsoft Word.

c) Microsoft Windows, Linux Ubuntu e iOS.

d) Microsoft Windows, Linux Ubuntu e Microsoft Excel.

Resposta comentada: Microsoft Windows, Linux Ubuntu e iOS são sistemas operacionais. Microsoft Excel, Microsoft Word, Google Maps e WhatsApp são softwares de aplicativos, ou seja, são programas utilizados para realizar alguma tarefa.

Questão 2

Os sistemas operacionais podem ser destinados a diversos tipos de sistemas computacionais. Há sistemas operacionais específicos para computadores servidores de rede, outros específicos para computadores pessoais como desktops e notebooks, e ainda, outros específicos para dispositivos móveis. São considerados sistemas operacionais utilizados em dispositivos móveis

a) Windows 10 e Linux Ubuntu.

b) iOS e Windows 10.

c) Linux Ubuntu e Microsoft Windows Server.

d) iOS e Android.

Resposta comentada: iOS e Android são sistemas operacionais utilizados em dispositivos móveis como smartphones e tablets. Windows 10 é um sistema operacional utilizado em computadores pessoais como desktop e notebook. O Linux Ubuntu é utilizado em servidores de rede e computadores pessoais, mas também pode ser utilizado em smartphone. E o Microsoft Windows Server é utilizado em servidores de rede.

AULA PRÁTICA 38

Resumo Explicativo:

Os sistemas operacionais possuem características fundamentais que garantem o funcionamento eficiente e seguro dos computadores e dispositivos móveis. Entre essas características estão o gerenciamento de processos, controle de memória, gerenciamento de arquivos, segurança do sistema, interface com o usuário, e a capacidade de multitarefa. Compreender essas funções é essencial para desenvolver sistemas, pois elas determinam como o hardware é utilizado e como os aplicativos interagem com o computador.

Estudo de Caso:

Cenário:

Na aula de Desenvolvimento de Sistemas, o professor propôs que cada grupo estudasse uma característica principal dos sistemas operacionais e explicasse como ela funciona na prática.

O grupo de Júlia ficou responsável por apresentar o gerenciamento de processos. Durante a pesquisa, eles descobriram que o sistema operacional deve ser capaz de:

- Criar e finalizar processos.
- Atribuir prioridades de execução.
- Proteger a memória de cada processo.
- Permitir que os processos se comuniquem entre si.
Ao preparar a apresentação, o grupo encontrou exemplos em que uma má gestão de processos fez o computador travar ou ficar lento. Eles também estudaram como a capacidade de multitarefa e a segurança do sistema dependem do gerenciamento adequado de processos e memória.

O desafio final foi criar um exemplo prático simulando vários aplicativos rodando ao mesmo tempo e mostrar como o sistema operacional organiza cada um.

Questões

- Liste quatro características essenciais de um sistema operacional.
- Explique, com suas palavras, como o gerenciamento de memória influencia no desempenho do computador.
- Imagine que você abriu um editor de texto, um navegador e um player de música. Descreva como o sistema operacional gerencia esses processos para que funcionem ao mesmo tempo.
- Analise como as funções de segurança e gerenciamento de arquivos se complementam para proteger os dados de um usuário.
- Você considera a interface gráfica mais importante que o gerenciamento de processos em um sistema operacional? Justifique sua resposta com exemplos.
- Desenvolva uma simulação ou um fluxograma que mostre como um sistema operacional gerencia a execução simultânea de três programas diferentes, destacando os recursos usados e a proteção da memória.
