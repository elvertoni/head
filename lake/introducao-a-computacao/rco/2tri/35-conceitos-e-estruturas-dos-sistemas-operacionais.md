### Slide 7

- DESENVOLVIMENTO DE SISTEMAS
- Depois de pesquisar um pouco, Bob descobre que o sistema operacional é como o gerente do computador. Ele controla todos os recursos do sistema, incluindo o hardware (como a CPU, memória, teclado, mouse, etc.) e o software (todos os programas e aplicativos). O sistema operacional coordena todas as ações, decidindo qual programa recebe quanta memória, quando e por quanto tempo cada programa pode usar a CPU, como os programas se comunicam e muito mais.

### Slide 8

- DESENVOLVIMENTO DE SISTEMAS
- Bob fica ainda mais curioso sobre a estrutura de um sistema operacional. Ele descobre que, em termos muito simples, a estrutura de um sistema operacional pode ser dividida em três camadas principais.
- Na base, temos o hardware do computador. Acima do hardware, temos o próprio sistema operacional, que atua como uma interface entre o hardware e os aplicativos. No topo, temos os aplicativos e programas, que interagem com o sistema operacional para acessar os recursos do hardware.

### Slide 12

- DESENVOLVIMENTO DE SISTEMAS
- A estrutura do sistema operacional é composta por várias
- camadas. A camada mais baixa é o kernel, que é o núcleo do sistema operacional e interage diretamente com o hardware. Acima do kernel estão os serviços do sistema e os drivers de dispositivos, que fornecem funcionalidades adicionais, como a capacidade de se conectar a redes ou exibir gráficos.
- No topo da hierarquia estão os programas de usuário, que são os aplicativos que os usuários realmente usam, como navegadores da web ou processadores de texto.

ATIVIDADE AULA 35

Questão 1

O que é um sistema operacional?

A) Um software de edição de vídeo.

B) Um conjunto de instruções que permite ao computador realizar tarefas.

C) Um hardware que permite ao computador conectar-se à internet.

D) Um software que permite criar apresentações.

Resposta Correta: B) Um sistema operacional é um conjunto de instruções que permite ao computador realizar tarefas. Ele controla todos os recursos do sistema, decidindo como e quando os programas podem acessar a CPU, a memória e outros recursos.

Questão 2

Como é a estrutura básica de um sistema operacional?

A) Aplicativos - Sistema Operacional - Hardware.

B) Hardware - Aplicativos - Sistema Operacional.

C) Sistema Operacional - Hardware - Aplicativos.

D) Hardware - Sistema Operacional - Aplicativos.

Resposta Correta: A) Aplicativos - Sistema Operacional - Hardware. A estrutura básica de um sistema operacional é geralmente compreendida como uma hierarquia de camadas, com o hardware na base, o sistema operacional acima dele agindo como uma interface, e os aplicativos e programas no topo, interagindo com o sistema operacional para acessar os recursos do hardware.

AULA PRÁTICA 35

Resumo Explicativo:

Sistemas Operacionais (SOs) são responsáveis por gerenciar os recursos do computador e fornecer uma interface entre o hardware e os programas. Eles controlam processos, memória, armazenamento, dispositivos de entrada/saída e oferecem serviços essenciais para a execução de softwares. Compreender a estrutura de um SO é essencial para desenvolver sistemas eficientes e seguros.

Estudo de Caso:

Cenário:

Em uma escola técnica, a professora Marina propõe que os alunos configurem um laboratório com diferentes sistemas operacionais (Windows, Linux e Android-x86) para uma atividade prática. O objetivo é explorar como cada sistema organiza seus componentes principais: gerenciamento de processos, sistema de arquivos, controle de dispositivos e interface com o usuário.

Durante a atividade, os alunos percebem diferenças importantes: no Linux, muitos processos são iniciados com comandos no terminal; no Windows, há maior dependência de interfaces gráficas; já no Android, a estrutura é otimizada para dispositivos móveis e sensores.

Diante disso, o desafio final da atividade é montar um relatório comparando os sistemas, explicando como a estrutura interna de cada um afeta seu desempenho, segurança e usabilidade em diferentes contextos.

Questões

- Quais são as principais funções de um sistema operacional? Liste pelo menos três.
- Explique com suas palavras o que é o "gerenciador de processos" em um sistema operacional.
- Imagine que um computador está lento porque há muitos programas abertos. Como o sistema operacional poderia ajudar a resolver esse problema?
- Compare os sistemas operacionais Windows e Linux em relação ao gerenciamento de memória e arquivos. Quais são as principais diferenças?
- Você acredita que sistemas operacionais baseados em Linux são mais seguros que os baseados em Windows? Justifique sua resposta considerando o controle do usuário e atualizações.
- Proponha uma estrutura ideal de sistema operacional para ser usada em um laboratório escolar, considerando fatores como facilidade de uso, segurança e compatibilidade com programas educacionais.
