### Slide 8

- Resposta
- 3 minutos
- R. Requisitos podem ser definidos como recursos de hardware e software para suporte à instalação e execução de um determinado sistema.
- R. Por exemplo: tipo de processador, quantidade de memória RAM necessária para execução do sistema, quantidade de espaço em disco rígido (ou memória sólida) para armazenamento do sistema operacional e sua execução, tipo de resolução do monitor de vídeo (qualidade gráfica) e também tipo de placa de vídeo (que processa e controla as imagens enviadas ao monitor de vídeo).
- R. Na realidade, o sistema operacional Windows 10 pode ser executado em um computador pessoal ou dispositivo móvel como smartphone ou tablet com requisitos simples, considerando os computadores atuais.

### Slide 12

- Sistemas de 32 bits e sistemas de 64 bits
- O Windows 10 suporta dois tipos de arquitetura de processamento:
- 32 bits: arquitetura de processamento onde os processadores do computador executam os programas (processos) em 32 bits. Arquitetura utilizada por sistemas mais “antigos”.
- 64 bits: arquitetura de processamento onde os processadores do computador executam os programas (processos) em 64 bits. Arquitetura utilizada por sistemas mais “recentes”.

### Slide 14

- Processador
- O processador é o elemento do sistema computacional que realiza todo o processamento de dados codificados em linhas de programação em informações na sua tela, utilizando-se da eletrônica para converter códigos em sinais eletrônicos e informação.

_2 imagem(ns) no slide._

### Slide 15

- Memória RAM
- A memória RAM (Random Access Memory) é a memória, ou conjunto de memórias utilizadas pelo sistema computacional para carregar os arquivos executáveis de programas e manter espaço para que o processador armazene e organize as informações no período que o computador está ligado.
- Ao desligar o computador, todo o conteúdo da memória RAM é apagado.

_2 imagem(ns) no slide._

### Slide 16

- Espaço em disco
- O espaço em disco é o volume de bytes necessários para instalação e armazenamento dos arquivos do sistema operacional Windows 10 no disco rígido do computador, que mantém os arquivos de forma permanente.

### Slide 17

- Placa gráfica
- A placa gráfica é um dispositivo que pode estar incluída dentro da chamada placa-mãe do computador pessoal ou ser uma placa adicionada, com recursos e qualidade de processamento superiores.

### Slide 18

- Monitor de vídeo
- O monitor de vídeo (ou projetor de vídeo) é o dispositivo computacional que irá apresentar as informações processadas pelo hardware e controladas pelo sistema operacional em formato gráfico ao usuário e permitir a interação com o sistema.

_2 imagem(ns) no slide._

### Slide 19

- Recursos mínimos para instalação
- Recursos mínimos para instalação de um sistema operacional Windows 10:
- Processador: 1 GHz (giga-hertz) ou superior.
- Memória RAM: 1 GB para sistemas em 32 bits e 3 GB para sistemas em 64 bits.
- Espaço em disco rígido: 16 GB para sistemas em 32 bits e 20 GB para sistemas de 64 bits.
- Monitor de vídeo: monitor com resolução de 800x600 pixels ou superior.
- Placa gráfica: qualquer placa de vídeo com suporte a tecnologia Directex 9. Placas mais simples também permitem a utilização do sistema.

Questão 1

A instalação de um sistema operacional Microsoft Windows 10 necessita que alguns requisitos de hardware sejam avaliados para que o sistema suporte uma execução adequada do sistema operacional. Qual das alternativas a seguir apresenta o conceito de requisitos?

a) Recurso de memória do computador que apresenta a quantidade de processamento do sistema computacional apenas.

b) Recurso apresentação de dados em formato gráfico no computador que apresenta a resolução das imagens gráficas projetadas apenas.

c) Recursos de hardware (processador, memórias e monitor) e de software necessários para que um sistema operacional seja instalado e executado.

d) Apenas o recurso de processamento representado pelo processador do computador que apresenta a velocidade de processamento do sistema computacional.

Resposta comentada: A resposta correta é a letra “c”, pois os requisitos de sistema para instalação de um sistema operacional necessitam considerar o processador e sua capacidade de processamento, a memória RAM com a sua capacidade de armazenamento volátil de dados, a memória em disco ou sólida e suas capacidades de armazenamento permanente de dados, a placa gráfica de processamento e geração de imagens e o próprio monitor com sua resolução de projeção. Estão incorretas as alternativas “a”, “b” e “d”, pois não apresentam todos os requisitos necessários para que o sistema suporte uma execução adequada do sistema operacional.

Questão 2

Considerando a necessidade de processamento de dados, um sistema computacional que irá receber a instalação do Microsoft Windows 10 necessita de uma velocidade de um processador compatível com uma execução satisfatória para suportar os processos (programas em execução) do usuário. Qual é o recurso mínimo referente a velocidade de processamento de um processador de um computador pessoal?

a) 1 KHz (kilo-hertz) de velocidade.

b) 1 MHz (mega-hertz) de velocidade.

c) 1 THz (tera-hertz) de velocidade.

d) 1 GHz (giga-hertz) de velocidade.

Resposta comentada: A resposta correta é a letra “d”, pois 1 GHz (giga-hertz) de velocidade é a velocidade mínima recomenda para que um sistema computacional possa ter instalado um sistema operacional Microsoft Windows 10. A letra “a” está incorreta, pois 1 KHz (kilo-hertz) de velocidade representa um processamento 1000000 vezes menor que um GHz, insuficiente para a execução do Windows 10. A letra “b” está incorreta, pois 1 MHz (mega-hertz) de velocidade representa um processamento 1000 vezes menor que um GHz, insuficiente para a execução do Windows 10. A letra “c” está incorreta, pois 1 THz (tera-hertz) de velocidade representa um processamento 1000 vezes maior que um GHz, velocidade atingida por sistemas computacionais mais complexos e não representa o requisito mínimo para execução do Windows 10.

Resumo Explicativo:

O sistema operacional Windows 10 é amplamente utilizado em ambientes pessoais, educacionais e corporativos. Para que funcione adequadamente, ele requer configurações mínimas de hardware, como processador, memória RAM, espaço em disco e placa gráfica. Além disso, é a base para a instalação e execução de diversos tipos de aplicações, desde navegadores até softwares profissionais. Conhecer os requisitos e aplicações do sistema é essencial para a escolha adequada do hardware e para o bom desempenho no uso cotidiano.

Estudo de Caso:

Cenário:

O professor André recebeu a missão de montar um novo laboratório de informática para uma escola pública. Ele precisa escolher computadores compatíveis com o Windows 10 e com os softwares educacionais utilizados na escola, como editores de texto, planilhas, navegadores modernos e simuladores de ciências.

André pesquisou os requisitos mínimos e recomendados do Windows 10, avaliou os tipos de aplicações que os alunos usariam e optou por máquinas com pelo menos 8 GB de RAM, 256 GB de SSD e processadores com no mínimo 2 núcleos.

Ao instalar o sistema operacional e os aplicativos, percebeu que o desempenho foi satisfatório e os estudantes puderam usar os programas com fluidez.
