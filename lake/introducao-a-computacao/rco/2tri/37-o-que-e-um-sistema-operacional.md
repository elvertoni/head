### Slide 8

- DESENVOLVIMENTO DE SISTEMAS
- Resposta
- Na definição de Deitel, Deitel e Choffnes (2005), um sistema operacional é reconhecido como um software que habilita as aplicações a interagir com o hardware de um computador.
- Os sistemas operacionais podem ser encontrados em:
- ● computadores pessoais;
- ● dispositivos móveis;
- ● equipamentos industriais;
- ● automóveis.

- DESENVOLVIMENTO DE SISTEMAS

Questão 1

Na definição de Deitel, Deitel e Choffnes (2005), um sistema operacional é reconhecido como um software que habilita as aplicações a interagir com o hardware de um computador.

Além disso, outra função do sistema operacional é:

a) realizar a interface com o usuário por meio de um conjunto de rotinas executadas pelo processador.

b) realizar a compilação de programas em sistemas executáveis por meio de um conjunto de hardwares.

c) realizar o desenvolvimento de linguagens de programação por meio de conjuntos de algoritmos.

d) realizar o controle de temperatura do hardware por meio de softwares como o termômetro.

Resposta comentada: Um sistema operacional consiste em um conjunto de rotinas executado pelo processador para controlar o funcionamento de um computador com o gerenciamento e compartilhamento de recursos (processador, memória, dispositivos de entrada e saída), além de realizar a interface com o usuário.

Questão 2

Um sistema operacional é um software de base que pode ser encontrado em diversos dispositivos computacionais.

Sabendo disso, assinale a opção que apresenta um dispositivo que não possui sistema operacional para seu funcionamento.

a) Computador pessoal.

b) Smartphone.

c) Notebook.

d) Monitor de vídeo.

Resposta comentada: O monitor de vídeo não possui um sistema operacional para sua operacionalização. Já os computadores pessoais, notebooks, smartphones, dentre outros dispositivos, utilizam sistemas operacionais, os quais controlam dispositivos de entrada e saída de dados, que, por sua vez, controlam um monitor de vídeo, por exemplo.

Resumo Explicativo:

O Sistema Operacional (SO) é um software fundamental que atua como intermediário entre o hardware e os usuários, além de gerenciar recursos como memória, processamento, armazenamento e dispositivos de entrada e saída. Sem o sistema operacional, os programas não teriam uma forma organizada e padronizada de se comunicar com o hardware. Entender sua função é essencial para quem deseja desenvolver sistemas, já que ele é a base para o funcionamento de qualquer computador ou dispositivo inteligente.

Estudo de Caso:

Cenário:

Gabriel está montando um computador novo. Depois de instalar todas as peças, ele liga o computador e percebe que, sem um sistema operacional, não é possível realizar nenhuma tarefa, como acessar a internet, abrir programas ou criar documentos. Ao instalar o Windows, ele percebe que agora existe uma interface gráfica, que permite clicar em ícones, abrir pastas e executar aplicativos.

Ao conversar com o professor, Gabriel descobre que o sistema operacional é responsável por:

- Controlar o uso da memória.
- Gerenciar processos e tarefas.
- Organizar os arquivos e pastas.
- Facilitar a comunicação entre os programas e os componentes do computador.
O desafio da turma é entender que, sem o sistema operacional, o hardware é praticamente inútil para o usuário comum. Eles são convidados a simular, por meio de uma dramatização, como seria o funcionamento de um computador com e sem sistema operacional.

Questões

- Liste três funções básicas de um sistema operacional.
- Explique, com suas palavras, por que o sistema operacional é considerado um intermediário entre o hardware e os usuários.
- Imagine que você precisa instalar um novo sistema operacional em um notebook. Quais etapas básicas você precisa seguir para concluir essa tarefa?
- Analise como as funções de gerenciamento de memória e de processos trabalham juntas para garantir que vários programas possam rodar ao mesmo tempo no computador.
- Você acha que um sistema operacional com interface gráfica é sempre melhor do que um baseado em linha de comando? Justifique sua resposta considerando facilidade de uso e controle do sistema.
- Desenvolva uma proposta de sistema operacional ideal para ser usado em escolas, levando em consideração segurança, facilidade de uso e acesso aos recursos educacionais.
