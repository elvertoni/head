Questão 1

Para ampliar as funcionalidades de um computador, basta utilizar algum periférico. Considere a situação em que uma pessoa precisa conectar seu computador a uma rede cabeada em sua residência. Qual tipo de conexão do computador você recomendaria?

a) HDMI.

b) RJ-45.

c) PS/2.

d) USB.

Resposta comentada: A conexão padrão para uma rede cabeada é a RJ-45, com ela é possível atingir uma velocidade de até 10Gbps. A conexão HDMI é para monitores e projetores, PS/2 é para mouse ou teclado e USB para uma larga faixa de periféricos.

Questão 2

Um computador pode ter vários periféricos conectados, de acordo com o número de conexões existentes. Quais os benefícios do uso dos periféricos?

a) Periféricos aumentam as funcionalidades de um computador.

b) Não muitos, pois periféricos não podem se conectar na conexão USB.

c) Ainda não existem muitos tipos de periféricos.

d) Periféricos sempre deixam o computador mais lento.

Resposta comentada: Os periféricos podem trazer novos usos e assim ampliam as funcionalidades de um computador.

Muitos periféricos podem se conectar na conexão USB e já existe uma gama imensa de tipos de periféricos. Uma tarefa feita sem um periférico especializado normalmente é mais demorada. Um exemplo é desenhar apenas usando o mouse ao invés de uma mesa digitalizadora ou uma caneta mouse.

###### Resumo Explicativo:

As interfaces de conexão são os meios pelos quais os dispositivos se comunicam com o computador, seja para enviar ou receber dados. Elas podem ser físicas (como portas e cabos) ou lógicas (como protocolos e padrões de comunicação).

As interfaces desempenham papel essencial na transferência de dados, alimentação de energia e na compatibilidade entre dispositivos. Entre as principais estão:

- USB (Universal Serial Bus): conexão universal para periféricos.
- HDMI: transmissão de áudio e vídeo de alta definição.
- Ethernet: comunicação em redes locais (LAN).
- Bluetooth: conexão sem fio de curto alcance.
- Wi-Fi: rede sem fio para acesso à internet e troca de dados.
- Serial e Paralela (mais antigas, ainda usadas em contextos específicos).
Compreender as interfaces de conexão é essencial no desenvolvimento de sistemas, pois influencia diretamente a escolha de componentes, a velocidade de comunicação e a integração de hardware com software.

###### Estudo de Caso:

Cenário: Uma escola técnica está montando um laboratório de robótica educacional. Os kits de robôs disponíveis possuem diferentes formas de conexão: alguns usam USB, outros Bluetooth e alguns se comunicam via Wi-Fi.

Os professores querem que os alunos desenvolvam aplicações que enviem comandos aos robôs e coletem dados dos sensores. No entanto, surgiram os seguintes desafios:

- Alguns computadores não têm Bluetooth integrado.
- As portas USB disponíveis não são suficientes para todos os dispositivos conectados simultaneamente.
- A conexão via Wi-Fi exige configuração de rede segura e estável.
A equipe de TI precisa:

- Analisar as interfaces de conexão de cada robô.
- Definir o tipo de conexão mais eficiente para cada atividade.
- Garantir que todos os alunos consigam usar os robôs simultaneamente sem interrupções.
A correta compreensão das interfaces será essencial para garantir a funcionalidade e o sucesso do laboratório.

###### Questões:

- Cite cinco interfaces de conexão comuns e diga qual é o seu uso principal.
- Explique, com suas palavras, a diferença entre uma interface de conexão física e uma interface sem fio. Dê exemplos de cada uma.
- Imagine que um aluno precisa enviar comandos de um notebook para um robô via Bluetooth, mas o notebook não tem essa interface. O que poderia ser feito para resolver esse problema?
- Analise os prós e contras de utilizar Wi-Fi, USB ou Bluetooth na comunicação entre o computador e um robô no laboratório da escola. Qual seria mais adequada para cada situação?
- Avalie a decisão da escola de priorizar robôs com conexão via Wi-Fi em detrimento dos conectados por USB. Essa escolha é vantajosa para um ambiente educacional? Justifique.
- Crie um plano de conexão para um laboratório de informática com 10 robôs que usam diferentes tipos de interface. Descreva como garantir que todos funcionem simultaneamente com eficiência.
