- Dispositivos usados na atualidade
- Mouse: atua como apontador de itens na tela do computador para seleção e organização. Bom para desenhos e jogos também. O padrão é ter 3 botões, mas, pode ser encontrado com mais.

Questão 1

Trabalhar com um sistema computacional envolve conhecer alguns aspectos de sua formação básica, como dispositivos de entrada e saída. Conforme visto em aula, a parte que não se integra à um sistema computacional básico é:

a) CPU.

b) Sistema de irrigação.

c) Controladores de dispositivos.

d) Adaptador gráfico.

Resposta comentada: Um sistema de irrigação, embora possa ser acionado automaticamente por um sistema eletrônico ou computacional, não é uma parte básica de um sistema computacional. CPU (Central Processing Unit), controladores de dispositivos e o adaptador gráfico compõem alguns dos principais elementos de um sistema computacional.

Questão 2

Os dispositivos conectados ao computador compartilham um canal próprio de troca de dados. As conexões estabelecidas passam a fluir seus dados de entrada e saída conforme o uso. Esse meio de comunicação é descrito como:

a) USB.

b) CPU.

c) Adaptador gráfico.

d) Barramento do Sistema.

Resposta comentada: O BUS ou Barramento do Sistema é o canal por onde fluem todos os dados de entrada e saída do sistema. Os periféricos ao terem acesso a esse canal de dados ficam à disposição para serem usados tanto para envio como recebimento de dados. USB (Universal Serial Bus) é um padrão de conexão muito usado pelos periféricos. A CPU é a unidade de processamento central que fica interna ao sistema e não a controlamos diretamente. O adaptador gráfico destina-se à conexão com um monitor de vídeo.

Resumo Explicativo:

Os periféricos são dispositivos que se conectam ao computador para expandir suas funcionalidades. Eles são classificados, de forma geral, como dispositivos de entrada, saída ou híbridos (entrada e saída). Através deles, o computador se comunica com o mundo externo, seja recebendo dados, transmitindo informações ou realizando ações físicas.

Exemplos de periféricos incluem:

Entrada: teclado, mouse, scanner, webcam

Saída: monitor, impressora, caixas de som

Entrada/Saída: pen drives, impressoras multifuncionais, headsets, telas sensíveis ao toque

No contexto do desenvolvimento de sistemas, entender como os periféricos funcionam e interagem com o sistema operacional é essencial para criar soluções compatíveis, eficientes e adaptáveis a diferentes ambientes e necessidades dos usuários.

###### Estudo de Caso:

Cenário: Uma empresa de automação comercial chamada TechPoint foi contratada para informatizar um pequeno supermercado. O objetivo é modernizar os pontos de venda (caixas) e o controle de estoque usando periféricos apropriados.

A equipe identificou que o sistema precisaria se integrar com vários periféricos, incluindo:

- Leitor de código de barras para registrar produtos
- Impressora térmica para emitir cupons fiscais
- Balança digital para pesar itens vendidos por quilo
- Teclado numérico externo para facilitar o uso pelos operadores de caixa
- Display para o cliente mostrando o valor da compra
O desafio está em:

- Escolher periféricos compatíveis com os sistemas operacionais e softwares usados.
- Garantir que todos os dispositivos funcionem em conjunto, sem conflitos.
- Criar uma interface que se adapte à variedade de periféricos e facilite a operação por funcionários com pouco domínio de informática.
A escolha correta e a integração eficiente dos periféricos são decisivas para o sucesso do projeto.

###### Questões:

- Liste cinco periféricos comuns e classifique cada um como entrada, saída ou entrada/saída.
- Explique, com suas palavras, como os periféricos contribuem para expandir as funcionalidades de um computador em diferentes contextos.
- Suponha que você foi contratado para informatizar uma farmácia. Quais periféricos você recomendaria e qual a função de cada um no sistema?
- Analise como os diferentes periféricos utilizados no supermercado do estudo de caso interagem com o sistema. Quais dados cada um fornece ou recebe e como isso impacta a operação?
- Um cliente deseja economizar e instalar apenas teclado e mouse em seu novo sistema de ponto de venda. Essa decisão atende aos objetivos de automação do negócio? Justifique sua resposta.
- Projete um sistema de autoatendimento para uma lanchonete que utiliza periféricos modernos (ex: tela touch, leitor de cartão, impressora de pedidos). Descreva o funcionamento e os periféricos envolvidos.
