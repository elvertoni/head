### Slide 11

- Software é a parte lógica de um sistema computacional. É o conjunto de instruções, escritas em linguagem de programação, que orienta o hardware sobre o que fazer e como fazer.
- Se o hardware é o corpo físico (processador, memória, teclado, tela), o software é o “roteiro de comportamento”. Ele diz ao computador como calcular, armazenar, exibir, conectar, processar.

Questão 1

A palavra hardware pode se referir também como o conjunto de equipamentos acoplados em produtos que precisam de algum tipo de processamento computacional. A ciência que estuda o hardware é conhecida como arquitetura de computadores.

DANTAS, T. Hardware e Software. Mundo educação, online. Disponível em: https://mundoeducacao.uol.com.br/informatica/hardware-software.htm. Acesso em: 20 out. 2021.

Com base nessas informações e no conteúdo estudado, pode-se dizer que o hardware corresponde à parte:

a) Lógica do computador.

b) Física do computador.

c) Burocrática do computador.

d) Substancial do computador.

Resposta comentada: O hardware se refere à parte física de computadores, uma vez que contempla um conjunto de aparatos eletrônicos que fazem o computador funcionar (alternativa B). A parte lógica do computador é denomida de software, sendo responsável pela manipulação, instrução, redirecionamento e executação das tarefas lógias do computador. Não existem partes burocráticas ou substanciais do computador.

Questão 2

Em termos práticos, o software é uma coleção de dados ou instruções que informam a um mecanismo como ele deve trabalhar. Ele nada mais é do que um programa que você acessa no celular, tablet, PC, ou qualquer outro dispositivo eletrônico.

COSTA, M. B. O que é software? Canaltech, 2020. Disponível em: https://canaltech.com.br/software/o-que-e-software/. Acesso em: 20 out. 2021.

Dito isso, podem ser considerados softwares:

a) A calculadora eletrônica, o Ábaco e a tabuladora.

b) O Windows, o Ábaco e a calculadora eletrônica.

c) O Linux, a memória de um computador e o PowerPoint.

d) O Windows, o Linux e a calculadora eletrônica.

Resposta comentada: A calculadora se trata de um software, uma vez que corrresponde a um aplicativo para a resolução de cálculos. O Ábaco é uma espécie de calculadora manual, ou seja, não requer nenhum software para o funcionar. A tabuladora, apesar de uma máquina muito antiga, pode ser considerada um software escrito em cartões perfurados. O Windows e o Linux são Sistemas Operacionais, programas que controlam as operações do computador e, portanto, são tipos de softwares. A memória é um hardware que permite a escrita e leitura de dados pelo computador. O PowerPoint é uma ferramenta utilizada para a geração de material para apresentação. Com base nestas definições, conclui-se que as alternativa A, B e C estão incorretas, e apenas a alternativa D está correta.
