Questão 1

Para estabelecer uma comunicação é necessário que o receptor e o emissor falem a mesma língua. A comunicação entre o computador e um periférico se dá por meio de uma interface. Quando nos referimos a parte dos conectores físicos, trata-se de uma interface:

a) de software.

b) de hardware.

c) USB.

d) Bluetooth.

Resposta comentada: Uma interface é um elo de interação. Para conectores físicos é do tipo hardware. Para interação com o usuário por um programa, é de tipo software. A conexão USB é apenas uma especificidade de conexão como o Bluetooth.

Questão 2

Quando adquirimos um novo equipamento, um manual também é disponibilizado para informar a correta utilização. Um dispositivo conectado a um computador necessita de um software especial para a correta utilização no sistema. Este software é o:

a) Sistema Operacional (SO).

b) HID (Human Interface Device).

c) Assistente de configuração.

d) Driver.

Resposta comentada: Para a correta utilização de um novo dispositivo é necessária a instalação de um software especializado conhecido como drive do dispositivo. O SO não reconhece todos os dispositivos. O HID é um periférico feito especialmente para ser usado por pessoal. O assistente de configuração é um software que auxilia na instalação de drivers.

###### Resumo Explicativo:

O sistema de refrigeração é fundamental para o bom funcionamento de computadores e outros equipamentos eletrônicos. Durante o uso, componentes como processadores (CPU), placas de vídeo (GPU), memória RAM e fontes de alimentação geram calor. Se esse calor não for dissipado adequadamente, pode causar lentidão, travamentos, desligamentos repentinos e até a queima de componentes.

As soluções térmicas mais comuns incluem:

- Coolers (ventoinhas): utilizam ar para dissipar calor.
- Dissipadores de calor: peças metálicas que absorvem e dispersam o calor.
- Pasta térmica: melhora o contato entre o processador e o dissipador.
- Water coolers: sistemas de resfriamento a líquido para alto desempenho.
- Refrigeração passiva: sem ventoinhas, usada em dispositivos de baixo consumo.
No desenvolvimento de sistemas, conhecer essas soluções é essencial para montar equipamentos estáveis, silenciosos e duradouros, especialmente em ambientes que exigem alto desempenho.

###### Estudo de Caso:

Cenário: Um laboratório de criação de jogos da escola técnica TechLab começou a perceber que os computadores mais potentes estavam travando ou reiniciando após algumas horas de uso. A equipe de suporte identificou que os jogos desenvolvidos exigiam processamento intenso da CPU e da GPU, elevando muito a temperatura interna dos computadores.

Ao investigar mais a fundo, notaram que:

- Alguns coolers estavam sujos ou desgastados.
- Havia máquinas sem pasta térmica aplicada corretamente.
- A ventilação do ambiente era limitada.
Com isso, a coordenação decidiu investir em melhorias no sistema de refrigeração para garantir estabilidade durante as aulas e testes de jogos.

Agora, o desafio da equipe é:

- Escolher as soluções térmicas mais apropriadas para os computadores do laboratório.
- Implementar medidas para evitar o superaquecimento no futuro.
- Monitorar a temperatura dos equipamentos e garantir sua durabilidade.

###### Questões:

- Cite três componentes internos do computador que exigem algum tipo de refrigeração e diga por que isso é necessário.
- Explique, com suas palavras, como o calor é dissipado de um processador com o uso de pasta térmica e cooler.
- Imagine que um computador do laboratório está superaquecendo. Quais etapas você seguiria para diagnosticar e resolver esse problema?
- Analise as vantagens e desvantagens de utilizar um sistema de refrigeração a ar (cooler tradicional) em comparação com um sistema de refrigeração líquida (water cooler).
- Avalie a decisão da escola de manter computadores de alto desempenho com apenas o cooler padrão que vem com o processador. Essa é uma decisão adequada para o contexto de desenvolvimento de jogos? Justifique.
- Projete um plano de refrigeração para o laboratório TechLab, considerando a instalação de novos jogos mais pesados. Indique os tipos de refrigeração, práticas de manutenção preventiva e controle de temperatura ambiente.
