### Slide 17

- Configurações do Linux Ubuntu
- Considerando aqui uma orientação para usuários comuns, as configurações no sistema operacional Linux Ubuntu serão realizadas dentro do um ambiente gráfico Unity que é muito utilizado e que será considerado para falarmos em configurações.
- Mas há outras interfaces ou ambientes gráficos que também podem ser utilizadas no Ubuntu como: Gnome, KDE, SFCE, LXDE, Cinnanon e Mate.

- ajuda no Ubuntu
- É importante que o usuário do sistema tenha acesso a informações do Ubuntu Linux e seu ícone de ajuda. Leia o manual do usuário do Ubuntu clicando no ponto de interrogação no Painel (Dock), localizado normalmente na parte superior a esquerda do sistema.

### Slide 19

- Atualização do Linux Ubuntu
- É importante manter atualizada a versão instalada do sistema operacional Ubuntu.
- Para isso, utilize o aplicativo Atualizador de Programas.
- Para acessá-lo, basta digitar Atualizador de Programas no menu de pesquisa que terá acesso a este aplicativo.
- Se aparecerem atualizações (é muito comum haver atualizações disponíveis), clique em Instalar.

_1 imagem(ns) no slide._

### Slide 20

- Configuração de idiomas do Linux Ubuntu
- Importante tarefa no Linux Ubuntu é fazer a instalação dos pacotes de idioma.
- Em Painel de Controle, procure por Região & Idioma e clique em Gerir idiomas instalados.
- Haverá uma verificação dos idiomas instalados. Você pode instalar novos idiomas ou atualizar o idioma em Português, já instalado.

_1 imagem(ns) no slide._

### Slide 21

- Configuração de endereçamento de rede
- Estas configurações são importantes para que seu sistema operacional tenha acesso à rede e à internet.
- Elas estão disponíveis em Configurações do Sistema na barra lateral do Linux Ubuntu chamada de Lançador.
- Acesse na seção Hardware o item Rede para acessar as configurações da placa de rede.

_1 imagem(ns) no slide._

### Slide 22

- Configuração de Codecs no Ubuntu Linux
- Codecs é uma sigla para Codificador/DECodificador, softwares para compactar áudio e vídeo em formato de arquivo eletrônico.
- Para instalar e configurar seu computador, abra a loja de aplicativos na barra lateral (Lançador) do sistema operacional, busque por complementos.
- Acesse a aba Codecs e clique para fazer a instalação.

_1 imagem(ns) no slide._

### Slide 23

- Configuração de Drivers no Ubuntu Linux
- Drives de hardware são softwares que controlam os hardwares de seu computador.
- Escolha Software e Atualizações dentro do item Central de Aplicativos na parte superior do sistema, no Painel (Dock), localizado normalmente na parte superior a esquerda do sistema.
- Este recurso também está disponível em Drivers de hardware dentro de Complementos que pode ser acessado escrevendo complementos no menu de pesquisa.

_1 imagem(ns) no slide._

### Slide 24

- Instalação e configuração de aplicativos extras
- O usuário também pode acessar o aplicativo de software que deseja instalar diretamente no site do fornecedor e executá-lo através de um duplo clique com o mouse no arquivo de instalação.
- Instalar softwares pode ser realizado dentro da
- Central de Software ou Central de Aplicativos.

### Slide 25

- Customizar as notificações e
- configurar backup
- Esta configuração pode ser acessada através de Configurações que podem ser acessados pela barra superior esquerda, chamada de Painel ou Dock.
- Backup é uma aplicação que irá fazer uma cópia de segurança do sistema para proteção de seus dados e aplicações em caso de falha.
- Através do item Notificações é possível verificar aplicativos de Backup dentre outras configurações que podem ser acessadas.
