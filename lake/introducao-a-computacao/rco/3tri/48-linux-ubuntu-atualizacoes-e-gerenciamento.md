### Slide 11

- Resposta
- O que são requisitos no Linux Ubuntu?
- Os requisitos para sistemas Linux Ubuntu são recursos de hardware e software para suporte à instalação e execução do sistema.
- Quais os exemplos de requisitos para o Ubuntu?
- Os requisitos de hardware são os mesmos da plataforma Windows ou das demais. Por exemplo: tipo de processador, quantidade de memória RAM necessária para execução do sistema, quantidade de espaço em disco rígido (ou memória sólida) para armazenamento do sistema operacional e sua execução, tipo de resolução do monitor de vídeo (qualidade gráfica) e tipo de placa de vídeo (que processa e controla as imagens enviadas ao monitor de vídeo).

### Slide 12

- Resposta
- Será que o sistema operacional Linux Ubuntu exige requisitos muito avançados?
- Na realidade, o sistema operacional Linux Ubuntu pode ser executado em um computador pessoal ou dispositivo móvel como smartphone ou tablet com requisitos simples, considerando os computadores atuais. O Linux, por exemplo, foi utilizado como base para criar o sistema operacional mais utilizado para smartphones, o Android.
- O sistema operacional Linux possui dois modos de utilização: o modo texto que exige poucos recursos computacionais, e o modo gráfico, que exige mais de seus requisitos de hardware.

### Slide 13

- Requisitos do Linux Ubuntu
- Ao abordar o tema de requisitos para um sistema operacional Linux Ubuntu, precisamos levar em consideração:
- Servidores de rede são sistemas computacionais mais robustos, com maior capacidade de processamento e armazenamento e necessitam de recursos mais robustos como requisitos.
- Computadores de estação de trabalho utilizados como terminais de acesso, que variam de sistemas que exigem recursos gráficos e processamento alto até sistemas muito simplificados, que apenas operam aplicações simples e requisitos mínimos.

### Slide 17

- Funcionamento do Linux Ubuntu
- O sistema operacional Linux Ubuntu é um sistema operacional que utiliza o código aberto do Linux e uma distribuição customizada chamada de Ubuntu possuindo diferentes versões.
- Foi criado para suportar e controlar computadores pessoais e dispositivos móveis modernos. Pode ser utilizado em computadores mais antigos, que apresentam requisitos mínimos de hardware, compatíveis com definições do sistema.

### Slide 19

- O Linux Ubuntu suporta dois tipos de arquitetura de processamento:
- 32 bits: arquitetura de processamento onde os processadores do computador executam os programas (processos) em 32 bits. Arquitetura utilizada por sistemas mais “antigos”.
- 64 bits: arquitetura de processamento onde os processadores do computador executam os programas (processos) em 64 bits. Arquitetura utilizada por sistemas mais “recentes”.

### Slide 20

- Processador
- O processador é o elemento do sistema computacional que realiza todo o processamento de dados codificados em linhas de programação em informações na sua tela, utilizando-se da eletrônica para converter códigos em sinais eletrônicos e informação.
- Ele é o “cérebro” do computador, que processa as informações.
- Para o Linux Ubuntu 20.04 ter performance mínima satisfatória, é necessário que o computador tenha:
- Processador de Dual core de 1 GHz (gigahertz) ou superior.

_1 imagem(ns) no slide._

### Slide 21

- Memória RAM
- Para o Linux Ubuntu 20.04 ter performance mínima satisfatória, é necessário que o computador tenha:
- Memória RAM: 1 GB para sistemas em 32 bits.
- Memória RAM: 2 GB para sistemas em 64 bits.

### Slide 22

- Espaço em disco
- Atualmente, há também computadores que utilizam a tecnologia de SSD (Solid State Driver) como memória de armazenamento.
- Para o Linux Ubuntu 20.04 ter performance mínima satisfatória, é necessário que o computador tenha
- espaço em disco rígido com 25 GB de de memória para instalação do sistema.

_1 imagem(ns) no slide._

### Slide 23

- Placa gráfica
- A placa gráfica é um dispositivo que pode estar incluída dentro da chamada placa-mãe do computador pessoal ou ser uma placa adicionada, com recursos e qualidade de processamento superiores. É a responsável pelo processamento e geração das informações que serão apresentadas em formato gráfico em um monitor de vídeo ou projetor de imagens.
- Para o Linux Ubuntu 20.04 ter performance mínima satisfatória, é necessário que o computador tenha
- placa de vídeo com 128 MB de memória dedicada.

_1 imagem(ns) no slide._

### Slide 24

- Monitor de vídeo
- O monitor de vídeo é o dispositivo computacional que irá apresentar as informações processadas pelo hardware e controladas pelo sistema operacional em formato gráfico ao usuário e permitir a interação com o sistema.
- Para o Linux Ubuntu ter performance mínima satisfatória, é necessário que o computador tenha
- Resolução mínima de 800 x 600 pixels.

_1 imagem(ns) no slide._

### Slide 25

- Linux Ubuntu: recursos mínimos
- Processador: Dual core de 2 GHz (gigahertz) ou superior.
- Memória RAM: 1 GB para sistemas em 32 bits e 2 GB para sistemas em 64 bits.
- Espaço em disco rígido: 25 GB de espaço de memória para instalação do sistema.
- Monitor de vídeo: monitor com resolução de 800 x 600 pixels ou superior.
- Placa gráfica: placa de vídeo com 128 MB de memória dedicada.
- Unidade de DVD ou porta USB para a leitura dos arquivos fonte ou acesso à internet para download do pacote de instalação.
