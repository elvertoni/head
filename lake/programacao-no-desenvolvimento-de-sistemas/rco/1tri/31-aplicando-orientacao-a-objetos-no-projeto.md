### Slide 11

- DESENVOLVIMENTO DE SISTEMAS
- Fundamentos da Orientação a Objetos
- Os fundamentos da orientação a objetos incluem a criação de classes que definem os atributos e métodos necessários para os objetos.
- Uma classe funciona como um blueprint para criar instâncias (objetos), cada uma com seu próprio estado definido pelos valores de seus atributos. Este conceito ajuda na organização do código e na implementação de funcionalidades de maneira lógica e agrupada.

### Slide 12

- DESENVOLVIMENTO DE SISTEMAS
- Conceitos em Orientação a Objetos
- Esses conceitos são fundamentais para a construção de sistemas flexíveis e escaláveis.
- Conceitos avançados como encapsulamento, herança e polimorfismo permitem uma maior abstração e reutilização de código.
- Encapsulamento: esconde os detalhes internos do funcionamento dos objetos
- Herança: permite a criação de novas classes baseadas em classes existentes
- Polimorfismo: possibilita que diferentes objetos sejam tratados de maneira uniforme através de uma interface comum.

Questão 1

Qual método é recomendado para verificar se uma variável é None em Python?

A) is None

B) == None

C) === None

D) equals(None)

Resposta correta: A) is None

Comentários: O operador is é usado para verificar identidade em Python, sendo a forma recomendada para testar se uma variável é None.

Questão 2

O que significa a palavra-chave None em Python?

A) Um tipo de dado especial indicando ausência de valor

B) Um erro no código

C) Um valor numérico zero

D) Uma string vazia

Resposta correta: A) Um tipo de dado especial indicando ausência de valor

Comentários: None é usado para representar a ausência de valor ou um valor nulo em Python.

class Car:

def __init__(self, model, color):

self.model = model

self.color = color

self.is_running = False # Estado inicial do carro, não está em funcionamento

def start(self):

"""Método para iniciar o carro"""

if not self.is_running:

self.is_running = True

print(f'O {self.model} está agora em funcionamento.')

else:

print(f'O {self.model} já está em funcionamento.')

def stop(self):

"""Método para parar o carro"""

if self.is_running:

self.is_running = False

print(f'O {self.model} foi desligado.')

else:

print(f'O {self.model} já está desligado.')

# Criando uma instância da classe Car

meu_carro = Car('Ford Mustang', 'vermelho')

# Operações com o carro

meu_carro.start() # Inicia o carro

meu_carro.stop() # Para o carro
