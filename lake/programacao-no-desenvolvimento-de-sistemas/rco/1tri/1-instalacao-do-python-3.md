- Configuração do PATH

Questão 1

Qual comando é utilizado para verificar se o Python está instalado em um sistema operacional Windows?

a) python --version

b) python -v

c) check python

d) install python

Resposta correta: a) python --version

Comentário: O comando python --version é usado para verificar a versão do Python instalada, confirmando assim sua instalação no sistema.

Questão 2

Ao instalar o Python, qual opção deve ser marcada para adicionar o Python ao PATH do sistema?

a) Add Python to Start Menu

b) Install launcher for all users

c) Add Python to PATH

d) Customize installation

Resposta correta: c) Add Python to PATH

Comentário: Marcar a opção "Add Python to PATH" durante a instalação permite que o Python seja executado de qualquer local no terminal ou prompt de comando.
