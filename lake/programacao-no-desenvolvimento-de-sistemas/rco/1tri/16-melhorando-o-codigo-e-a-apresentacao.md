Questão 1

Qual é a principal vantagem de organizar o código em funções?

a) Aumentar a complexidade do código.

b) Permitir a execução mais rápida do programa.

c) Facilitar a manutenção e a reutilização do código.

d) Restringir o acesso aos dados do programa.

Resposta Correta: c) Facilitar a manutenção e a reutilização do código.

Comentário: Organizar o código em funções torna o programa mais modular, permitindo que partes do código sejam reutilizadas em diferentes contextos. Além disso, a manutenção se torna mais simples, pois alterações em uma função específica não afetam diretamente outras partes do programa.

Questão 2

O que significa refatorar um código?

a) Reduzir a quantidade de funções para simplificar o código.

b) Modificar o código para melhorar a estrutura e a clareza sem alterar seu comportamento.

c) Converter todo o código em uma única função para aumentar a eficiência.

d) Escrever o código em uma nova linguagem de programação.

Resposta Correta: b) Modificar o código para melhorar a estrutura e a clareza sem alterar seu comportamento.

Comentário: Refatorar um código envolve revisar e modificar a estrutura interna do software para torná-lo mais entendível e menos complexo, sem mudar o comportamento externo do programa. Isso facilita a manutenção e a expansão futuras do código.
