Questão 1

Qual estratégia pode ser usada para implementar diferentes níveis de dificuldade em um jogo de adivinhação?

a) Alterar o intervalo do número aleatório

b) Mudar a cor do fundo do jogo

c) Aumentar o número de tentativas

d) Tocar músicas diferentes

Resposta correta: a) Alterar o intervalo do número aleatório

Comentário: Alterar o intervalo do número aleatório (por exemplo, de 1-10 para 1-100) é uma maneira eficaz de ajustar a dificuldade.

Questão 2

Como um sistema de pontuação pode ser implementado em um jogo de adivinhação?

a) Atribuir pontos por cada tentativa correta

b) Dar pontos baseados no tempo gasto

c) Reduzir pontos a cada tentativa errada

d) Todas as opções acima

Resposta correta: d) Todas as opções acima

Comentário: Um sistema de pontuação pode ser baseado em acertos, tempo ou número de tentativas, para tornar o jogo mais desafiador e envolvente.

Exemplo 1: jogo de adivinhação em Python, agora com a implementação de diferentes níveis de dificuldade e um sistema de pontuação.

import random

def jogar_adivinhacao():

nivel = int(input("Escolha o nível de dificuldade (1- Fácil, 2- Médio, 3- Difícil): "))

max_numero = 10 if nivel == 1 else 50 if nivel == 2 else 100

numero_secreto = random.randint(1, max_numero)

tentativas = 10 if nivel == 1 else 5 if nivel == 2 else 3

pontos = 1000

print(f"Jogo de Adivinhação - Nível {nivel}")

print(f"Tente adivinhar o número que estou pensando, entre 1 e {max_numero}.")

for tentativa in range(1, tentativas + 1):

print(f"Tentativa {tentativa} de {tentativas}")

palpite = int(input("Digite seu palpite: "))

if palpite < 1 or palpite > max_numero:

print(f"Digite um número entre 1 e {max_numero}.")

continue

acertou = palpite == numero_secreto

maior = palpite > numero_secreto

menor = palpite < numero_secreto

if acertou:

print(f"Você acertou e fez {pontos} pontos!")

break

else:

pontos_perdidos = abs(numero_secreto - palpite)

pontos -= pontos_perdidos

if maior:

print("Seu palpite foi maior do que o número secreto.")

elif menor:

print("Seu palpite foi menor do que o número secreto.")

if not acertou:

print(f"Suas tentativas acabaram. O número secreto era {numero_secreto}.")

print("Fim do jogo!")

if __name__ == "__main__":

jogar_adivinhacao()
