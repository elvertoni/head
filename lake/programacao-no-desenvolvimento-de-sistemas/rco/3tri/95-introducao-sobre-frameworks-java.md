### Slide 8

- DESENVOLVIMENTO DE SISTEMAS
- Resposta
- O Hibernate é um dos frameworks mais recomendados, pois simplifica a conexão com bancos relacionais e facilita o mapeamento entre as classes Java e as tabelas do banco de dados. Além disso, o Hibernate automatiza operações de CRUD (Create, Read, Update, Delete) com suas funções de persistência.

### Slide 9

- DESENVOLVIMENTO DE SISTEMAS
- Frameworks
- Frameworks Java são bibliotecas que oferecem suporte para o desenvolvimento de aplicativos, com funcionalidades prontas que economizam tempo e esforço. Eles ajudam a estruturar o código, oferecendo soluções para mapeamento de dados, gerenciamento de dependências e criação de interfaces.

_4 imagem(ns) no slide._

### Slide 10

- DESENVOLVIMENTO DE SISTEMAS
- Definição e Aplicação
- Frameworks Java podem ser classificados em duas categorias principais:
- Frameworks de Backend: como Spring, Hibernate e Jakarta EE, que oferecem suporte para persistência de dados, segurança e integração com bancos.
- Frameworks de Frontend: como JavaFX e Vaadin, que ajudam a criar interfaces visuais interativas.

_4 imagem(ns) no slide._

### Slide 11

- DESENVOLVIMENTO DE SISTEMAS
- Importância
- O uso de frameworks permite a padronização do código, aumenta a produtividade e simplifica tarefas complexas, como manipulação de banco de dados e comunicação entre serviços. Isso garante um desenvolvimento mais rápido e com menos erros.

Questão 1

Qual desses frameworks Java é especializado em persistência de dados?

A) Hibernate

B) Vaadin

C) JUnit

D) Mockito

Resposta:

A) Hibernate.

Explicação: O Hibernate é um framework de mapeamento objeto-relacional que facilita a persistência e recuperação de dados em bancos de dados relacionais.

Questão 2

Qual ferramenta é usada para construir interfaces visuais em Java?

A) Spring

B) Hibernate

C) JavaFX

D) Maven

Resposta:

C) JavaFX.

Explicação: JavaFX é uma biblioteca Java usada para criar interfaces gráficas ricas e interativas para aplicativos desktop.
