### Slide 9

- DESENVOLVIMENTO DE SISTEMAS
- Visão Geral
- A manutenção dos dados de clientes em uma aplicação é essencial para garantir que as informações estejam sempre corretas e organizadas. Isso envolve a recuperação de dados, limpeza de formulários e armazenamento seguro das informações.

### Slide 10

- DESENVOLVIMENTO DE SISTEMAS
- Definição e Aplicação
- A manutenção de dados inclui operações como adicionar, editar, excluir e recuperar informações de clientes. Aplicações Windows Forms utilizam métodos para manipular formulários e interagir com bases de dados para realizar essas operações.

### Slide 11

- DESENVOLVIMENTO DE SISTEMAS
- Importância
- Manter os dados dos clientes atualizados e bem organizados é crucial para a eficiência de uma aplicação, além de melhorar a experiência do usuário e garantir que as operações comerciais sejam realizadas sem erros.

Questão 1

Qual das opções abaixo não faz parte da lógica de salvar dados?

A) Validar os dados do cliente.

B) Mostrar uma mensagem de erro se os dados estiverem incorretos.

C) Preencher o formulário com dados aleatórios.

D) Salvar os dados no banco de dados.

Resposta Correta: C) Preencher o formulário com dados aleatórios.

Questão 2

O que deve ser feito após salvar os dados do cliente?

A) Fechar a aplicação.

B) Limpar o formulário.

C) Exibir uma mensagem de erro.

D) Recarregar os dados JSON.

Resposta Correta: B) Limpar o formulário.
