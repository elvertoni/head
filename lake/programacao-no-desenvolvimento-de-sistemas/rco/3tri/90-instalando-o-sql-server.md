### Slide 9

- DESENVOLVIMENTO DE SISTEMAS
- O SQL Server é um sistema de gerenciamento de banco de dados relacional (RDBMS) que oferece uma maneira poderosa de gerenciar dados. O SQL Server Management Studio (SSMS) é a interface gráfica que simplifica a administração desses dados.

Questão 1

O que é necessário instalar para gerenciar um banco de dados SQL no Windows Forms?

A) Microsoft Word

B) SQL Server e SSMS

C) Windows Media Player

D) Microsoft Excel

Resposta Correta: B

Explicação: O SQL Server é necessário para gerenciar dados, e o SSMS facilita a administração do banco de dados.

Questão 2

Qual das seguintes opções é uma boa prática ao criar um banco de dados?

A) Manter todas as tabelas no mesmo arquivo de texto

B) Usar nomes de tabelas claros e descritivos

C) Não se preocupar com a segurança

D) Armazenar todos os dados em uma única coluna

Resposta Correta: B

Explicação: Usar nomes de tabelas claros facilita a manutenção e a compreensão do banco de dados.
