### Slide 9

- DESENVOLVIMENTO DE SISTEMAS
- DataGridView
- O DataGridView é um componente do Windows Forms que permite a exibição de tabelas de dados, oferecendo uma interface de usuário rica e interativa. Ele é amplamente utilizado para visualizar e manipular grandes volumes de dados de forma organizada.

- O DataGridView é uma ferramenta visual que possibilita a exibição de dados em formato de tabela dentro de um formulário. Além de mostrar informações, ele permite a inclusão, edição e exclusão de registros.

Questão 1

Qual método é usado para vincular uma lista de dados ao DataGridView?

A) DataSource

B) Items.Add

C) RowInsert

D) SetData

Resposta Correta: A. O DataSource vincula diretamente uma lista ou DataTable ao DataGridView.

Questão 2

Qual propriedade define se o usuário pode editar as células no DataGridView?

A) AllowUserToDeleteRows

B) ReadOnly

C) EditMode

D) Columns

Resposta Correta: B. A propriedade ReadOnly define se as células podem ou não ser editadas pelo usuário.
