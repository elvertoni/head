Questão 1

Qual método é utilizado para exibir uma caixa de mensagem em Windows Forms?

A) ShowDialog

B) DisplayMessage

C) MessageBox.Show

D) ShowMessageBox

Resposta: C) MessageBox.Show. Este método exibe uma caixa de mensagem na tela.

Questão 2

O que acontece quando você chama Application.Run(new MainForm()) no método Main?

A) Cria uma nova instância de MainForm e a exibe.

B) Fecha a aplicação imediatamente.

C) Inicia o loop de mensagens do aplicativo e exibe MainForm.

D) Nenhuma das anteriores.

Resposta: C) Inicia o loop de mensagens do aplicativo e exibe MainForm. Este comando inicia a aplicação e exibe o formulário principal.
