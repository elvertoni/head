Questão 1

Qual é a principal diferença entre os métodos sort() e sorted() em Python?

A) sort() ordena a lista no local, enquanto sorted() retorna uma nova lista ordenada.

B) sort() só funciona com números, enquanto sorted() funciona com strings.

C) sort() é mais lento que sorted().

D) sort() cria uma cópia da lista antes de ordenar.

Resposta correta: A) sort() ordena a lista no local, enquanto sorted() retorna uma nova lista ordenada.

Comentário: sort() modifica a lista original, enquanto sorted() retorna uma nova lista sem modificar a original.

Questão 2

Como você pode ordenar uma lista de números em ordem decrescente usando sort()?

A) Usando o argumento reverse=True no método sort().

B) Usando o argumento descending=True no método sort().

C) Usando o método sorted().

D) Adicionando reverse=False no método sort().

Resposta correta: A) Usando o argumento reverse=True no método sort().

Comentário: O argumento reverse=True faz com que o método sort() ordene a lista em ordem decrescente.

Resumo Explicativo:

A ordem natural em Python refere-se à forma padrão de organizar elementos, como ordenar strings alfabeticamente e números de forma crescente. Ordenar dados é uma operação essencial na programação, pois facilita a busca, análise e apresentação de informações de maneira lógica e estruturada. Python oferece métodos e funções integradas, como sort() e sorted(), que simplificam a tarefa de ordenar coleções de dados.

Estudo de Caso:

Imagine que você é um desenvolvedor responsável por criar um sistema de gerenciamento de biblioteca escolar. O sistema precisa organizar livros por título e autores por sobrenome, além de ordenar listas de números como códigos de livro e datas de publicação.

Exemplo de código:

# Ordenando uma lista de títulos de livros

titulos_livros = ["O Apanhador no Campo de Centeio", "1984", "Orgulho e Preconceito", "Dom Quixote"]

titulos_livros.sort()

print("Títulos ordenados:", titulos_livros)

# Ordenando uma lista de sobrenomes de autores

autores = ["Orwell", "Salinger", "Austen", "Cervantes"]

autores.sort()

print("Autores ordenados:", autores)

# Ordenando uma lista de datas de publicação

datas_publicacao = [1951, 1949, 1813, 1605]

datas_publicacao_ordenadas = sorted(datas_publicacao)

print("Datas de publicação ordenadas:", datas_publicacao_ordenadas)

Questões:

1- Liste dois métodos usados para ordenar listas em Python.

Resposta esperada: Os métodos são sort() e sorted().

2-Explique a diferença entre os métodos sort() e sorted() em Python.

Resposta esperada: O método sort() ordena a lista no local, modificando a lista original. O método sorted() retorna uma nova lista ordenada sem modificar a lista original.

3- Dado uma lista de números [3, 1, 4, 1, 5, 9, 2], use o método adequado para ordená-la em ordem crescente e imprima o resultado.

*Resposta esperada:*

numeros = [3, 1, 4, 1, 5, 9, 2]

numeros_ordenados = sorted(numeros)

print("Números ordenados:", numeros_ordenados)

4- Identifique as partes do código de exemplo que usam sort() e sorted(). Explique como cada uma contribui para a ordenação dos dados.

Resposta esperada:

sort() é usado para ordenar a lista titulos_livros e autores no local. sorted() é usado para criar uma nova lista ordenada datas_publicacao_ordenadas a partir da lista datas_publicacao, sem modificar a original.

5- Avalie a importância de usar métodos de ordenação em sistemas de gerenciamento de dados. Justifique sua resposta com exemplos práticos.

Resposta esperada: Métodos de ordenação são cruciais em sistemas de gerenciamento de dados para garantir que a informação esteja estruturada de maneira lógica. Isso facilita a busca e análise de dados, como encontrar um livro específico em uma lista ordenada por título ou autor.

6- Desenvolva um código que ordene uma lista de alunos por nome e, em seguida, por nota em ordem decrescente. Utilize sort() para ordenar a lista de nomes e sorted() para ordenar as notas.
