Questão 1

O que ocorre quando o método MessageBox.Show() é chamado?

A) Nada

B) Uma caixa de diálogo é exibida

C) Um novo formulário é aberto

D) O programa é encerrado

Resposta correta: B - MessageBox.Show() exibe uma caixa de diálogo com uma mensagem para o usuário.

Questão 2

Como você pode verificar se um campo de entrada está vazio antes de processar a informação?

A) Usando string.IsNullOrWhiteSpace(campo)

B) Usando campo == null

C) Usando campo.Clear()

D) Usando campo.Length > 0

Resposta correta: A - string.IsNullOrWhiteSpace(campo) verifica se o campo é nulo, vazio ou contém apenas espaços em branco.
