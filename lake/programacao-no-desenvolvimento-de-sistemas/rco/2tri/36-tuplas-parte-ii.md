Questão 1

O que é "anemia" em termos de objetos em Python?

A) Objetos que não podem ser modificados

B) Objetos que apenas contêm dados sem comportamento

C) Objetos que têm métodos, mas nenhum dado

D) Objetos que ocupam menos memória

Resposta correta: B) Objetos que apenas contêm dados sem comportamento

Comentários sobre a resposta correta: A anemia de objetos refere-se a instâncias que armazenam dados sem métodos próprios, geralmente usadas para dados estruturados.

Questão 2

Como você cria uma lista de tuplas em Python?

A) list((1, 2), (3, 4))

B) [(1, 2), (3, 4)]

C) {1, 2, 3, 4}

D) [(1, 2), {3, 4}]

Resposta correta: B) [(1, 2), (3, 4)]

Comentários sobre a resposta correta: Uma lista de tuplas é criada utilizando colchetes para a lista e parênteses para as tuplas, como em [(1, 2), (3, 4)].

Exemplo prático:

# Definindo uma tupla para armazenar informações imutáveis de um produto

produto_info = ("ID123", "Notebook", "Eletrônicos")

# Definindo uma classe Produto para atributos mutáveis

class Produto:

def __init__(self, preco, quantidade):

self.preco = preco

self.quantidade = quantidade

# Criando uma lista de produtos

produtos = [

(produto_info, Produto(2500.00, 10)),

(("ID124", "Mouse", "Eletrônicos"), Produto(150.00, 50))

]

# Acessando dados

for info, produto in produtos:

print(f"Produto: {info[1]}, Categoria: {info[2]}, Preço: {produto.preco}, Quantidade: {produto.quantidade}")

Este exemplo demonstra como combinar tuplas e objetos para criar um sistema de gestão de produtos eficiente, integrando dados imutáveis e mutáveis.
