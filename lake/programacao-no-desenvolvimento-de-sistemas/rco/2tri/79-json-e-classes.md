Questão 1

O que deve ser feito para transformar uma string JSON em uma classe em C#?

A) Convertê-la manualmente

B) Usar a função ConvertJsonToObject

C) Utilizar a função JsonConvert.DeserializeObject<T>

D) Usar uma biblioteca externa

Explicação: A resposta correta é C. A função JsonConvert.DeserializeObject<T> é usada para converter uma string JSON em um objeto do tipo especificado.

Questão 2

Por que é importante validar o JSON recebido de uma API antes de utilizá-lo na aplicação?

A) Para garantir que os dados são precisos

B) Para evitar que a aplicação trave

C) Para impedir a entrada de dados inválidos

D) Todas as anteriores

Explicação: A resposta correta é D. A validação assegura que os dados são precisos, protege contra falhas na aplicação e mantém a integridade dos dados.
