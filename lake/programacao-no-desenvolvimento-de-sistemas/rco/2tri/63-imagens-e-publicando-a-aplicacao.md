### Slide 7

- DESENVOLVIMENTO DE SISTEMAS
- Para pensarmos juntos!
- Duas Soluções Possíveis:
- Clara pode usar imagens de alta qualidade e ícones consistentes, assegurando que eles sejam licenciados para uso comercial. Para a publicação, ela pode usar o ClickOnce, uma ferramenta simples integrada ao Visual Studio.
- Clara decide usar imagens e ícones de fontes variadas e sem verificar a licença, o que pode resultar em problemas de direitos autorais. Para publicar, ela considera apenas enviar o executável para os usuários sem um processo de instalação adequado.
- Quem sabe responde!

_4 imagem(ns) no slide._

### Slide 8

- DESENVOLVIMENTO DE SISTEMAS
- Resposta
- A primeira solução é correta, pois garante uma interface de usuário profissional e segura, além de usar métodos adequados para publicação, assegurando que o software funcione corretamente em diferentes computadores.
- A segunda solução é incorreta, pois não considera os aspectos legais e técnicos importantes, como direitos autorais e a garantia de que todos os componentes necessários serão instalados corretamente.

Questão 1

Qual é a melhor prática ao adicionar ícones a uma aplicação?

A) Usar ícones de diferentes tamanhos e estilos

B) Usar ícones de uma biblioteca com licença adequada

C) Evitar o uso de ícones para manter a simplicidade

D) Criar ícones manualmente para todas as funções

Resposta: B) Usar ícones de uma biblioteca com licença adequada

Questão 2

Qual ferramenta do Visual Studio é recomendada para a publicação de uma aplicação Windows Forms?

A) XAML Publisher

B) ClickOnce

C) GitHub Actions

D) IIS

Resposta: B) ClickOnce
