Questão 1

Qual das opções abaixo é usada para exibir uma caixa de diálogo que solicita confirmação ao usuário?

A) OpenFileDialog

B) SaveFileDialog

C) MessageBox

D) ColorDialog

Resposta Correta: C

Comentário: A classe MessageBox é usada para exibir caixas de diálogo que solicitam confirmação ao usuário, entre outras funcionalidades como exibir mensagens de informação ou alerta.

Questão 2

Qual é o método correto para exibir uma MessageBox com um botão "OK" e um título "Informação"?

A) MessageBox.Show("Informação", "Esta é uma mensagem.", MessageBoxButtons.OK);

B) MessageBox.Show("Esta é uma mensagem.", "Informação", MessageBoxButtons.OK);

C) MessageBox.Display("Esta é uma mensagem.", "Informação", MessageBoxButtons.OK);

D) MessageBox.Display("Informação", "Esta é uma mensagem.", MessageBoxButtons.OK);

Resposta Correta: B

Comentário: O método MessageBox.Show é usado para exibir uma MessageBox. O primeiro parâmetro é a mensagem, o segundo é o título, e o terceiro define os botões a serem exibidos.
