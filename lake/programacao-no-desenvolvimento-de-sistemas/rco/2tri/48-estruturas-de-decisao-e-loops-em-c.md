Questão 1

Qual é a diferença entre for e while loops em C?

A) for é usado para loops infinitos, while para loops finitos.

B) for é usado quando o número de iterações é conhecido, while é usado quando não é.

C) for é mais eficiente que while.

D) while é usado para loops aninhados.

Resposta Correta: B) for é usado quando o número de iterações é conhecido, while é usado quando não é.

Comentário: for loops são frequentemente usados quando o número de iterações é conhecido antecipadamente, enquanto while loops são mais apropriados quando as iterações dependem de uma condição dinâmica.

Questão 2

Qual loop você usaria para garantir que o bloco de código execute pelo menos uma vez?

A) for

B) while

C) do-while

D) foreach

Resposta Correta: C) do-while

Comentário: O loop do-while garante que o bloco de código seja executado pelo menos uma vez, pois a condição é verificada após a execução do bloco.

Resumo Explicativo:

Estruturas de decisão e loops são fundamentais na programação em C. As estruturas de decisão, como if, else if, else e switch, permitem que o programa tome diferentes ações com base em condições específicas. Os loops, como for, while e do-while, permitem a execução repetitiva de um bloco de código enquanto uma condição é verdadeira. Essas estruturas são essenciais para criar programas dinâmicos e interativos, facilitando o controle de fluxo e a repetição de tarefas.

Estudo de Caso:

Imagine que você está desenvolvendo um sistema de biblioteca em C. Você precisa implementar uma função que classifique livros em categorias e outra função que liste os livros de cada categoria repetidamente até que todos os livros sejam exibidos. O sistema deve permitir ao usuário escolher uma categoria e listar os livros dessa categoria.

João está trabalhando em uma função que lê uma linha de texto do usuário e a armazena em memória dinâmica. Ele também precisa implementar funções para concatenar duas strings e liberar a memória alocada após o uso. João sabe que um gerenciamento inadequado da memória pode levar a vazamentos de memória, enquanto uma manipulação inadequada de strings pode causar erros de segmentação.

Questões:

1- Liste e descreva brevemente as principais estruturas de decisão em C.

Resposta Esperada: As principais estruturas de decisão em C são if, else if, else e switch. O if avalia uma condição e executa um bloco de código se a condição for verdadeira. O else if e else são usados para avaliar condições adicionais. O switch avalia uma expressão e executa o bloco de código correspondente ao valor da expressão.

2- Explique, com suas próprias palavras, como funciona um loop for em C.

Resposta Esperada: O loop for em C é usado para repetir um bloco de código um número específico de vezes. Ele consiste de três partes: inicialização, condição e incremento. A inicialização define a variável de controle do loop, a condição é avaliada antes de cada iteração e, se verdadeira, o bloco de código é executado. O incremento ajusta a variável de controle após cada iteração.

3- Escreva um programa em C que utilize um switch para classificar livros em categorias e um loop for para listar os livros de uma categoria escolhida pelo usuário.

#include <stdio.h>

int main() {

int categoria;

printf("Digite a categoria do livro (1-5): ");

scanf("%d", &categoria);

switch(categoria) {

case 1:

printf("Categoria: Ficção\n");

break;

case 2:

printf("Categoria: Não-ficção\n");

break;

case 3:

printf("Categoria: Biografia\n");

break;

case 4:

printf("Categoria: Tecnologia\n");

break;

case 5:

printf("Categoria: Arte\n");

break;

default:

printf("Categoria inválida\n");

}

printf("Listando livros da categoria %d:\n", categoria);

for (int i = 1; i <= 5; i++) {

printf("Livro %d da categoria %d\n", i, categoria);

}

return 0;

}

4- Identifique e explique as partes componentes de um loop while em C e como ele se relaciona com um loop for.

Resposta Esperada: Um loop while em C repete um bloco de código enquanto uma condição é verdadeira. Ele possui uma condição que é avaliada antes de cada iteração. Se a condição for verdadeira, o bloco de código é executado. Comparado a um loop for, o while é mais flexível, pois não possui inicialização e incremento embutidos na estrutura do loop. A inicialização deve ser feita antes do loop e o incremento dentro do bloco de código do loop.

5- Avalie a eficácia de usar um switch em vez de múltiplos if-else para decidir a categoria de um livro. Justifique sua resposta.

Resposta Esperada: Usar um switch pode ser mais eficaz que múltiplos if-else quando se trata de avaliar uma única variável contra vários valores constantes. Isso porque o switch é mais legível e pode ser mais eficiente em termos de execução, já que o compilador pode otimizar o switch melhor do que uma série de if-else aninhados.

6- Desenvolva um programa que use estruturas de decisão e loops para implementar um menu interativo de biblioteca. O programa deve permitir ao usuário adicionar livros a uma categoria, listar livros de uma categoria e sair do programa.

#include <stdio.h>

#include <string.h>

#define MAX_LIVROS 100

typedef struct {

char titulo[100];

int categoria;

} Livro;

Livro biblioteca[MAX_LIVROS];

int contador = 0;

void adicionar_livro(char* titulo, int categoria) {

strcpy(biblioteca[contador].titulo, titulo);

biblioteca[contador].categoria = categoria;

contador++;

}

void listar_livros(int categoria) {

printf("Listando livros da categoria %d:\n", categoria);

for (int i = 0; i < contador; i++) {

if (biblioteca[i].categoria == categoria) {

printf("Livro: %s\n", biblioteca[i].titulo);

}

}

}

int main() {

int opcao, categoria;

char titulo[100];

while (1) {

printf("Menu:\n");

printf("1. Adicionar Livro\n");

printf("2. Listar Livros\n");

printf("3. Sair\n");

printf("Escolha uma opção: ");

scanf("%d", &opcao);

switch (opcao) {

case 1:

printf("Digite o título do livro: ");

scanf("%s", titulo);

printf("Digite a categoria do livro (1-5): ");

scanf("%d", &categoria);

adicionar_livro(titulo, categoria);

break;

case 2:

printf("Digite a categoria dos livros para listar (1-5): ");

scanf("%d", &categoria);

listar_livros(categoria);

break;

case 3:

return 0;

default:

printf("Opção inválida!\n");

}

}

return 0;

}
