### Slide 10

- DESENVOLVIMENTO DE SISTEMAS
- Definição e Aplicação
- O cadastro de clientes se refere à prática de inserir e manter registros de clientes em um banco de dados. Isso é feito por meio de formulários, onde os usuários inserem dados que são processados e armazenados para uso posterior.

- DESENVOLVIMENTO DE SISTEMAS
- Importância
- Ter um sistema de cadastro de clientes eficiente é essencial para a gestão de relacionamento com o cliente (CRM), marketing e atendimento ao cliente. Isso garante que as informações dos clientes estejam organizadas e acessíveis.

Questão 1

O que deve ser feito primeiro ao criar um formulário de cadastro de clientes?

A) Adicionar um menu flutuante

B) Organizar os campos de entrada de dados

C) Criar uma tabela no banco de dados

D) Implementar a função de pesquisa

Resposta correta: B. A organização dos campos de entrada de dados é o primeiro passo na criação de um formulário de cadastro de clientes.

Questão 2

Qual é a principal vantagem de usar um sistema de cadastro de clientes?

A) Simplifica o design do sistema

B) Facilita a organização e o acesso às informações dos clientes

C) Diminui a quantidade de dados armazenados

D) Elimina a necessidade de validação dos dados

Resposta correta: B. Um sistema de cadastro de clientes facilita a organização e o acesso às informações essenciais dos clientes.
