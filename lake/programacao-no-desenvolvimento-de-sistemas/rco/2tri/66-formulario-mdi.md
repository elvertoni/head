- Definição e Aplicação
- MDI (Multiple Document Interface) é um padrão de interface de usuário que permite gerenciar múltiplas janelas dentro de uma única janela principal. É amplamente utilizado em aplicativos como sistemas de gerenciamento e editores de texto.

Questão 1

Questão: Qual método é utilizado para definir um formulário como pai de outros formulários em um aplicativo MDI?

A) this.SetParentForm

B) this.IsMdiContainer

C) this.AddChildForm

D) this.MdiParent

Resposta: B) this.IsMdiContainer

Comentário: O método this.IsMdiContainer = true é utilizado para definir um formulário como contêiner pai de outros formulários no modelo MDI. Este é um passo crucial para organizar formulários filhos dentro de um único formulário principal.

Questão 2

Questão: Como você cria e exibe um novo formulário filho dentro de um formulário MDI em C#?

A) Form childForm = new Form(); childForm.Show();

B) Form childForm = new Form(); childForm.MdiParent = this; childForm.Show();

C) Form childForm = new Form(); this.Add(childForm); childForm.Show();

D) Form childForm = new Form(); childForm.SetParentForm(this); childForm.Show();

Resposta: B) Form childForm = new Form(); childForm.MdiParent = this; childForm.Show();

Comentário: Para criar e exibir um novo formulário filho dentro de um formulário MDI, é necessário definir o formulário pai utilizando a propriedade MdiParent e, em seguida, chamar o método Show() para exibir o formulário filho.
