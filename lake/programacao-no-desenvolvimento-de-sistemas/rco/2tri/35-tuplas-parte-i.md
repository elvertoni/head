### Slide 10

- DESENVOLVIMENTO DE SISTEMAS
- Entendendo Tuplas
- Tuplas são estruturas de dados imutáveis em Python que podem armazenar múltiplos itens em uma única variável. São semelhantes às listas, mas, ao contrário destas, não podem ser modificadas após a criação, garantindo a integridade dos dados.

_3 imagem(ns) no slide._

### Slide 11

- DESENVOLVIMENTO DE SISTEMAS
- Utilização de Tuplas em Diferentes Contextos
- Tuplas são definidas usando parênteses (), e podem armazenar diferentes tipos de dados. São usadas quando a imutabilidade é necessária, como em constantes ou dados que não devem ser alterados após a criação, como coordenadas geográficas ou configurações de sistema.

Questão 1

Qual método pode ser usado para encontrar o índice de um elemento em uma tupla?

A) find()

B) index()

C) locate()

D) search()

Resposta correta: B) index()

Comentários sobre a resposta correta: O método index() retorna a posição do primeiro elemento encontrado que corresponde ao valor especificado.

Questão 2

Qual é uma das principais diferenças entre tuplas e listas em Python?

A) Tuplas são imutáveis, enquanto listas são mutáveis.

B) Tuplas podem conter apenas um tipo de dado.

C) Listas são mais rápidas que tuplas.

D) Tuplas são definidas com colchetes.

Resposta correta: A) Tuplas são imutáveis, enquanto listas são mutáveis.

Comentários sobre a resposta correta: Tuplas não podem ser modificadas após a criação, ao contrário das listas, que podem ser alteradas.

Exemplo prático:

# Definindo uma tupla para armazenar informações de um livro

livro = ("1984", "George Orwell", 1949)

print(livro)

# Definindo uma classe Livro e armazenando objetos em uma lista

class Livro:

def __init__(self, titulo, autor, ano):

self.titulo = titulo

self.autor = autor

self.ano = ano

livros = [

Livro("1984", "George Orwell", 1949),

Livro("O Senhor dos Anéis", "J.R.R. Tolkien", 1954)

]

for livro in livros:

print(f"{livro.titulo}, por {livro.autor} ({livro.ano})")

Este exemplo mostra como definir uma tupla e uma lista de objetos de classe, destacando a diferença entre a imutabilidade das tuplas e a flexibilidade das listas.
