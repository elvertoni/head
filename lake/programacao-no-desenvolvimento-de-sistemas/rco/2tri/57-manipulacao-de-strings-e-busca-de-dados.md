### Slide 8

- DESENVOLVIMENTO DE SISTEMAS
- Resposta
- Em C, strings são manipuladas usando funções específicas da biblioteca <string.h>.
- Usar strcpy e strcmp permite manipular e comparar strings corretamente.
- Comparar strings diretamente com == compara os ponteiros, não o conteúdo das strings, levando a resultados incorretos!

Questão 1

Qual função é usada para comparar duas strings em C?

A) strcmp

B) strcpy

C) strlen

D) strcat

Resposta: A) strcmp

Comentário: A função strcmp compara duas strings e retorna 0 se elas são iguais.

Questão 2

O que faz a função fgets em C?

A) Lê uma string do teclado.

B) Copia uma string.

C) Compara duas strings.

D) Calcula o tamanho de uma string.

Resposta: A) Lê uma string do teclado.

Comentário: fgets lê uma linha de texto do teclado, incluindo o caractere de nova linha \n.
