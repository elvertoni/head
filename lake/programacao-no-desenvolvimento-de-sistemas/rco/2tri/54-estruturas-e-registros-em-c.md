Questão 1

O que é uma estrutura em C?

A) Um tipo de dado que permite armazenar múltiplos valores de diferentes tipos.

B) Uma função que calcula a média de valores.

C) Uma variável global.

D) Um operador de incremento.

Resposta Correta: A - As estruturas permitem agrupar múltiplos valores de diferentes tipos sob um único nome.

Questão 2

Qual é a sintaxe correta para definir uma estrutura em C?

A) struct nome { ... }

B) structure nome { ... }

C) class nome { ... }

D) typedef nome { ... }

Resposta Correta: A) struct nome { ... }
