Questão 1

Como você declara um array de inteiros com 10 elementos em C?

A) int array[10];

B) int array[];

C) array int[10];

D) array[10] int;

Resposta correta: A) int array[10];

Comentários sobre a resposta correta: Em C, um array é declarado especificando o tipo de elemento seguido pelo nome do array e o número de elementos entre colchetes.

Questão 2

Qual estrutura de controle permite executar um bloco de código pelo menos uma vez antes de verificar a condição em C?

A) while

B) for

C) if

D) do-while

Resposta correta: D) do-while

Comentários sobre a resposta correta: A estrutura do-while executa o bloco de código uma vez antes de verificar a condição no final, garantindo que o bloco seja executado pelo menos uma vez, independentemente da condição.
