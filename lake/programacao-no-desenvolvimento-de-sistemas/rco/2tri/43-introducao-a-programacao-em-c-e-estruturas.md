### Slide 10

- DESENVOLVIMENTO DE SISTEMAS
- Primeiros Passos em C
- A linguagem de programação C é conhecida por sua eficiência e controle próximo ao hardware, essencial para sistemas operacionais e aplicações de performance crítica. Iniciamos com uma compreensão das estruturas básicas de C, como funções, variáveis e tipos de dados, que são os blocos construtivos de qualquer programa em C. O conhecimento desses elementos permite aos iniciantes começar a escrever programas simples e entender como os computadores executam o código.

### Slide 11

- DESENVOLVIMENTO DE SISTEMAS
- Lidando com Erros Eficazmente
- Programar em C envolve lidar com diversos tipos de erros, desde sintaxe até erros de execução. Aprender a interpretar mensagens de erro do compilador e usar técnicas de depuração é crucial. Exploramos como usar o debugger e verificar o código para encontrar e corrigir bugs. Este conhecimento é vital para escrever programas confiáveis e entender as mensagens de erro pode economizar horas de frustração.

### Slide 12

- DESENVOLVIMENTO DE SISTEMAS
- Dominando o Compilador C
- O compilador é uma ferramenta essencial que traduz o código C escrito por humanos em código de máquina que os computadores podem executar. Discutimos como configurar e usar o compilador C, incluindo as flags de compilação mais comuns que controlam o processo de compilação. Entender essas opções ajuda os programadores a otimizar o desempenho do programa e a personalizar o processo de compilação às suas necessidades.

- A programação em C suporta várias estruturas de controle, como loops (for, while) e condicionais (if, else). Questão 1

Qual diretiva de pré-processador em C é utilizada para incluir bibliotecas padrão ou do usuário no programa?

A) #include

B) #library

C) #module

D) #package

Resposta correta: A) #include

Comentários sobre a resposta correta: A diretiva #include é usada em C para incorporar o conteúdo de um arquivo de biblioteca no programa, permitindo o acesso a funções e macros definidas nesse arquivo.

Questão 2

Qual palavra-chave é usada em C para iniciar a definição de uma função?

A) function

B) def

C) Func

D) Nenhuma das anteriores

Resposta correta: D) Nenhuma das anteriores

Comentários sobre a resposta correta: Em C, a definição de uma função começa com o tipo de retorno da função, seguido pelo nome da função e parênteses, sem uma palavra-chave específica como em outras linguagens.
