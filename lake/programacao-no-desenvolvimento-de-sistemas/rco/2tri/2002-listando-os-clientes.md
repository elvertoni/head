- Definição e Aplicação
- A manutenção de dados refere-se ao processo de garantir que os dados no sistema estejam corretos, completos e prontos para uso. No contexto de um formulário, isso significa garantir que os dados inseridos sejam válidos e que o formulário esteja preparado para novos dados após cada operação.

Questão 1

Qual dos métodos abaixo é responsável por limpar os campos de um formulário após o salvamento dos dados do cliente?

A) ValidarDadosCliente

B) LimparFormulario

C) SalvarDadosCliente

D) AtualizarFormulario

Resposta Correta: B

Comentário: O método LimparFormulario é utilizado para garantir que todos os campos do formulário estejam vazios e prontos para um novo cadastro após o salvamento dos dados do cliente.

Questão 2

O que deve ser verificado no método SalvarDadosCliente antes de armazenar as informações?

A) Se o formulário está preenchido corretamente

B) Se o formulário foi salvo anteriormente

C) Se o campo de telefone está vazio

D) Se o campo de endereço contém números

Resposta Correta: A

Comentário: Antes de salvar as informações, o método SalvarDadosCliente verifica se todos os dados inseridos no formulário são válidos, garantindo que apenas dados corretos sejam armazenados.
