Questão 1

Qual das seguintes funções é usada para ler dados de um arquivo em C?

A) fwrite

B) fprintf

C) fscanf

D) fputc

Resposta Correta: C) fscanf

Comentário: A função fscanf é usada para ler dados formatados de um arquivo, assim como scanf lê da entrada padrão.

Questão 2

O que acontece se tentar abrir um arquivo inexistente para leitura?

A) O programa cria um novo arquivo.

B) O programa continua sem erro.

C) O programa exibe um erro e encerra.

D) O programa zera o conteúdo do arquivo.

Resposta Correta: C) O programa exibe um erro e encerra.

Comentário: Quando um arquivo é aberto para leitura ("r") e ele não existe, a função fopen retorna NULL, indicando um erro.
