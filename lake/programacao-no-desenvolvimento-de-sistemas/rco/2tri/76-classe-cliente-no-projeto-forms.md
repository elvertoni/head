Questão 1

Qual é a função principal de uma classe Cliente em um sistema de cadastro?

A) Armazenar e manipular os dados do cliente

B) Somente validar os dados do cliente

C) Apenas exibir os dados do cliente

D) Nenhuma das alternativas Resposta

correta: A) Armazenar e manipular os dados do cliente

Questão 2

Por que as políticas de testes são importantes em um projeto?

A) Para garantir que o código funcione corretamente e evitar erros futuros

B) Para criar mais trabalho para o desenvolvedor

C) Para permitir que os clientes insiram dados errados

D) Para economizar tempo na fase de desenvolvimento

Resposta correta: A) Para garantir que o código funcione corretamente e evitar erros futuros
