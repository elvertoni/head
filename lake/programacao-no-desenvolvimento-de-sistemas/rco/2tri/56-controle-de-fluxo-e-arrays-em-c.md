Qual das opções a seguir representa corretamente a declaração de um array de 10 inteiros em C?

A) int array[10];

B) int array(10);

C) array int[10];

D) int[10] array;

Qual das seguintes opções descreve corretamente o funcionamento de um loop for?

A) Executa um bloco de código enquanto uma condição for verdadeira.

B) Executa um bloco de código um número específico de vezes.

C) Executa um bloco de código pelo menos uma vez, independentemente da condição.

Resposta Correta: B) Executa um bloco de código um número específico de vezes. Explicação: O loop for é usado para repetir um bloco de código um número específico de vezes.

Resumo Explicativo:

Controle de fluxo e arrays são componentes essenciais na programação em C. Controle de fluxo permite que o programa tome decisões e repita tarefas com base em condições especificadas, enquanto arrays permitem o armazenamento e manipulação de grandes conjuntos de dados de forma eficiente.

Estudo de Caso:

Imagine que você está desenvolvendo um sistema de gerenciamento de notas para uma escola. O sistema deve ser capaz de armazenar as notas dos alunos em diferentes disciplinas, calcular a média dessas notas e determinar se os alunos foram aprovados ou reprovados. Para isso, você precisará usar estruturas de controle de fluxo como if, else e loops (for, while), bem como arrays para armazenar as notas.

#include <stdio.h>

int main() {

int notas[5];

int i, soma = 0;

float media;

// Entrada de dados

for (i = 0; i < 5; i++) {

printf("Digite a nota %d: ", i + 1);

scanf("%d", &notas[i]);

}

// Processamento

for (i = 0; i < 5; i++) {

soma += notas[i];

}

media = soma / 5.0;

// Saída de dados

printf("Média das notas: %.2f\n", media);

if (media >= 60) {

printf("Aluno aprovado.\n");

} else {

printf("Aluno reprovado.\n");

}

return 0;

}

Questões:

1- Liste três estruturas de controle de fluxo em C.

Resposta Esperada: if, else, for, while, do-while.

2- Explique com suas próprias palavras como um array é usado para armazenar múltiplas notas de alunos.

Resposta Esperada: Um array permite armazenar múltiplas notas de alunos em uma única estrutura de dados, onde cada nota pode ser acessada usando um índice.

3- Modifique o código de exemplo para calcular e exibir a maior e a menor nota digitada.

int maior = notas[0], menor = notas[0];

for (i = 1; i < 5; i++) {

if (notas[i] > maior) maior = notas[i];

if (notas[i] < menor) menor = notas[i];

}

printf("Maior nota: %d\n", maior);

printf("Menor nota: %d\n", menor);

4- Identifique e explique as partes do código que calculam a média das notas.

Resposta Esperada: A média é calculada somando todas as notas usando um loop for e depois dividindo a soma pelo número total de notas (media = soma / 5.0;).

5- Avalie a eficácia do código para um grande número de notas. O que pode ser melhorado?

Resposta Esperada: O código é eficaz para um pequeno número de notas, mas para um grande número de notas, seria melhor usar alocação dinâmica de memória para arrays e modularizar o código em funções.

6- Desenvolva uma função que receba um array de notas e retorne a média, permitindo reutilização do código.

float calcularMedia(int notas[], int tamanho) {

int soma = 0;

for (int i = 0; i < tamanho; i++) {

soma += notas[i];

}

return soma / (float)tamanho;

}

int main() {

int notas[5];

for (int i = 0; i < 5; i++) {

printf("Digite a nota %d: ", i + 1);

scanf("%d", &notas[i]);

}

float media = calcularMedia(notas, 5);

printf("Média das notas: %.2f\n", media);

return 0;

}
