### Slide 10

- DESENVOLVIMENTO DE SISTEMAS
- Definição e Aplicação
- Eventos de mouse são ações capturadas pelo sistema quando o usuário interage com o mouse, como cliques, movimentos e rolagens. Eles são aplicados em várias situações para melhorar a interatividade de um sistema.

Questão 1

Qual evento do mouse seria mais adequado para capturar quando o usuário clica e segura um botão?

A) MouseEnter

B) MouseClick

C) MouseDown

D) MouseDoubleClick

Resposta: C) MouseDown - Captura o evento de quando o botão do mouse é pressionado.

Questão 2

Para alterar o cursor ao passar sobre um componente, qual propriedade é usada?

A) MouseIcon

B) CursorType

C) MousePointer

D) Cursor

Resposta: D) Cursor - A propriedade Cursor permite definir o cursor do mouse sobre o componente.
