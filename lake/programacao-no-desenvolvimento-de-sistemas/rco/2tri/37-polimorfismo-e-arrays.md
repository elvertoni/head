Tema do Estudo de Caso: Polimorfismo em Python

Resumo Explicativo:

Polimorfismo é um princípio fundamental da programação orientada a objetos (OOP), que permite que diferentes classes utilizem métodos com o mesmo nome, mas comportamentos distintos. Em Python, isso é alcançado através de herança e sobrecarga de métodos, permitindo que objetos de diferentes tipos sejam tratados de forma uniforme. Polimorfismo facilita a extensão do código, a manutenção e a reutilização, proporcionando maior flexibilidade e modularidade no desenvolvimento de sistemas.

Estudo de Caso:

Vamos considerar um sistema de gerenciamento de transportes que lida com diferentes tipos de veículos: Carro, Bicicleta e Caminhão. Cada tipo de veículo tem um método `calcular_custo` que calcula o custo de uma viagem baseado em critérios específicos para cada veículo. Usando polimorfismo, podemos definir uma interface comum para todos os veículos, permitindo que o sistema chame `calcular_custo` em qualquer veículo, sem se preocupar com o tipo específico de veículo.

Exemplo de código:

class Veiculo:

def calcular_custo(self, distancia):

raise NotImplementedError("Este método deve ser sobrescrito pelas subclasses")

class Carro(Veiculo):

def calcular_custo(self, distancia):

return distancia * 0.5 # Exemplo: custo de R$0,50 por km

class Bicicleta(Veiculo):

def calcular_custo(self, distancia):

return distancia * 0.1 # Exemplo: custo de R$0,10 por km

class Caminhao(Veiculo):

def calcular_custo(self, distancia):

return distancia * 1.0 # Exemplo: custo de R$1,00 por km

# Uso do polimorfismo

veiculos = [Carro(), Bicicleta(), Caminhao()]

distancia = 100 # Exemplo de distância

for veiculo in veiculos:

custo = veiculo.calcular_custo(distancia)

print(f"Custo de viagem com {veiculo.__class__.__name__}: R${custo}")

*Resposta esperada:* Polimorfismo é a capacidade de diferentes classes utilizarem métodos com o mesmo nome mas comportamentos distintos. Benefícios incluem flexibilidade, reutilização de código, e manutenção facilitada.

2-Explique, com suas próprias palavras, como o polimorfismo é implementado em Python, utilizando herança e sobrecarga de métodos.

*Resposta esperada:* Polimorfismo em Python é implementado através de herança, onde uma classe base define métodos que são sobrescritos por subclasses. Isso permite que diferentes classes respondam a chamadas de método de maneira específica.

def calcular_custo_total(veiculos, distancia):

custo_total = 0

for veiculo in veiculos:

custo_total += veiculo.calcular_custo(distancia)

return custo_total

veiculos = [Carro(), Bicicleta(), Caminhao()]

distancia = 200

print(f"Custo total da viagem: R${calcular_custo_total(veiculos, distancia)}")

4- Identifique as partes componentes do código de exemplo e explique como elas se relacionam para implementar o polimorfismo.
