Questão 1

O que é Windows Forms?

A) Uma linguagem de programação.

B) Uma ferramenta para criar aplicações web.

C) Uma ferramenta para criar interfaces gráficas em aplicações desktop.

D) Uma biblioteca para manipulação de arquivos.

Resposta Correta: C. Windows Forms é uma ferramenta para criar interfaces gráficas em aplicações desktop.

Questão 2

Qual componente do Windows Forms é usado para adicionar botões?

A) TextBox

B) Label

C) Button

D) ListBox

Resposta Correta: C. O componente Button é usado para adicionar botões.
