Resumo Explicativo:

Funções e modularização são conceitos fundamentais em programação que ajudam a organizar o código, tornando-o mais legível, reutilizável e fácil de manter. Em C, uma função é um bloco de código que realiza uma tarefa específica e pode ser chamado sempre que necessário. Modularização envolve dividir um programa em módulos ou arquivos menores, cada um com responsabilidades específicas, o que facilita o desenvolvimento colaborativo e a manutenção do software.

Estudo de Caso:

Imagine que você trabalha em uma empresa de software que desenvolve sistemas educacionais. Seu próximo projeto é criar um sistema de avaliação de notas para alunos. O sistema deve calcular a média, a mediana e a moda das notas dos alunos, além de determinar a nota final com base na média. Para tornar o código mais organizado e fácil de manter, você decide dividir o programa em várias funções e organizá-las em arquivos separados.

Você recebeu a tarefa de implementar a funcionalidade de cálculo de notas em um sistema educacional. O sistema deve:

Receba três notas de um aluno.

Calcular a média dessas notas.

Determinar a mediana e a moda das notas.

Determinar a nota final com base na média.

Exibir os resultados para o usuário.

Para facilitar a implementação e manutenção, você decide usar funções para cada uma dessas operações e modularizar o código em diferentes arquivos.

#include <stdio.h>

#include "funcoes.h"

int main() {

float notas[3];

float media, mediana, moda;

char nota_final;

// Entrada de dados

printf("Digite as três notas do aluno: ");

for (int i = 0; i < 3; i++) {

scanf("%f", &notas[i]);

}

// Cálculo da média

media = calcular_media(notas, 3);

// Cálculo da mediana

mediana = calcular_mediana(notas[0], notas[1], notas[2]);

// Cálculo da moda

moda = calcular_moda(notas[0], notas[1], notas[2]);

// Determinação da nota final

nota_final = determinar_nota_final(media);

// Saída de dados

printf("Média: %.2f\n", media);

printf("Mediana: %.2f\n", mediana);

if (moda != -1) {

printf("Moda: %.2f\n", moda);

} else {

printf("Não há moda.\n");

}

printf("Nota final: %c\n", nota_final);

return 0;

}

#include <stdio.h>

#include "funcoes.h"

// Função para calcular a média de um array de notas

float calcular_media(float notas[], int num_notas) {

float soma = 0;

for (int i = 0; i < num_notas; i++) {

soma += notas[i];

}

return soma / num_notas;

}

// Função para determinar a nota final com base na média

char determinar_nota_final(float media) {

if (media >= 90) {

return 'A';

} else if (media >= 80) {

return 'B';

} else if (media >= 70) {

return 'C';

} else if (media >= 60) {

return 'D';

} else {

return 'F';

}

}

// Função para calcular a mediana de três notas

float calcular_mediana(float nota1, float nota2, float nota3) {

float notas[3] = {nota1, nota2, nota3};

// Ordenando as notas

for (int i = 0; i < 2; i++) {

for (int j = i + 1; j < 3; j++) {

if (notas[i] > notas[j]) {

float temp = notas[i];

notas[i] = notas[j];

notas[j] = temp;

}

}

}

return notas[1]; // A mediana é a nota do meio após ordenação

}

// Função para calcular a moda de três notas

float calcular_moda(float nota1, float nota2, float nota3) {

if (nota1 == nota2 && nota2 == nota3) {

return nota1; // Todas as três notas são iguais

} else if (nota1 == nota2 || nota1 == nota3) {

return nota1; // nota1 é a moda

} else if (nota2 == nota3) {

return nota2; // nota2 é a moda

} else {

return -1; // Não há moda

}

}

#ifndef FUNCOES_H

#define FUNCOES_H

float calcular_media(float notas[], int num_notas);

char determinar_nota_final(float media);

float calcular_mediana(float nota1, float nota2, float nota3);

float calcular_moda(float nota1, float nota2, float nota3);

#endif

Questões:

1- Liste os benefícios de usar funções e modularização em um programa C.

Benefícios incluem melhor organização do código, facilidade de manutenção, reutilização de código, maior legibilidade, e suporte a desenvolvimento colaborativo.

2-Explique com suas próprias palavras como a modularização ajuda na manutenção de um programa C.

Resposta Esperada: A modularização ajuda a manter o código organizado dividindo-o em módulos ou arquivos menores, cada um responsável por uma parte específica da funcionalidade. Isso facilita a identificação de problemas, a atualização de componentes individuais sem afetar o resto do sistema, e promove a reutilização de código em diferentes partes do projeto.

3- Escreva uma função em C que calcule a média de três notas. Utilize essa função em um programa principal que recebe as notas do usuário.

// função para calcular a média

float calcular_media(float nota1, float nota2, float nota3) {

return (nota1 + nota2 + nota3) / 3;

}

int main() {

float nota1, nota2, nota3, media;

printf("Digite as três notas do aluno: ");

scanf("%f %f %f", &nota1, &nota2, &nota3);

media = calcular_media(nota1, nota2, nota3);

printf("Média: %.2f\n", media);

return 0;

}

4- Analise o código a seguir e identifique como as funções estão sendo usadas para modularizar as operações de cálculo de notas.

Resposta Esperada:

A função calcular_media é responsável pelo cálculo da média das notas.

A função determinar_nota_final determina a nota final com base na média calculada.

A função calcular_mediana ordena as notas e retorna a mediana.

A função calcular_moda calcula a moda das três notas.

Essas funções são chamadas no main para realizar operações específicas e modularizar o programa.

5- Avalie as vantagens e desvantagens de dividir um programa C em múltiplos arquivos em comparação com manter todo o código em um único arquivo.

Resposta Esperada:

Vantagens: Melhor organização, facilidade de manutenção, possibilita trabalho colaborativo, facilita testes individuais de módulos.

Desvantagens: Pode aumentar a complexidade inicial do projeto, exigindo mais configuração (por exemplo, incluir arquivos de cabeçalho), possível sobrecarga na gestão dos arquivos.

6- Desenvolva um programa C modularizado que receba notas de vários alunos, calcule a média, mediana e moda, e determine a nota final para cada aluno. Organize o código em diferentes arquivos para cada operação.

Resposta Esperada:

O aluno deve criar várias funções para cada operação e organizá-las em arquivos diferentes (por exemplo, main.c, funcoes.c, funcoes.h). O main.c deve lidar com a entrada e saída de dados, enquanto funcoes.c deve conter as funções para cálculos, e funcoes.h deve declarar essas funções.
