### Slide 8

- DESENVOLVIMENTO DE SISTEMAS
- Resposta
- Solução Correta: scanf e printf são funções padrão para entrada e saída em C, e if-else permite tomar decisões baseadas nas notas.
- Solução Falsa: gets é inseguro e obsoleto, e a falta de controle de fluxo resulta em um programa que não pode tomar decisões.

Questão 1

Qual é a função padrão em C para receber entrada de dados do usuário?

A) gets

B) printf

C) scanf

D) puts

Resposta Correta: C) scanf

Comentário: scanf é a função padrão para receber entrada de dados em C, utilizada para ler dados de diferentes tipos.

Questão 2

Qual estrutura de controle de fluxo é usada para repetir um bloco de código enquanto uma condição é verdadeira?

A) if-else

B) for

C) while

D) switch

Resposta Correta: C) while

Comentário: A estrutura while repete um bloco de código enquanto a condição especificada for verdadeira, permitindo a repetição de operações.
