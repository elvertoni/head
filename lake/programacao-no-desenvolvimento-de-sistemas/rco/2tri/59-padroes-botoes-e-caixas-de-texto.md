Questão 1

Qual propriedade de um TextBox permite definir seu texto?

(A) Text

(B) Value

(C) Input

(D) Content

Comentário:

Resposta correta: (A). A propriedade Text define ou obtém o texto do TextBox.

Questão 2

Como você pode adicionar um evento de clique a um botão no Visual Studio?

(A) Arrastando o botão para o formulário

(B) Escrevendo código no editor

(C) Usando o editor de propriedades para selecionar o evento Click

(D) Todas as anteriores

Comentário:

Resposta correta: (D). Todas as opções são métodos válidos para adicionar eventos a botões no Visual Studio.
