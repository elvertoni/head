### Slide 11

- Modelos de processos
- Modelos de processos de desenvolvimento de software são abordagens estruturadas para criar programas e aplicativos de computador. Eles ajudam as equipes de desenvolvedores a organizar seu trabalho, melhorar a comunicação e colaboração, e garantir a qualidade do software produzido.
- Existem diferentes modelos de processos, cada um com suas características, vantagens e desvantagens, adequados para diferentes tipos de projetos.

_1 imagem(ns) no slide._

### Slide 12

- Um modelo popular é o modelo cascata, que é uma abordagem linear e sequencial para o desenvolvimento de software. Nele, o projeto é dividido em etapas bem definidas, como análise de requisitos, projeto, implementação, teste e manutenção. Cada etapa deve ser concluída antes de passar para a próxima. Este modelo funciona bem para projetos com requisitos estáveis e bem definidos, mas pode ser inflexível quando se trata de mudanças no decorrer do projeto.
- Modelo cascata

_1 imagem(ns) no slide._

### Slide 13

- Abordagem ágil
- Outra abordagem é o desenvolvimento ágil, que é uma alternativa mais flexível e adaptável ao modelo cascata. No desenvolvimento ágil, as equipes trabalham em pequenas iterações, desenvolvendo e entregando partes do software de forma contínua. Essa abordagem permite que as equipes respondam rapidamente às mudanças nos requisitos e colaborem de maneira mais eficaz. O Scrum é um framework ágil comum que organiza o trabalho em sprints, períodos de tempo curtos durante os quais a equipe se concentra em entregar uma parte funcional do software.

### Slide 15

- Modelo iterativo e incremental
- Há também o modelo iterativo e incremental, que combina aspectos do modelo cascata e do desenvolvimento ágil. Nele, o software é desenvolvido em etapas, com cada iteração abordando uma parte do projeto e entregando uma versão incremental do produto. Esse modelo permite que as equipes avaliem o progresso e ajustem o projeto conforme necessário ao longo do tempo. É especialmente útil para projetos complexos e de longo prazo.

### Slide 19

- Resposta
- A principal diferença entre os modelos cascata e ágil está na forma como o trabalho é organizado e como as equipes lidam com mudanças nos requisitos. O modelo cascata é uma abordagem linear e sequencial, onde as etapas do projeto são concluídas uma após a outra, e mudanças nos requisitos podem ser difíceis de acomodar.
- Já no desenvolvimento ágil, o trabalho é organizado em pequenas iterações, permitindo maior flexibilidade e adaptabilidade às mudanças nos requisitos, além de uma maior colaboração entre os membros da equipe.

Questão 1

Qual dos seguintes modelos de processo de desenvolvimento de software é caracterizado por um conjunto de atividades sequenciais, em que o progresso flui de uma etapa para outra, como em uma cascata?

a) Modelo em espiral

b) Modelo cascata

c) Desenvolvimento ágil

d) Modelo iterativo e incremental

Resposta correta: b) Modelo cascata

Comentário: O modelo cascata é um processo linear e sequencial que envolve várias etapas, como análise de requisitos, projeto, implementação, testes e manutenção. Cada etapa deve ser concluída antes que a próxima comece.

Questão 2

Qual abordagem de desenvolvimento de software enfatiza a colaboração, a adaptabilidade e a entrega contínua de valor para o cliente?

a) Modelo em espiral

b) Modelo cascata

c) Desenvolvimento ágil

d) Modelo V

Resposta correta: c) Desenvolvimento ágil

Comentário: O desenvolvimento ágil é uma abordagem que se concentra na colaboração entre equipes multidisciplinares, adaptabilidade às mudanças e entrega contínua de valor ao cliente. Ele utiliza processos iterativos e incrementais para desenvolver software de maneira mais rápida e flexível.

##### 1. Objetivo da Aula Prática

Ao final desta aula prática, o estudante deverá:

- Aprender os principais modelos de processos de desenvolvimento de software e suas características.
- Desenvolver a habilidade prática de analisar um projeto e escolher o modelo mais adequado.
- Ser capaz de produzir uma justificativa técnica simples para a escolha entre modelo cascata, ágil ou iterativo-incremental.

##### 4. Passo a Passo do Docente (Aula de até 50 minutos)

###### Como conduzir a aula

- Retome rapidamente a aula anterior sobre metodologias de desenvolvimento.
- Apresente o cenário do material: Pedro questionando qual modelo de processo será adotado em um novo projeto.
- Explique os três modelos principais apresentados:
- Modelo cascata
- Desenvolvimento ágil (Scrum)
- Modelo iterativo e incremental
- Destaque vantagens, limitações e contextos de aplicação de cada modelo.
- Apresente a atividade prática.

###### Preparações necessárias

- Preparar um cenário fictício de projeto (ex.: sistema escolar, aplicativo de entregas, sistema hospitalar etc.)
- Garantir que os alunos compreenderam as diferenças entre os modelos
- Disponibilizar quadro ou projetor para síntese

- Reforce a importância da justificativa baseada no contexto do projeto

##### 5. Atividade Prática — Descrição Geral

O estudante deverá analisar um cenário de projeto de software e escolher o modelo de processo mais adequado, justificando sua decisão.

Sugestão de cenário: desenvolvimento de um sistema com requisitos variáveis, prazos curtos ou necessidades estáveis.

A atividade simula uma situação real de planejamento de projeto, em que a escolha da metodologia impacta diretamente o sucesso do software.

A habilidade desenvolvida será a capacidade de tomada de decisão técnica fundamentada.

##### 6. Metodologia Ativa Utilizada

- Aprendizagem baseada em problemas (PBL)
- Ensino por descoberta
- Aprendizagem colaborativa (quando em duplas ou grupos)
Elementos de Lemov aplicados:

- Objetivo claro
- Participação ativa
- Produção visível
- Estruturação do raciocínio

##### 7. Passo a Passo da Atividade Prática (para os alunos)

- Leia o cenário apresentado pelo professor.
- Identifique características do projeto (complexidade, mudanças esperadas, prazo, equipe).
- Compare essas características com os modelos estudados.
- Escolha o modelo mais adequado:
- Cascata
- Ágil (Scrum)
- Iterativo-incremental
- Justifique sua escolha com argumentos claros.
- Registre a resposta de forma organizada.
- Prepare-se para explicar sua decisão à turma.

##### 8. Exemplo ou Demonstração

Exemplo de análise:

Projeto: Sistema com requisitos bem definidos e poucas mudanças previstas.

Modelo escolhido: Cascata

Justificativa: Como os requisitos são estáveis e claros desde o início, o modelo sequencial permite planejamento detalhado e controle das etapas.

##### 9. Resultado Esperado

O estudante deverá apresentar:

- Identificação do modelo escolhido
- Justificativa coerente com o cenário
- Demonstração de compreensão das diferenças entre os modelos
O professor poderá verificar o aprendizado observando:

- Clareza da argumentação
- Adequação da escolha ao contexto
- Uso correto dos conceitos estudados
