### Slide 10

- Conceituando
- A ideia principal é representar tarefas, projetos ou atividades com cartões (físicos ou digitais) em um quadro dividido em colunas que representam diferentes estágios do processo.
- A gestão visual do Kanban é um método de organização de tarefas que permite a um time visualizar o fluxo de trabalho de uma maneira simples e eficiente.

_1 imagem(ns) no slide._

### Slide 11

- Conceituando
- Essa visualização oferece uma visão clara do andamento do trabalho, ajudando a identificar possíveis gargalos e facilitando a compreensão do progresso geral do projeto.
- Cada cartão geralmente contém informações detalhadas sobre a tarefa, como descrição, responsável, data de entrega, entre outras.

- Conceituando

Além disso, a gestão visual facilita a comunicação e a colaboração dentro da equipe, pois promove um entendimento compartilhado do fluxo de trabalho e dos objetivos do projeto.

Questão 1

No sistema Kanban, para que serve o quadro visual?

a) Para documentar o código

b) Para listar todos os clientes

c) Para gerenciar o fluxo de trabalho e tornar o progresso das tarefas visível

d) Para realizar brainstorming de novas ideias

Resposta correta: Alternativa c. O quadro visual no Kanban serve para gerenciar o fluxo de trabalho e tornar o progresso das tarefas visível para toda a equipe.

Questão 2

No sistema Kanban, como os cartões são usados?

a) Para dar feedbacks para a equipe

b) Para representar tarefas individuais, movendo-os ao longo do quadro conforme o status da tarefa muda

c) Para anotar os contatos dos clientes

d) Para registrar o tempo de trabalho

Resposta correta: Alternativa b. Os cartões no sistema Kanban representam tarefas individuais e são movidos ao longo do quadro conforme o status da tarefa muda, dando uma visão visual instantânea do fluxo de trabalho.

#### 1. Objetivo da Aula Prática

Ao final desta aula prática, o estudante deverá:

- Compreender o conceito de gestão visual aplicado ao Kanban.
- Desenvolver a habilidade de organizar informações de forma visual para facilitar o acompanhamento do trabalho.
- Identificar como cartões e quadros Kanban auxiliam na transparência e comunicação das equipes.
- Ser capaz de construir e utilizar um quadro Kanban visual para gerenciar atividades de um projeto.
- Reconhecer como a gestão visual ajuda a identificar gargalos e melhorar o fluxo de trabalho.

#### 2. Ferramentas Recomendadas

###### Post-its ou Cartões de Papel

Para que serve: Representar tarefas e atividades do projeto.

Por que é adequada ao tema: Os cartões são elementos centrais da gestão visual no Kanban.

Como facilita o aprendizado: Permite visualizar facilmente o andamento das atividades.

###### Quadro Branco ou Cartolina

Para que serve: Construção do quadro Kanban.

Por que é adequada ao tema: Facilita a organização visual das tarefas.

Como facilita o aprendizado: Ajuda a compreender o fluxo de trabalho em tempo real.

###### Trello

Para que serve: Criar quadros Kanban digitais.

Por que é adequada ao tema: Permite aplicar os conceitos de gestão visual em ambiente digital.

Como facilita o aprendizado: Aproxima os estudantes das ferramentas utilizadas no mercado.

Link: https://trello.com

###### Canva (Opcional)

Para que serve: Criar representações visuais do fluxo de trabalho.

Por que é adequada ao tema: Facilita a construção de modelos personalizados de quadros.

Como facilita o aprendizado: Desenvolve a organização visual das informações.

#### 3. Checklist Inicial

Antes de iniciar a prática, os estudantes devem possuir:

- Post-its ou cartões de papel
- Canetas ou marcadores
- Cartolina ou quadro branco
- Computador ou celular com internet (opcional)
- Conta no Trello (opcional)
- Acesso ao conteúdo da aula
- Equipes organizadas entre 3 e 5 integrantes

#### 4. Passo a Passo do Docente (Aula de até 50 minutos)

##### Como conduzir a aula

- Retome os conceitos da aula anterior sobre Kanban.
- Explique o conceito de gestão visual.
- Apresente os elementos principais:
- Quadro Kanban
- Colunas
- Cartões
- Fluxo de trabalho
- Transparência
- Gargalos
- Mostre exemplos de quadros físicos e digitais.
- Demonstre como os cartões se movimentam entre as colunas.
- Apresente a atividade prática.
- Organize os grupos.

##### Preparações necessárias

- Separar cartolinas e post-its.
- Preparar um exemplo simples de quadro Kanban.
- Organizar os grupos.
- Disponibilizar acesso ao Trello, se houver internet.

##### Alertas e pontos de atenção

- Os alunos podem focar apenas na estética do quadro.
- Reforce que a função principal é comunicar visualmente o fluxo de trabalho.
- Incentive a utilização de informações claras nos cartões.
- Oriente para que as colunas representem etapas reais do processo.

Planejamento → Construção do Quadro → Organização dos Cartões → Simulação do Fluxo → Análise dos Resultados

#### 5. Atividade Prática — Descrição Geral

Os estudantes deverão criar um quadro Kanban visual para organizar as atividades de desenvolvimento de um sistema fictício.

Cada equipe deverá:

- Definir etapas do fluxo de trabalho.
- Criar cartões para representar tarefas.
- Organizar os cartões nas colunas adequadas.
- Simular a movimentação das tarefas.
- Identificar possíveis gargalos e oportunidades de melhoria.
A atividade simula o uso da gestão visual em equipes de desenvolvimento de software.

#### 6. Metodologia Ativa Utilizada

###### Aprendizagem Baseada em Projetos (PBL)

Os estudantes criam uma solução prática para organizar um projeto.

###### Simulação Profissional

A atividade reproduz práticas utilizadas em equipes ágeis.

###### Aprendizagem Colaborativa

O quadro será construído coletivamente.

###### Elementos de Lemov Aplicados

- Objetivo Claro
- Produção Visível
- Participação Ativa
- Feedback Imediato
- Responsabilidade Compartilhada

#### 7. Passo a Passo da Atividade Prática (para os alunos)

##### Cenário

Sua equipe foi contratada para desenvolver um sistema de gerenciamento de biblioteca escolar.

##### Etapa 1 – Construção do Quadro

- Formem grupos de 3 a 5 integrantes.
- Criem um quadro contendo as colunas:
- A Fazer
- Em Progresso
- Em Revisão
- Concluído

##### Etapa 2 – Criação dos Cartões

- Criem pelo menos 12 tarefas relacionadas ao projeto.
Exemplos:

- Cadastro de livros
- Cadastro de usuários
- Empréstimo de livros
- Devolução de livros
- Relatórios
- Tela inicial
- Escrevam cada tarefa em um cartão contendo:
- Nome da tarefa
- Responsável
- Prazo fictício

##### Etapa 3 – Organização Visual

- Posicionem todas as tarefas inicialmente em "A Fazer".
- Simulem o avanço do projeto movimentando os cartões.

##### Etapa 4 – Análise dos Gargalos

- Observem onde as tarefas ficaram acumuladas.
- Identifiquem possíveis gargalos.
- Registrem sugestões de melhoria.

##### Etapa 5 – Apresentação

- Apresentem o quadro para a turma.
- Expliquem:
- Como organizaram as tarefas.
- Onde surgiram gargalos.
- Como poderiam melhorar o fluxo.

#### 8. Exemplo ou Demonstração

##### Quadro Kanban

| A Fazer | Em Progresso | Em Revisão | Concluído |
| --- | --- | --- | --- |
| Relatórios | Cadastro de livros | Tela inicial | Login |
| Empréstimos | Cadastro de usuários |  |  |

##### Exemplo de Cartão

Tarefa: Cadastro de Livros Responsável: João Prazo: 3 dias

##### Gargalo Identificado

Muitas tarefas acumuladas na coluna "Em Revisão".

###### Solução

Distribuir melhor as atividades de revisão entre os membros da equipe.
