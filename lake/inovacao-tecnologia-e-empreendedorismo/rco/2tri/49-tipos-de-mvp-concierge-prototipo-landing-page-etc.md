### Slide 9

- Resposta!
- Beatriz poderia usar diferentes tipos de MVP. Se quiser testar o interesse dos alunos, pode criar uma landing page explicando a solução e pedindo cadastro dos interessados.
- Se quiser testar o funcionamento do serviço, pode usar um MVP concierge, organizando manualmente os grupos de estudo antes de automatizar tudo. Se quiser testar a experiência visual, pode criar um protótipo no Figma mostrando como o aplicativo funcionaria.

### Slide 13

- MVP Concierge
- Nesse modelo, a equipe entrega o serviço manualmente, como se estivesse “atendendo pessoalmente” o usuário.
- Exemplo:
- Antes de criar um aplicativo que recomenda grupos de estudo, a equipe conversa com os alunos, entende suas necessidades e organiza os grupos manualmente.

_1 imagem(ns) no slide._

### Slide 14

- MVP Protótipo
- É uma versão visual da solução, feita com telas, desenhos ou fluxos de navegação.
- Exemplo:
- Criar no Figma as telas de um aplicativo de estudos, mostrando cadastro, escolha de disciplina e entrada em um grupo.

_1 imagem(ns) no slide._

### Slide 15

- MVP Landing Page
- É uma página simples que apresenta a ideia e convida o usuário a demonstrar interesse.
- Exemplo:
- Uma página com o título “Encontre seu grupo de estudos ideal”, explicação da proposta e um botão para cadastro.

### Slide 16

- MVP Mágico de Oz
- Nesse tipo, o usuário acredita que está usando uma solução automatizada, mas algumas ações são feitas manualmente pela equipe nos bastidores.
- Exemplo:
- O aluno preenche um formulário pedindo sugestão de grupo de estudos. A resposta parece automática, mas a equipe analisa manualmente e envia a recomendação.

Questão 1

No MVP Mágico de Oz, algumas ações são:

A. Realizadas manualmente nos bastidores

B. Feitas apenas depois do produto final

C. Ignoradas pela equipe

D. Criadas sem relação com o usuário

Resposta correta: A

Comentário:

Nesse tipo de MVP, o usuário tem a sensação de usar uma solução automatizada, mas parte do processo ainda é feita manualmente pela equipe.

Questão 2

Qual exemplo representa melhor um teste de fumaça?

A. Desenvolver um aplicativo completo antes de mostrar para alguém

B. Criar uma página de lançamento para medir cadastros de interessados

C. Finalizar o projeto sem testar com usuários

D. Apagar todas as ideias antes da apresentação

Resposta correta: B

Comentário:

O teste de fumaça busca medir interesse antes do produto estar pronto. Uma página de cadastro é uma forma simples de verificar demanda.

#### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante deverá ser capaz de:

- Compreender os diferentes tipos de MVP.
- Identificar qual modelo de MVP é mais adequado para diferentes ideias de projeto.
- Relacionar MVP com validação de ideias e aprendizado rápido.
- Criar uma proposta simples de MVP para testar uma solução.
Habilidade prática desenvolvida: Planejamento e definição de estratégias de validação utilizando diferentes tipos de MVP.

Resultado esperado do aluno: Produção de uma proposta simples de MVP adequada para uma ideia de solução tecnológica.

#### 2. Ferramentas Recomendadas

Canva

Para que serve: Criar apresentações, páginas simuladas e materiais visuais.

Por que é adequado ao tema: Permite representar ideias de MVP de forma rápida e visual.

Como facilita o aprendizado: Ajuda os estudantes a transformar ideias em representações práticas.

Google Forms

Para que serve: Criar formulários para coleta de interesse e validação.

Por que é adequado ao tema: Permite testar interesse do público em uma solução.

Como facilita o aprendizado: Ajuda os estudantes a compreender validação de ideias.

Figma

Para que serve: Criar protótipos visuais de aplicativos e sistemas.

Por que é adequado ao tema: Permite simular experiências digitais sem desenvolver um sistema completo.

Como facilita o aprendizado: Ajuda na visualização prática do funcionamento de um MVP.
