Questão 2

Um exemplo de estratégia para lidar com riscos é:

A. Ignorar os riscos e esperar que não aconteçam.

B. Planejar ações preventivas e alternativas caso o risco ocorra.

C. Aumentar o escopo do projeto.

D. Iniciar todas as tarefas ao mesmo tempo.

Comentário: Estratégias preventivas reduzem impacto e aumentam a segurança do projeto.

#### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante deverá ser capaz de:

- Identificar os recursos necessários para desenvolver um projeto inovador.
- Analisar possíveis riscos que podem afetar o andamento de um projeto.
- Organizar recursos e tarefas de forma estratégica.
- Planejar ações para reduzir impactos de riscos identificados.
Habilidade prática desenvolvida: Planejamento de recursos e análise de riscos em projetos de inovação tecnológica.

Resultado esperado do aluno: Documento contendo a lista de recursos do projeto e a identificação dos principais riscos envolvidos.

#### 2. Ferramentas Recomendadas

###### Google Sheets (gratuito – online)

Para que serve: Criar tabelas organizando recursos necessários e análise de riscos.

Por que é adequada ao tema: Permite visualizar de forma clara os elementos necessários para execução do projeto.

Como facilita o aprendizado: Ajuda os estudantes a compreender que projetos precisam de planejamento estruturado.

###### Trello (gratuito – online)

Para que serve: Organizar tarefas, responsáveis e recursos do projeto.

Por que é adequada ao tema: Simula a organização de projetos usada por equipes de tecnologia.

Como facilita o aprendizado: Permite visualizar o fluxo de trabalho do projeto.

#### 3. Checklist Inicial

Antes de iniciar a prática, o estudante deve ter:

Computador ou notebook Conexão com internet Conta Google Acesso ao Google Sheets Acesso ao Trello (https://trello.com) Documento do projeto criado nas aulas anteriores Ambiente: sala de aula ou laboratório

#### 4. Passo a Passo do Docente (Aula de até 50 minutos)

##### Como conduzir a aula

###### 1. Retomada da aula anterior

Relembre que os alunos já definiram:

- problema do projeto
- público-alvo
- objetivos
- escopo
Explique que agora o próximo passo é planejar os recursos necessários e prever riscos.

###### 2. Contextualização do desafio

Apresente o cenário:

Isabela está desenvolvendo um protótipo para organizar eventos escolares, mas não sabe quais recursos serão necessários nem quais riscos podem afetar o projeto.

###### 3. Explanação orientada

Explique que um projeto precisa considerar:

Recursos

- pessoas
- ferramentas
- materiais
- tempo
Riscos

- atrasos
- problemas técnicos
- falta de recursos
- falhas de comunicação

###### 4. Apresentação da atividade prática

Os alunos irão planejar:

- recursos necessários para o projeto
- possíveis riscos que podem acontecer

###### Preparações necessárias

- Solicitar acesso ao projeto criado anteriormente
- Apresentar um exemplo simples de tabela de planejamento

###### Alertas e pontos de atenção

Evitar respostas superficiais como:

“precisa de computador” “pode dar problema”

Estimular respostas mais detalhadas.

###### Dinâmica sugerida

Revisão → atividade prática → discussão → ajustes.

###### Gerenciamento do tempo

5 min — Revisão do conteúdo anterior 10 min — Explicação de recursos e riscos 20 min — Atividade prática 10 min — Compartilhamento das respostas 5 min — Encerramento

#### 5. Atividade Prática — Descrição Geral

##### O que o estudante deve executar

Criar um planejamento simples contendo:

- recursos necessários para o projeto
- possíveis riscos que podem ocorrer

##### Problema Real Simulado

Projeto para melhorar a organização de eventos escolares por meio de tecnologia.

##### Habilidade Desenvolvida

- Planejamento de projetos
- Identificação de riscos
- Organização de recursos
- Pensamento estratégico

#### 6. Metodologia Ativa Utilizada

- Aprendizagem baseada em projetos (PBL)
- Aprendizagem por resolução de problemas
- Trabalho colaborativo

###### Elementos de Lemov aplicáveis

- Objetivo claro
- Modelagem pelo professor
- Verificação de entendimento
- Feedback imediato

#### 7. Passo a Passo da Atividade Prática (para os alunos)

- Abra o documento do seu projeto criado nas aulas anteriores.
- Crie uma nova seção chamada:
Planejamento de Recursos

- Liste os recursos necessários para o projeto:
- recursos humanos
- recursos tecnológicos
- materiais
- tempo estimado
- Crie outra seção chamada:
Análise de Riscos

- Liste possíveis riscos do projeto.
- Para cada risco, indique:
- probabilidade (baixa, média ou alta)
- impacto no projeto
- Revise sua análise.

#### 8. Exemplo ou Demonstração

##### Exemplo de Planejamento

| Tipo de Recurso | Descrição |
| --- | --- |
| Humano | alunos responsáveis pelo projeto |
| Tecnológico | computador e software de desenvolvimento |
| Material | internet, sala de trabalho |
| Tempo | 3 semanas para desenvolvimento |

##### Exemplo de Análise de Riscos

| Risco | Probabilidade | Impacto |
| --- | --- | --- |
| atraso no cronograma | média | alto |
| problemas técnicos | baixa | médio |
| falta de colaboração | média | alto |
