Questão 1

Qual ferramenta é comumente utilizada para prototipação de interfaces digitais?

(A) Figma

(B) Photoshop

(C) Excel

(D) PowerPoint

Resposta Correta: (A) Figma

Comentário: Figma é amplamente utilizada para criar interfaces digitais interativas, sendo ideal para protótipos rápidos e colaborativos.

Questão 2

Por que é importante testar um protótipo com usuários reais?

(A) Para detectar falhas no código

(B) Para entender as necessidades reais dos usuários

(C) Para evitar alterações no design

(D) Para acelerar o lançamento do produto

Resposta Correta: (B) Para entender as necessidades reais dos usuários

Comentário: Testes com usuários garantem que o produto atenda às expectativas e necessidades reais do público-alvo.
