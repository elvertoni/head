Questão 1

Qual a principal vantagem de realizar testes de usabilidade em um protótipo de interface?

A) Reduz o tempo de desenvolvimento.

B) Garante a melhor experiência para o usuário final.

C) Evita a necessidade de feedback dos usuários.

D) Aumenta os custos do projeto.

Resposta Correta: B

Explicação: Testes de usabilidade garantem que a interface seja intuitiva e fácil de usar, promovendo uma experiência de qualidade para o usuário.

Questão 2

Qual ferramenta é mais adequada para realizar testes de usabilidade com protótipos?

A) Microsoft Word

B) Google Forms

C) Figma

D) Adobe Photoshop

Resposta Correta: C

Explicação: Figma permite a criação e testes de protótipos, sendo ideal para conduzir testes de usabilidade de forma interativa.
