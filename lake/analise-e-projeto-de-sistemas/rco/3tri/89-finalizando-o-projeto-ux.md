Questão 1

Para que serve a etapa de validação das melhorias em um projeto de UX?

A) Para garantir que as melhorias implementadas realmente atendem às necessidades do usuário

B) Para desenvolver novas funcionalidades sem revisão

C) Para finalizar o design sem testes adicionais

D) Para avaliar a eficácia do Design System no marketing

Resposta Correta: A

Explicação: A validação das melhorias assegura que as mudanças atendem às necessidades dos usuários, garantindo uma experiência otimizada e confirmando a eficácia das atualizações.

Questão 2

Por que é importante documentar no Design System as modificações de um projeto?

A) Facilita a comunicação entre equipe e usuários

B) Torna o projeto mais fácil de ser revisado e mantido

C) Aumenta o orçamento do projeto

D) Evita a necessidade de feedback de usuários

Resposta Correta: B

Explicação: Documentar as modificações no Design System facilita futuras manutenções e revisões, além de garantir consistência em todo o projeto, promovendo eficiência no trabalho da equipe.
