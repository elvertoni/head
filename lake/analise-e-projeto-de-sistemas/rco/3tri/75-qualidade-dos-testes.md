### Slide 9

- DESENVOLVIMENTO DE SISTEMAS
- A qualidade nos testes
- A qualidade dos testes é um conjunto de práticas que garantem que os resultados dos testes reflitam de forma precisa o comportamento do software. A qualidade é medida pela eficácia em detectar defeitos e pela clareza na definição de critérios de aceitação.

_4 imagem(ns) no slide._

### Slide 10

- DESENVOLVIMENTO DE SISTEMAS
- Capacidade
- Qualidade é a capacidade de um teste medir exatamente o que se propõe, evitando falsos positivos ou falsos negativos. Para isso, é essencial aplicar os conceitos de Critérios de Aceitação e Definição de Pronto durante todo o ciclo de desenvolvimento.

_4 imagem(ns) no slide._

### Slide 11

- DESENVOLVIMENTO DE SISTEMAS
- Por Que o Tema é Importante?
- Um teste de alta qualidade evita retrabalho, acelera o ciclo de desenvolvimento e aumenta a confiança na entrega final. Sem um controle de qualidade, os testes podem não capturar todos os problemas, o que comprometeria o produto.

Questão 1

O que é uma Definição de Pronto (DoD)?

(A) Uma lista de tarefas que devem ser completadas para um projeto ser concluído.

(B) Um conjunto de critérios que indicam que uma funcionalidade está totalmente implementada e testada.

(C) Um documento de requisitos para novos recursos.

(D) Uma descrição das funções de cada membro da equipe.

Resposta correta: B

Explicação: A Definição de Pronto (DoD) é um conjunto de critérios que define quando uma funcionalidade está completa e pronta para ser liberada.

Questão 2

Qual é a principal diferença entre Critérios de Aceite e Definição de Pronto?

(A) Os Critérios de Aceite focam na validação de funcionalidades específicas, enquanto a Definição de Pronto foca em garantir a qualidade geral antes de entregar um item.

(B) A Definição de Pronto é usada apenas para testes de unidade.

(C) Os Critérios de Aceite são usados para avaliar o desempenho do sistema.

(D) Não há diferença entre os dois conceitos.

Resposta correta: A

Explicação: Os Critérios de Aceite validam cada funcionalidade individualmente, enquanto a Definição de Pronto abrange todo o ciclo de desenvolvimento para garantir a entrega com qualidade.
