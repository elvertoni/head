Questão 1

Por que os modais devem ser compatíveis com leitores de tela?

A) Para aumentar o número de animações.

B) Para garantir acessibilidade a usuários com deficiência visual.

C) Para tornar a interface mais complexa.

D) Para dificultar a leitura de informações.

Resposta correta: B. Explicação: A compatibilidade com leitores de tela assegura inclusão para pessoas com deficiência visual.

Questão 2

O que é essencial ao destacar informações?

A) Usar tipografia legível e cores contrastantes.

B) Evitar hierarquia visual.

C) Ocultar as informações mais importantes.

D) Usar apenas texto simples, sem design.

Resposta correta: A. Explicação: Tipografia legível e cores contrastantes garantem que as informações sejam compreendidas com facilidade.
