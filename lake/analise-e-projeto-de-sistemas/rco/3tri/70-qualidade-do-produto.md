Questão 1

O que são Critérios de Aceite?

(A) Normas ISO que o produto deve seguir.

(B) Requisitos mínimos que o produto precisa atender para ser considerado pronto.

(C) Etapas do desenvolvimento do produto.

(D) Parâmetros de teste automatizado.

Resposta Correta: (B) Critérios de Aceite são os requisitos mínimos que precisam ser atendidos para que o produto seja considerado pronto.

Questão 2

O que significa Definição de Pronto?

(A) Quando o produto passa pela fase de desenvolvimento.

(B) Quando o produto está pronto para o usuário final.

(C) Quando o código está livre de bugs.

(D) Quando os requisitos de qualidade são atendidos e validados.

Resposta Correta: (D) Definição de Pronto envolve garantir que todos os requisitos de qualidade foram atendidos e validados antes da entrega.
