- Ana, líder de um projeto de desenvolvimento de software, precisa assegurar que todas as funcionalidades sejam testadas antes do lançamento. Ela tem que escolher entre duas abordagens: criar um ambiente de testes completo ou apenas testar em dispositivos isolados.

### Slide 7

- DESENVOLVIMENTO DE SISTEMAS
- Pergunta!
- Quem sabe responde!
- Qual solução é a correta?
- Criar um ambiente de testes completo: Reproduzir o ambiente de produção para identificar como o software se comporta em diferentes cenários.
- Testar apenas em dispositivos isolados: Limitar os testes a alguns dispositivos, verificando funcionalidade básica sem reproduzir o ambiente real.

_5 imagem(ns) no slide._

### Slide 8

- DESENVOLVIMENTO DE SISTEMAS
- Resposta
- Criar um ambiente de testes completo é a melhor opção, pois reflete melhor as condições reais e ajuda a identificar problemas complexos.
- Testar em dispositivos isolados é menos eficiente e pode levar a resultados incompletos, uma vez que não considera interações complexas.

Questão 1

O que é um escopo de testes?

(A) Um documento para relatar todos os bugs encontrados.

(B) A definição das funcionalidades e áreas que serão testadas.

(C) Um script para automatizar o processo de testes.

(D) Uma lista de requisitos do cliente.

Resposta correta: (B)

Comentário: O escopo de testes estabelece exatamente o que será testado, ajudando a focar os esforços e garantir cobertura adequada.

Questão 2

Qual o objetivo principal da arquitetura de testes?

(A) Melhorar a aparência visual do software.

(B) Definir os tipos e métodos de teste a serem utilizados.

(C) Criar um banco de dados para os testes.

(D) Substituir o ambiente de produção.

Resposta correta: (B)

Comentário: A arquitetura de testes organiza e estrutura os processos de verificação e validação para garantir um fluxo eficiente e abrangente.
