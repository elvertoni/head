Questão 1

Qual ferramenta ajuda no controle de versões em projetos colaborativos?

A) Visual Studio Code

B) GitHub

C) Jest

D) Node.js

Resposta: B) GitHub

Comentário: GitHub permite controlar versões e colaborar com eficiência.

Questão 2

Por que o modelo piloto-copiloto é útil?

A) Melhora a qualidade da codificação em pares.

B) Reduz o uso de memória do computador.

C) Facilita reuniões de equipe.

D) Aumenta o número de funções no projeto.

Resposta: A) Melhora a qualidade da codificação em pares.

Comentário: O modelo piloto-copiloto promove revisões imediatas e troca de conhecimento.
