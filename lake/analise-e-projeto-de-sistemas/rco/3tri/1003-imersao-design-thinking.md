Questão 1

Qual é o principal objetivo da fase de ideação no Design Thinking?

(A) Criar um produto final

(B) Gerar o maior número de ideias possíveis

(C) Definir o problema de forma clara

(D) Implementar a solução

Resposta correta: (B) Gerar o maior número de ideias possíveis. Explicação: A fase de ideação é voltada para a criação de diversas ideias que possam solucionar o problema identificado.

Questão 2

O que significa prototipar no processo de Design Thinking?

(A) Lançar o produto no mercado

(B) Desenvolver um modelo para testar as ideias

(C) Estudar o mercado

(D) Definir os recursos financeiros necessários

Resposta correta: (B) Desenvolver um modelo para testar as ideias. Explicação: Prototipar envolve a criação de um modelo simples da solução para testá-la com os usuários.
