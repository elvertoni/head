Questão 1

O que é comunicação no contexto do XP?

A. Realizar reuniões diárias com a equipe

B. Escrever relatórios detalhados

C. Compartilhar conhecimento frequentemente

D. Criar interfaces visuais para o cliente

Resposta Correta: C

A comunicação eficaz é essencial para o alinhamento contínuo da equipe.

Questão 2

Como o feedback é aplicado no XP?

A. Realizando testes de desempenho

B. Recebendo e incorporando melhorias constantes

C. Corrigindo bugs no final do projeto

D. Desenvolvendo interfaces gráficas

Resposta Correta: B

Feedback frequente ajuda a ajustar o trabalho conforme as necessidades.
