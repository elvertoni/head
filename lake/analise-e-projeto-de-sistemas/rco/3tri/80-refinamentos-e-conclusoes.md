Questão 1

Qual ferramenta é mais adequada para automatizar testes em aplicações web?

A) Jenkins

B) Selenium

C) Trello

D) Python

Resposta correta: B)

Explicação: O Selenium é a ferramenta mais indicada para automatizar testes em interfaces web.

Questão 2

Qual métrica pode ajudar a determinar a qualidade do código testado?

A) Número de desenvolvedores

B) Cobertura de código

C) Interface gráfica

D) Integração contínua

Resposta correta: B)

Explicação: A cobertura de código indica quanto do código foi efetivamente testado, ajudando a avaliar sua qualidade.
