Questão 1

Qual é o papel das personas em um projeto de UX?

A) Ajudar na construção do layout gráfico

B) Fornecer uma visão dos diferentes tipos de usuários do site

C) Propor soluções de código

D) Definir o conteúdo visual do site

Resposta Correta: B

Comentário: Personas representam usuários-tipo e ajudam a entender como diferentes públicos navegarão e interagirão com o site.

Questão 2

Qual ferramenta é ideal para mapear a estrutura de navegação de um site?

A) Photoshop

B) Lucidchart

C) Google Docs

D) Excel

Resposta Correta: B

Comentário: Lucidchart permite criar mapas visuais, essenciais para desenvolver sitemaps e organizar hierarquias de navegação.
