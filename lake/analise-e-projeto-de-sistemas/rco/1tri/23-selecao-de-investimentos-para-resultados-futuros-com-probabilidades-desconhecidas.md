### Slide 19

- DESENVOLVIMENTO DE SISTEMAS
- Dominância e princípios MaxiMin e MaxiMax
- 8 minutos
- Link para tarefa: https://cursos.alura.com.br/course/viabilidade-projetos-negocios-alternativas-investimento/task/85637
- Os princípios MaxiMin e MaxiMax são estratégias de decisão sob incerteza. MaxiMin é conservador, focando no melhor dos piores cenários, enquanto MaxiMax é otimista, escolhendo a melhor possível das melhores situações, ambos usados para avaliar riscos e retornos.
- Atividade no portal Alura

_7 imagem(ns) no slide._

### Slide 20

- DESENVOLVIMENTO DE SISTEMAS
- Princípio de Hurwicz
- 4 minutos
- Link para tarefa: https://cursos.alura.com.br/course/viabilidade-projetos-negocios-alternativas-investimento/task/85638
- O Princípio de Hurwicz é uma técnica de decisão que combina otimismo e pessimismo. O tomador de decisão define um coeficiente de otimismo entre 0 e 1 para ponderar o melhor e o pior cenário possível, balanceando risco e oportunidade.

### Slide 21

- DESENVOLVIMENTO DE SISTEMAS
- Princípio de Laplace
- 7 minutos
- Link para tarefa: https://cursos.alura.com.br/course/viabilidade-projetos-negocios-alternativas-investimento/task/85639
- O Princípio de Laplace é uma abordagem na tomada de decisões sob incerteza que assume igual probabilidade para todos os cenários possíveis. Calcula-se a média dos resultados de todas as possíveis situações, favorecendo decisões com melhores médias esperadas.

Qual princípio é melhor para um investidor conservador?

A) MaxiMax

Resposta Correta: C) MaxiMin

Questão 2

O Princípio de Laplace é usado quando:

A) O risco é desconhecido

B) As probabilidades são iguais

C) O retorno é máximo

D) O investimento é mínimo

Resposta Correta: B) As probabilidades são iguais
