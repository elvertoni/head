Questão 1

Qual das opções abaixo é um exemplo de ferramenta de colaboração para projetos digitais?

A) Excel

B) Google Docs

C) Photoshop

D) Figma

Resposta Correta: D. Explicação: O Figma é uma ferramenta colaborativa usada para design e prototipagem em projetos digitais.

Questão 2

Qual é o primeiro passo ao iniciar um projeto digital?

A) Criar o design final do produto

B) Definir o escopo e criar um plano de gerenciamento

C) Lançar o produto no mercado

D) Testar o produto com os usuários finais

Resposta Correta: B. Explicação: O primeiro passo é definir o escopo do projeto e criar um plano de gerenciamento para guiar todas as etapas subsequentes.
