- Duas Soluções Possíveis:
- Luísa pode incluir todas as funcionalidades planejadas para o aplicativo desde o início.

### Slide 8

- DESENVOLVIMENTO DE SISTEMAS
- Resposta
- Solução 1 (Falsa): Incluir todas as funcionalidades aumenta o risco de atrasos, custos elevados e desperdício de recursos se o mercado não aceitar o produto.
- Solução 2 (Correta): Lançar um MVP com funcionalidades essenciais permite testar o mercado, obter feedback dos usuários e fazer ajustes antes de investir mais recursos.

_3 imagem(ns) no slide._

### Slide 9

- DESENVOLVIMENTO DE SISTEMAS
- O Que é MVP?
- MVP (Minimum Viable Product) é a versão mais simples e funcional de um produto que pode ser lançada para testar uma ideia no mercado com o mínimo de esforço e custo.

Questão 1

Qual é o principal objetivo de desenvolver um MVP?

A) Incluir todas as funcionalidades possíveis

B) Minimizar riscos e validar a ideia no mercado

C) Aumentar os custos iniciais

D) Ignorar o feedback dos usuários

Resposta correta: B) Minimizar riscos e validar a ideia no mercado

Comentário: O objetivo do MVP é testar a aceitação da ideia com um investimento mínimo, obtendo feedback real dos usuários para ajustar e melhorar o produto.

Questão 2

Qual ferramenta é ideal para criar protótipos de MVPs?

A) Microsoft Word

B) Photoshop

C) Figma

D) Excel

Resposta correta: C) Figma

Comentário: Figma é uma ferramenta excelente para criar protótipos interativos de MVPs, permitindo testar e ajustar a interface antes do lançamento.
