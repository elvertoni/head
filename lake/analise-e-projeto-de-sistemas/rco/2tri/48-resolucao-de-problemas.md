Questão 1

Qual das seguintes ferramentas é mais adequada para comunicação contínua em uma equipe?

A) Miro

B) Trello

C) Slack

D) GitHub

Resposta Correta: C) Slack

Comentário: Slack é uma plataforma de comunicação que facilita a colaboração e a discussão em tempo real, essencial para a coordenação eficaz em projetos.

Questão 2

Por que é importante realizar uma análise qualitativa de riscos?

A) Para garantir que todos os riscos sejam eliminados.

B) Para priorizar riscos com base em sua probabilidade e impacto.

C) Para simplificar o processo de gestão de projetos.

D) Para aumentar o número de reuniões da equipe.

Resposta Correta: B) Para priorizar riscos com base em sua probabilidade e impacto

Comentário: A análise qualitativa ajuda a determinar quais riscos precisam de mais atenção, permitindo uma gestão mais eficiente dos recursos do projeto.
