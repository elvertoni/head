Questão 1

Qual ferramenta é ideal para acompanhamento de projetos ágeis?

A) Microsoft Project

B) Trello

C) Excel

D) SAP

Resposta correta: B - Explicação: Trello é frequentemente usado em projetos ágeis devido à sua interface visual e flexibilidade.

Questão 2

O que é uma reunião de revisão de progresso?

A) Uma reunião para planejar novas fases do projeto

B) Uma reunião para avaliar o desempenho da equipe

C) Uma reunião para discutir o progresso do projeto e ajustar planos

D) Uma reunião para finalizar o projeto

Resposta correta: C - Explicação: Uma reunião de revisão de progresso é usada para avaliar o andamento do projeto e fazer ajustes conforme necessário.
