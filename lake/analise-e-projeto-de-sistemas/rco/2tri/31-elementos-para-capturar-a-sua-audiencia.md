Questão 1

Por que é importante ter um antagonista na história?

A) Para simplificar a narrativa

B) Para criar conflitos e desafios para o protagonista

C) Para aumentar o número de personagens

D) Para evitar finais felizes

Resposta correta: B) Para criar conflitos e desafios para o protagonista

Comentário: O antagonista é crucial para criar tensão e desenvolvimento na história, desafiando o protagonista e mantendo a audiência interessada.

Questão 2

Qual é um exemplo de elemento inesquecível em uma história?

A) Cenários vagos

B) Personagens mal desenvolvidos

C) Conflitos emocionantes

D) Diálogos monótonos

Resposta correta: C) Conflitos emocionantes

Comentário: Conflitos emocionantes são elementos inesquecíveis que mantêm a audiência engajada e investida na história.
