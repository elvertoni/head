Questão 1

Qual é a principal função de um Roadmap?

A. Criar um protótipo interativo.

B. Organizar as funcionalidades em uma ordem lógica de desenvolvimento.

C. Validar o MVP com os usuários.

D. Lançar o produto no mercado.

Resposta: B. O Roadmap organiza as funcionalidades em uma ordem lógica de desenvolvimento, guiando a evolução do produto ao longo do tempo.

Questão 2

Qual é o principal objetivo de um Release Plan?

A. Testar a usabilidade de um produto.

B. Definir as etapas para o lançamento gradual de funcionalidades.

C. Criar protótipos interativos para o produto.

D. Garantir que o produto final seja desenvolvido de uma vez só.

Resposta: B. O principal objetivo de um Release Plan é definir as etapas para o lançamento gradual de funcionalidades, priorizando o que deve ser entregue em cada fase do desenvolvimento.
