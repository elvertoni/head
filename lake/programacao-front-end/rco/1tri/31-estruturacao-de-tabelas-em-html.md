### Slide 8

- Resposta
- João deve usar elementos HTML específicos para tabelas, como <table> para criar a tabela, <tr> para linhas, <th> para células de cabeçalho e <td> para células de dados. Para agrupar linhas relacionadas, ele pode utilizar o elemento <tbody>. Ao aplicar esses elementos corretamente, ele garantirá uma estrutura clara e consistente para a tabela, facilitando a leitura e a interpretação das informações pelos visitantes do site.

### Slide 9

- Conceituando
- A estrutura de tabelas em HTML é utilizada para organizar e apresentar informações tabulares em páginas da web. As tabelas são compostas por uma série de elementos HTML que, em conjunto, formam uma grade de linhas e colunas. Elas são úteis para exibir dados de maneira clara e organizada, permitindo aos usuários visualizar e interpretar facilmente as informações apresentadas.

### Slide 10

- Conceituando
- Os principais elementos para criar tabelas em HTML são <table>, <tr>, <th> e <td>. O elemento <table> define a tabela em si, enquanto <tr> representa uma linha da tabela. O elemento <th> é usado para criar células de cabeçalho, geralmente contendo títulos de colunas, e <td> cria células de dados que contêm as informações propriamente ditas. Além desses elementos básicos, outras tags como <thead>, <tbody> e <tfoot> podem ser usadas para agrupar e categorizar partes da tabela, melhorando a semântica e a acessibilidade.

Questão 1

Qual elemento HTML é usado para criar uma linha de cabeçalho em uma tabela?

a) <tr>

b) <th>

c) <td>

d) <thead>

Comentário: A resposta correta é a alternativa (b). O elemento <th> é usado para criar células de cabeçalho em uma tabela, que geralmente contêm títulos de colunas e ajudam a identificar o conteúdo das células da tabela.

Questão 2

Qual elemento HTML é usado para agrupar várias linhas de tabela relacionadas em um corpo de tabela?

a) <tbody>

b) <tr>

c) <tgroup>

d) <td>

Comentário: A resposta correta é a alternativa (a). O elemento <tbody> é usado para agrupar várias linhas de tabela relacionadas em um corpo de tabela, permitindo estilizar, manipular ou ocultar o grupo de linhas como uma unidade.

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Criar tabelas em HTML utilizando as tags <table>, <tr>, <th> e <td>.
- Organizar dados em linhas e colunas de forma estruturada.
- Utilizar elementos semânticos como <thead>, <tbody> e <tfoot>.
- Aplicar estilos CSS para melhorar a leitura da tabela.
- Estruturar dados de forma clara e acessível.
Produto final esperado:

- Página contendo uma tabela estruturada e estilizada, exibindo informações organizadas (ex: horário de funcionamento).

- Para que serve: criar e estruturar tabelas.
- Por que é adequado: permite organização clara do código.
- Como facilita o aprendizado: facilita visualização de linhas e colunas.

###### Navegador Web

- Para que serve: visualizar a tabela.
- Por que é adequado: simula experiência do usuário.
- Como facilita o aprendizado: permite validar organização visual.

###### Editor Online (HTML5 Editor)

- Link: https://html5-editor.net/
- Para que serve: testes rápidos.
- Como facilita o aprendizado: feedback imediato.
