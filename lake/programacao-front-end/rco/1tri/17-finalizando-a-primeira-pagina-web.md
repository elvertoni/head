### Slide 8

- Conceituando
- O cabeçalho em HTML, representado pela tag <header>, é utilizado para definir a parte inicial de uma página ou de uma seção. Esse elemento costuma reunir informações importantes de identificação e navegação, como logotipo, título do site, menu de navegação e, em alguns casos, dados de contato ou outras informações institucionais.
- Assim, o <header> contribui para organizar a estrutura da página e facilitar a navegação do usuário.

Questão 1

Qual a tag HTML utilizada para finalizar uma página?

a) <end>

b) </body>

c) <fin>

d) </html>

Resposta correta: d) </html>

Comentário: A tag </html> é utilizada para indicar o fim do documento HTML, finalizando a estrutura da página.

Questão 2

Qual a função da tag <footer> em uma página HTML?

a) Definir o cabeçalho da página

b) Inserir um rodapé na página

c) Adicionar uma imagem na página

d) Criar um menu de navegação

Resposta correta: b) Inserir um rodapé na página

Comentário: A tag <footer> é utilizada para definir o rodapé de uma página HTML, geralmente contendo informações de copyright, links úteis e outras informações relevantes para o usuário.

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Criar corretamente um cabeçalho utilizando a tag <header>.
- Organizar a estrutura final do documento HTML.
- Revisar e ajustar possíveis erros no código.
- Aplicar boas práticas de organização e acabamento.
- Preparar a página para entrega final.
Produto final esperado:

- Página HTML completa, organizada, com cabeçalho estruturado e revisada.

##### 2. Ferramentas Recomendadas

###### Editor HTML (VS Code ou Online)

- Para que serve: revisar, organizar e finalizar o código.
- Por que é adequado: permite editar HTML e CSS separadamente.
- Como facilita o aprendizado: possibilita visualizar ajustes estruturais.
Link online sugerido: https://html5-editor.net/

###### Navegador Web

- Para que serve: testar e validar a página.
- Por que é adequado: simula ambiente real de acesso.
- Como facilita o aprendizado: permite verificar layout final.

###### Plataforma Alura

- Para que serve: reforçar prática por meio de exercícios.
- Por que é adequada: alinhada ao conteúdo da aula.
- Como facilita o aprendizado: consolida entendimento estrutural.

##### 3. Checklist Inicial

Antes de iniciar a prática, o estudante deve ter:

- Projeto completo das aulas anteriores
- HTML estruturado com listas e imagens
- CSS externo aplicado
- Navegador atualizado
- Conexão com internet
Material de apoio: https://cursos.alura.com.br/course/html5-css3-primeiros-passos

##### 4. Passo a Passo do Docente (Aula de até 50 minutos)

###### Preparações necessárias

- Solicitar que todos abram o projeto final.
- Preparar exemplo de cabeçalho bem estruturado.
- Revisar rapidamente a estrutura básica do HTML:
- <!DOCTYPE>
- <html>
- <head>
- <body>

###### Condução da aula

###### Contextualização (5 minutos)

Perguntar:

- Vocês revisam seus trabalhos antes de entregar?
- O que significa “acabamento” em um projeto?
Relacionar com desenvolvimento web:

- Revisão
- Organização
- Testes

###### Demonstração do professor (15 minutos)

Apresentar:

- Tag <header>
- Função do cabeçalho na página
- Importância para:
- Organização
- Navegação
- SEO
Demonstrar:

- Criar <header> dentro do <body>.
- Inserir nome do site.
- Aplicar estilo no CSS externo.
- Evitar estilização diretamente por tags.
Reforçar:

- Não usar CSS inline.
- Manter organização do código.

###### Prática guiada (20 minutos)

Alunos devem:

- Criar cabeçalho na página.
- Inserir nome do site.
- Aplicar destaque visual.
- Revisar:
- Estrutura
- Fechamento de tags
- Organização CSS

###### Revisão e fechamento (10 minutos)

- Testar página no navegador.
- Conferir:
- Estrutura correta
- Funcionamento visual
- Organização final

###### Pontos de atenção

- Verificar fechamento correto das tags.
- Garantir que CSS esteja no arquivo externo.
- Evitar estilos diretamente nas tags HTML.

##### 5. Atividade Prática — Descrição Geral

O estudante deverá:

- Criar o cabeçalho da página usando <header>.
- Inserir o nome da empresa/projeto.
- Aplicar estilo de destaque.
- Revisar toda a estrutura da página.
- Garantir organização final do projeto.
Problema real simulado: Entrega final de um site institucional simples.

Habilidade desenvolvida: Organização, revisão e acabamento de projeto front-end.

##### 6. Metodologia Ativa Utilizada

- Aprendizagem baseada em prática
- Revisão colaborativa
- Ensino por descoberta
- Elementos de Lemov:
- Modelagem
- Prática guiada
- Checagem de compreensão
- Feedback imediato

##### 7. Passo a Passo da Atividade Prática (para os alunos)

- Abra seu projeto final.
- Localize o início do <body>.
- Crie a tag <header>.
- Dentro dela, insira o nome da página.
- No CSS externo, crie uma classe para o cabeçalho.
- Aplique:
- Cor de fundo
- Cor do texto
- Alinhamento
- Revise toda a página.
- Teste no navegador.
- Corrija possíveis erros.
- Prepare para entrega.

##### 8. Exemplo ou Demonstração

Estrutura esperada:

- DOCTYPE declarado
- HTML organizado
- HEAD com link para CSS
- BODY estruturado
- HEADER destacado
- Conteúdo dividido
- Lista organizada
- Imagem dimensionada
Conceito reforçado:

- Finalização envolve revisão, organização e testes.
- Separação clara entre estrutura (HTML) e estilo (CSS).

- Funcionamento visual final.
