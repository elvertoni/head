Questão 1

Como é possível estilizar uma imagem em HTML?

a) Usando a propriedade "color" no elemento <img>

b) Usando a propriedade "background-color" no elemento <img>

c) Usando a propriedade "style" no elemento <img>

d) Não é possível estilizar uma imagem em HTML.

Resposta correta: c) Usando a propriedade "style" no elemento <img>. É possível adicionar estilos à imagem usando o atributo "style" no elemento <img> e especificando as propriedades desejadas, por exemplo: <img src="imagem.jpg" style="width: 100px; height: 100px;">

Questão 2

Qual é a forma correta de adicionar uma borda à uma imagem em HTML?

a) Usando a propriedade "borders" no elemento <img>

b) Usando a propriedade "border-color" no elemento <img>

c) Usando a propriedade "border" no elemento <img>

d) Não é possível adicionar borda à uma imagem em HTML.

Resposta correta: c) Usando a propriedade "border" no elemento <img>. É possível adicionar uma borda à uma imagem usando a propriedade "border" no elemento <img> e especificando o tamanho, o tipo de linha e a cor, por exemplo: <img src="imagem.jpg" style="border: 2px solid black;">

ATIVIDADE PRÁTICA AULA 14

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Inserir imagens corretamente utilizando a tag <img> no HTML.
- Utilizar os atributos src e alt de forma adequada.
- Aplicar estilos CSS em imagens, controlando tamanho e organização.
- Criar um identificador (id) para estilizar elementos específicos.
- Organizar o CSS em arquivo externo, removendo estilos inline.
Produto final esperado:

- Página HTML contendo imagem corretamente inserida e estilizada via CSS externo.

##### 2. Ferramentas Recomendadas

###### Editor HTML Online ou VS Code

- Para que serve: criar e editar arquivos HTML e CSS.
- Por que é adequado: permite trabalhar com estrutura e estilo de forma separada.
- Como facilita o aprendizado: visualização prática da organização do código.
Link sugerido (caso online): https://html5-editor.net/

###### Navegador Web (Chrome, Edge ou Firefox)

- Para que serve: visualizar o resultado final.
- Por que é adequado: ambiente real de execução.
- Como facilita o aprendizado: permite validar exibição da imagem.

###### Plataforma Alura

- Para que serve: reforçar o conteúdo com atividades guiadas.
- Por que é adequada: alinhada ao conteúdo HTML e CSS.
- Como facilita o aprendizado: complementa com exercícios progressivos.

##### 3. Checklist Inicial

Antes de iniciar a prática, o estudante deve ter:

- Página HTML criada anteriormente
- Arquivo CSS externo criado
- Navegador atualizado
- Conexão com internet
- Link de uma imagem ou arquivo de imagem salvo localmente
Link de apoio: https://cursos.alura.com.br/course/html5-css3-primeiros-passos

##### 4. Passo a Passo do Docente (Aula de até 50 minutos)

###### Preparações necessárias

- Disponibilizar imagem para uso em sala.
- Garantir que os alunos possuam arquivo CSS externo.
- Revisar rapidamente a estrutura HTML e CSS da aula anterior.

###### Condução da aula

1. Contextualização inicial (5 min)

- Retomar importância do CSS.
- Fazer analogia com organização de fotos em álbum digital.
2. Demonstração do professor (15 min)

Apresentar:

- Estrutura básica da tag <img>
- Atributos:
- src
- alt
- width
- height
Demonstrar:

- Inserção da imagem.
- Criação de um identificador (id).
- Estilização da imagem via CSS externo.
Explicar também:

- Importância do atributo alt para acessibilidade.
- Boas práticas de organização.
3. Prática guiada (20 min)

- Alunos inserem imagem na própria página.
- Criam um id para a imagem.
- Aplicam estilos como:
- Largura
- Altura
- Margem
- Bordas
4. Discussão e fechamento (10 min)

- Comparar resultados.
- Falar sobre papel do front-end no design visual.

###### Pontos de atenção

- Verificar caminhos corretos no atributo src.
- Reforçar remoção de CSS inline.
- Corrigir erro comum de esquecer alt.

##### 5. Atividade Prática — Descrição Geral

O estudante deverá:

- Inserir uma imagem em sua página HTML.
- Organizar o código removendo estilos inline.
- Aplicar CSS externo para estilizar a imagem.
Problema real simulado: Organizar visualmente imagens em um site profissional.

Habilidade desenvolvida: Manipulação de imagens e organização de CSS externo.

##### 6. Metodologia Ativa Utilizada

- Aprendizagem baseada na prática
- Experimentação
- Ensino por descoberta
- Elementos de Lemov:
- Modelagem
- Prática guiada
- Checagem de compreensão
- Feedback imediato

##### 7. Passo a Passo da Atividade Prática (para os alunos)

- Abra sua página HTML.
- Dentro do <body>, adicione a tag <img>.
- Defina o atributo src com o caminho da imagem.
- Defina o atributo alt com descrição da imagem.
- Crie um identificador (id) para a imagem.
- No arquivo CSS externo, crie uma regra usando esse id.
- Defina:
- Largura
- Margem
- Borda
- Atualize a página e verifique o resultado.
- Ajuste o estilo para melhorar a organização visual.

##### 8. Exemplo ou Demonstração

Estrutura conceitual esperada:

HTML:

- Tag <img>
- Atributos src e alt
- Uso de id
CSS:

- Seletor por id
- Propriedades de tamanho e espaçamento
Explicação: A imagem é parte do conteúdo HTML, enquanto seu visual é controlado pelo CSS externo.

##### 9. Resultado Esperado

O estudante deverá apresentar:

- Página HTML com imagem exibida corretamente.
- Uso correto do atributo alt.
- CSS externo aplicado à imagem.
- Código organizado e funcional.
O professor verifica analisando:

- Funcionamento da imagem.
- Organização do código.
- Separação entre HTML e CSS.

- Prazo sugerido: imediato.
