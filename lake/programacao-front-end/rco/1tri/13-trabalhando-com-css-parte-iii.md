### Slide 13

- As cores no CSS podem ser especificadas de várias maneiras, incluindo:
- Nome: As cores podem ser especificadas pelo nome, como "red", "blue", "green".

Questão 1

Qual é a principal função do CSS?

A) Adicionar efeitos visuais em páginas HTML

B) Armazenar informações de dados

C) Realizar cálculos matemáticos

D) Controlar a navegação do usuário na página

Resposta correta: A) Adicionar efeitos visuais em páginas HTML

O CSS é uma linguagem de folha de estilo que é utilizada para adicionar estilos e efeitos visuais às páginas HTML. É responsável por controlar a apresentação da página, incluindo as cores, fontes, posições e muito mais.

Questão 2

Como o CSS é aplicado às páginas HTML?

A) Adicionando o código CSS diretamente na tag HTML

B) Incluindo o código CSS em um arquivo separado e vinculando-o à página HTML

C) Embutindo o código CSS na tag head da página HTML

D) Incluindo o código CSS no corpo da página HTML

Resposta correta: B) Incluindo o código CSS em um arquivo separado e vinculando-o à página HTML

O CSS é geralmente escrito em um arquivo separado com a extensão .css e vinculado à página HTML usando uma tag link no head da página. Dessa forma, é possível reutilizar o mesmo estilo em várias páginas HTML, sem precisar escrever o mesmo código CSS várias vezes.

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Compreender como as cores são definidas no CSS.
- Aplicar cores utilizando diferentes formatos (nome, RGB e HEX).
- Utilizar propriedades como color e background-color corretamente.
- Criar uma identidade visual simples para uma página HTML.
Produto final esperado:

- Página HTML estilizada com diferentes formatos de cores aplicados corretamente em textos e fundos.

##### 2. Ferramentas Recomendadas

###### Editor HTML Online

- Para que serve: aplicar e testar estilos CSS em tempo real.
- Por que é adequado: facilita experimentação com cores.
- Como facilita o aprendizado: visualização imediata do resultado.
Link sugerido: https://html5-editor.net/

###### Navegador Web (Chrome, Edge ou Firefox)

- Para que serve: validar o resultado final da página.
- Por que é adequado: ambiente real de execução.
- Como facilita o aprendizado: permite comparar diferentes combinações de cores.

###### Plataforma Alura

- Para que serve: reforçar o conteúdo por meio de exercícios.
- Por que é adequada: alinhada ao conteúdo introdutório de HTML e CSS.
- Como facilita o aprendizado: complementa a prática com atividades guiadas.

##### 3. Checklist Inicial

Antes de iniciar a prática, o estudante deve ter:

- Página HTML criada nas aulas anteriores
- Editor HTML online ou ambiente local
- Navegador atualizado
- Conexão com internet
Link de apoio: https://cursos.alura.com.br/course/html5-css3-primeiros-passos

##### 4. Passo a Passo do Docente (Aula de até 50 minutos)

###### Preparações necessárias

- Disponibilizar a página criada anteriormente.
- Preparar exemplos de cores em nome, RGB e HEX.
- Testar combinações de cores previamente.

###### Condução da aula

1. Contextualização inicial (5 min)

- Retomar o conceito de CSS.
- Perguntar: “Por que as cores são importantes em uma página?”
2. Demonstração do professor (15 min)

Apresentar:

- Propriedade color
- Propriedade background-color
Demonstrar os formatos:

- Nome da cor Ex.: red, blue, green
- RGB Ex.: rgb(255, 0, 0)
- HEX Ex.: #FF0000
Mostrar que todas representam cores, mas com formas diferentes de especificação.

3. Prática guiada (20 min)

- Alunos aplicam diferentes formatos.
- Criam combinações de fundo e texto.
- Testam legibilidade.
4. Discussão e fechamento (10 min)

- Comparar combinações.
- Falar sobre contraste e organização visual.

###### Pontos de atenção

- Orientar sobre contraste (evitar fundo escuro com texto escuro).
- Reforçar a importância da legibilidade.

##### 5. Atividade Prática — Descrição Geral

O estudante deverá criar uma pequena identidade visual para sua página, aplicando cores de diferentes formas no CSS.

Problema real simulado: Criar visual atrativo e organizado para um site.

Habilidade desenvolvida: Aplicação de cores no CSS e compreensão dos formatos disponíveis.

##### 6. Metodologia Ativa Utilizada

- Aprendizagem baseada na prática
- Experimentação
- Ensino por descoberta
- Elementos de Lemov:
- Modelagem
- Prática guiada
- Verificação de entendimento
- Feedback imediato

##### 7. Passo a Passo da Atividade Prática (para os alunos)

- Abra sua página HTML.
- No CSS, altere a cor do fundo da página usando nome de cor.
- Altere a cor do título usando formato RGB.
- Altere a cor dos parágrafos usando formato HEX.
- Teste combinações diferentes.
- Ajuste para manter boa legibilidade.
- Salve ou registre o resultado.
- Escreva qual formato você achou mais prático e por quê.

##### 8. Exemplo ou Demonstração

Exemplo conceitual:

- color: blue;
- color: rgb(0, 0, 255);
- color: #0000FF;
Explicação: São três formas diferentes de representar a mesma cor.

##### 9. Resultado Esperado

O estudante deverá apresentar:

- Página com cores aplicadas nos três formatos:
- Nome
- RGB
- HEX
- Boa combinação de contraste.
- Código organizado e funcional.
O professor verifica analisando aplicação correta e coerência visual.

##### 10. Formato de Entrega da Atividade

- Formato: arquivo HTML + CSS ou print do editor.
- Conteúdo: página com aplicação de cores nos três formatos.
- Entrega: ao final da aula.
- Prazo sugerido: imediato.

##### 11. Encerramento e Reflexão

Perguntas orientadoras:

- Qual formato de cor é mais utilizado em projetos profissionais?
- Por que o código HEX é tão comum?
- Como as cores impactam a experiência do usuário?
