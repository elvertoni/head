Questão 1

Qual é a finalidade da utilização de listas em HTML?

A) Para formatar o texto de maneira organizada

B) Para mostrar informações em tabelas

C) Para apresentar informações em uma lista ordenada ou não ordenada

D) Para apresentar informações em formato gráfico

Resposta correta: C) Para apresentar informações em uma lista ordenada ou não ordenada. Listas em HTML são utilizadas para organizar informações em uma lista de forma clara e concisa, tanto para listas ordenadas (com números ou letras) quanto para listas não ordenadas (com marcadores como bolas ou asteriscos).

Questão 2

Qual é o elemento HTML usado para criar uma lista não ordenada?

A) <li>

B) <ol>

C) <ul>

D) <dl>

Resposta correta: C) <ul>. O elemento <ul> é usado para criar uma lista não ordenada em HTML, e cada item da lista é marcado com o elemento <li>. Juntos, eles são usados para apresentar informações em uma lista de forma clara e concisa.

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Utilizar corretamente a tag <div> para dividir conteúdos.
- Organizar duas seções distintas dentro da página.
- Compreender a diferença entre comportamento inline e block.
- Ajustar imagem e lista para que fiquem posicionadas lado a lado.
- Estruturar melhor a arquitetura visual de um site.
Produto final esperado:

- Página HTML organizada em duas divisões de conteúdo, com imagem posicionada ao lado da lista de benefícios.

- Para que serve: estruturar HTML e aplicar CSS.
- Por que é adequado: permite organizar divisões e aplicar estilos.
- Como facilita o aprendizado: visualização prática das mudanças estruturais.
Link online sugerido: https://html5-editor.net/

###### Navegador Web

- Para que serve: visualizar o resultado final.
- Por que é adequado: ambiente real de execução.
- Como facilita o aprendizado: permite observar comportamento block e inline.

###### Plataforma Alura

Antes de iniciar a prática, o estudante deve ter:

- Projeto da aula anterior aberto

##### 4. Passo a Passo do Docente (Aula de até 50 minutos)

###### Preparações necessárias

- Verificar se todos possuem a lista criada na aula anterior.
- Preparar exemplo visual com conteúdo mal organizado e organizado.
- Revisar rapidamente comportamento block e inline.

###### Condução da aula

###### Contextualização (5 minutos)

- Perguntar: Como separar visualmente duas partes de um site?
- Relembrar que organização visual impacta experiência do usuário.

###### Demonstração do professor (15 minutos)

Apresentar:

- Uso da tag <div> para dividir conteúdos.
- Criar duas divisões:
- Texto de apresentação.
- Benefícios com lista.
Explicar:

- Elementos block ocupam toda largura.
- Elementos inline ocupam apenas o necessário.
Demonstrar:

- Ajustar imagem para não ocupar 100%.
- Posicionar imagem ao lado da lista.

###### Prática guiada (20 minutos)

Alunos devem:

- Criar <div> para separar conteúdo.
- Ajustar CSS da imagem.
- Organizar lista e imagem lado a lado.
- Aplicar classe para estilizar o bloco.

###### Revisão e fechamento (10 minutos)

- Comparar resultados.
- Discutir importância da arquitetura de conteúdo.
- Reforçar conceito de organização semântica.

###### Pontos de atenção

- Corrigir erro de não fechar <div>.
- Garantir que imagem não fique desproporcional.
- Verificar organização visual.

- Criar uma nova divisão de conteúdo usando <div>.
- Separar apresentação e benefícios.
- Ajustar a imagem para ficar ao lado da lista.
- Aplicar CSS para organizar visualmente o bloco.
Problema real simulado: Organizar layout de uma página institucional.

Habilidade desenvolvida: Arquitetura de conteúdo e organização visual.
