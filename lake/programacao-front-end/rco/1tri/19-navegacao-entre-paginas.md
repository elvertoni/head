Questão 1

Qual é a tag HTML utilizada para criar links entre páginas?

a) <link>

b) <a>

c) <nav>

d) <url>

Resposta correta: b) <a>

Comentário: A tag <a> é usada para criar links entre páginas HTML. O atributo "href" especifica o URL do arquivo que o link leva o usuário. Por exemplo: <a href="https://www.exemplo.com">Exemplo</a> cria um link para https://www.exemplo.com.

Questão 2

Qual é a forma mais comum de navegação entre páginas HTML?

a) Usando botões na página

b) Digitando a URL na barra de endereço do navegador

c) Clicando em links dentro da página

d) Usando atalhos de teclado

Resposta correta: c) Clicando em links dentro da página

Comentário: A forma mais comum de navegação entre páginas HTML é clicando em links dentro da página, criados com a tag <a> e o atributo "href". O uso de botões na página e atalhos de teclado também são comuns, mas menos frequentes. Digitando a URL na barra de endereço do navegador não é considerado uma forma de navegação entre páginas dentro de um site.

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Criar links internos entre páginas do projeto utilizando a tag <a>.
- Criar links externos para outros sites.
- Organizar uma estrutura de navegação clara e funcional.
- Aplicar CSS para estilizar menu de navegação.
- Garantir que a navegação esteja funcional antes da estilização.
Produto final esperado:

- Projeto com navegação funcional entre pelo menos duas páginas, com menu estilizado via CSS.

##### 2. Ferramentas Recomendadas

###### VS Code ou Editor HTML Online

- Para que serve: editar arquivos HTML e CSS.
- Por que é adequado: permite testar navegação entre arquivos locais.
- Como facilita o aprendizado: visualização prática da arquitetura do projeto.
Link online sugerido: https://html5-editor.net/

###### Navegador Web

- Para que serve: testar funcionamento dos links.
- Por que é adequado: simula experiência real do usuário.
- Como facilita o aprendizado: valida navegação funcional.

###### Plataforma Alura

- Para que serve: reforçar conceitos de navegação.
- Por que é adequada: alinhada ao conteúdo da aula.
- Como facilita o aprendizado: complementa com exercícios práticos.

##### 3. Checklist Inicial

Antes de iniciar a prática, o estudante deve ter:

- Página inicial criada (index.html)
- Página de produtos criada (produtos.html)
- Arquivo CSS externo
- Estrutura básica do projeto organizada
- Navegador atualizado
- Conexão com internet
Material de apoio indicado na aula: https://cursos.alura.com.br/course/html5-css3-posicionamento-listas-navegacao

##### 4. Passo a Passo do Docente (Aula de até 50 minutos)

###### Preparações necessárias

- Solicitar que todos abram o projeto.
- Revisar rapidamente a tag <a>.
- Demonstrar exemplo funcional de navegação.

###### Condução da aula

###### Contextualização (5 minutos)

Perguntar:

- Como navegamos na internet?
- O que acontece se um link estiver quebrado?
Explicar importância da navegação clara e organizada.

###### Demonstração do professor (15 minutos)

Demonstrar:

- Uso da tag <a href="">.
- Link interno:
- index → produtos
- Link externo:
- Site externo (exemplo).
Explicar:

- Funcionamento do atributo href.
- Importância de caminhos corretos.
- Testar HTML antes de estilizar.

###### Estruturando o menu (10 minutos)

Criar:

- Lista de navegação com <ul> e <li>.
- Links dentro da lista.
- Aplicar estrutura no cabeçalho.

###### Estilizando a navegação (10 minutos)

No CSS:

- Deixar texto em letras maiúsculas.
- Aplicar negrito.
- Ajustar espaçamento.
- Remover marcadores da lista (se necessário).

###### Revisão e testes (10 minutos)

- Testar todos os links.
- Verificar se navegação funciona corretamente.
- Corrigir erros de caminho.

###### Pontos de atenção

- Garantir que nomes dos arquivos estejam corretos.
- Verificar se HTML funciona antes do CSS.
- Conferir se link externo abre corretamente.

Habilidade desenvolvida: Estruturação de navegação e organização da experiência do usuário.
