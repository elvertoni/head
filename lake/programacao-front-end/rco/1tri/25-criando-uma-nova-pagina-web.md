### Slide 11

- Conceituando
- As páginas HTML que fazem uso de formulário são aquelas que permitem a interação do usuário com o conteúdo apresentado, através do preenchimento de campos e submissão de informações. Os formulários podem ser utilizados para diversos fins, como coleta de informações pessoais, login de usuários, pesquisas, inscrições em eventos, entre outros.

_1 imagem(ns) no slide._

### Slide 12

- Conceituando
- Os formulários HTML são criados a partir da utilização de tags específicas, como <form>, <input>, <label>, <select>, entre outras. Cada tag tem uma função específica e é utilizada para criar diferentes tipos de campos, como campos de texto, caixas de seleção, botões de opção, botões de envio, entre outros.

_1 imagem(ns) no slide._

### Slide 13

- Conceituando
- Os formulários HTML são importantes para tornar as páginas interativas e permitir a comunicação entre o usuário e o servidor web. Quando um formulário é preenchido e submetido, as informações são enviadas para o servidor, que pode processá-las e retornar uma resposta ao usuário.

_1 imagem(ns) no slide._

### Slide 14

- Conceituando
- Além disso, os formulários HTML também permitem a validação dos dados inseridos pelo usuário, garantindo que as informações sejam corretas e seguras. A validação pode ser feita tanto pelo lado do cliente, utilizando JavaScript, quanto pelo lado do servidor, através de linguagens de programação como PHP ou Python.

Questão 1

Qual é a tag HTML usada para criar um hyperlink?

a) <link>

b) <a>

c) <href>

d) <img>

Resposta correta: b) <a>

Comentário: A tag <a> é usada para criar um hyperlink em uma página HTML. Atributos como "href" são adicionados à tag <a> para especificar a URL de destino do link.

Questão 2

Qual é a tag HTML usada para criar uma imagem em uma página?

a) <img>

b) <picture>

c) <image>

d) <photo>

Resposta correta: a) <img>

Comentário: A tag <img> é usada para inserir uma imagem em uma página HTML. O atributo "src" é usado para especificar a localização do arquivo de imagem.

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Criar uma nova página HTML de contato.
- Utilizar a tag <form> para criar formulários.
- Inserir campos de entrada utilizando <input>, <label> e outros elementos.
- Compreender o papel dos formulários na interação com o usuário.
- Organizar arquivos e páginas dentro do projeto.
Produto final esperado:

- Página de contato funcional contendo formulário básico para coleta de informações.

##### 2. Ferramentas Recomendadas

###### VS Code ou Editor HTML

- Para que serve: criar nova página e estruturar formulário.
- Por que é adequado: permite organização de múltiplos arquivos.
- Como facilita o aprendizado: simula ambiente profissional de desenvolvimento.

###### Navegador Web

- Para que serve: testar funcionamento do formulário.
- Por que é adequado: simula interação do usuário.
- Como facilita o aprendizado: permite validar preenchimento dos campos.

###### Editor Online (HTML5 Editor)

- Link: https://html5-editor.net/
- Para que serve: testes rápidos de código.
- Como facilita o aprendizado: feedback imediato.

- Testar o preenchimento.
Problema real simulado: Criar uma página de contato para comunicação com usuários.

##### 7. Passo a Passo da Atividade Prática (para os alunos)

- Abra a pasta do seu projeto.
- Crie um novo arquivo chamado contato.html.
- Insira a estrutura básica do HTML.
- Copie o cabeçalho das páginas anteriores.
- Dentro do <body>, crie a tag <form>.
- Adicione campos:
- Nome (input type="text")
- E-mail (input type="email")
- Mensagem (textarea)
- Adicione <label> para cada campo.
- Crie botão de envio (button ou input type="submit").
- Salve o arquivo.
- Abra no navegador e teste.
