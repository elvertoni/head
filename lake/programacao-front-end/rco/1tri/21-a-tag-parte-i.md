### Slide 7

- Para pensarmos juntos...
- O posicionamento de elementos em HTML pode ser um desafio para iniciantes, já que existem várias maneiras de posicionar elementos na página. Uma das maneiras mais comuns de posicionar elementos é usar o CSS. O CSS permite posicionar elementos com precisão, mas pode ser um pouco complicado de usar para iniciantes.
- 3 minutos
- Conversem e apresentem suas visões

### Slide 8

- Para pensarmos juntos...
- Outra maneira é usar a tag <table> para criar tabelas e posicionar elementos dentro delas. Essa abordagem é mais fácil de entender, mas pode ser menos flexível do que usar o CSS. Qual é a maneira mais flexível de posicionar elementos em uma página HTML?
- 3 minutos
- Conversem e apresentem suas visões

_4 imagem(ns) no slide._

### Slide 9

- Resposta
- A maneira mais flexível de posicionar elementos em uma página HTML é usando o CSS. O CSS permite posicionar elementos com precisão e flexibilidade, além de oferecer outras funcionalidades, como animações e efeitos visuais. Embora possa ser um pouco mais complicado para iniciantes, aprender a usar o CSS é uma habilidade essencial para criar páginas web modernas e atraentes.

### Slide 10

- Conceituando
- A tag section em HTML é utilizada para agrupar conteúdos relacionados em uma página. Ela é usada para dividir o conteúdo de uma página em seções lógicas e pode ser aninhada em outras tags, como article, main, div e outras.

### Slide 11

- Conceituando
- Ao utilizar a tag section, o conteúdo dentro dela é considerado como uma seção distinta do restante da página, permitindo uma melhor organização e estruturação do conteúdo.

Qual a função da tag <section> em HTML?

a) Representar um trecho de código

d) Nenhuma das alternativas anteriores

Questão 2

Onde é mais comum o uso da tag <section> em uma página HTML?

a) Na criação de links

b) Na definição de tabelas

c) Na organização de conteúdo principal

d) Nenhuma das alternativas anteriores

Resposta correta: c) Na organização de conteúdo principal.

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Compreender a função da tag <section> na organização semântica do HTML.
- Utilizar a tag <main> para estruturar o conteúdo principal da página.
- Criar divisões semânticas organizadas para exibição de produtos.
- Construir listas complexas contendo título, imagem e descrição.
- Aplicar display: inline-block para organizar elementos lado a lado.
Produto final esperado:

- Página organizada semanticamente, contendo uma seção principal com três produtos estruturados corretamente.

###### Plataforma Alura

##### 4. Passo a Passo do Docente (Aula de até 50 minutos)

###### Preparações necessárias

- Garantir que todos tenham o projeto aberto.
- Revisar rapidamente:
- Posicionamento CSS
- Estrutura básica HTML

###### Condução da aula

###### Contextualização (5 minutos)

Perguntar:

- O que vem depois do cabeçalho em um site?
- Como organizar o conteúdo principal?
Introduzir a importância da organização semântica.

###### Conceituação prática (10 minutos)

Explicar:

- <main> → conteúdo principal da página.
- <section> → divisão temática.
- Importância da organização lógica.
Mostrar exemplo no código.

###### Criando divisões semânticas (10 minutos)

Alunos devem:

- Criar <main>.
- Inserir uma <section> para produtos.
- Organizar três divisões internas.

###### Criando listas complexas (10 minutos)

Explicar que cada produto terá:

- Título
- Imagem
- Parágrafo descritivo
Estruturar lista com <ul> e <li>.

###### Aplicando inline-block (10 minutos)

No CSS:

- Aplicar display: inline-block nas divisões.
- Ajustar espaçamento.
- Organizar visualmente os três produtos lado a lado.

###### Revisão final (5 minutos)

- Verificar alinhamento.
- Conferir organização semântica.
- Ajustar possíveis erros.

###### Pontos de atenção

- Não usar <div> quando <section> for mais adequado.
- Conferir fechamento correto das tags.
- Garantir legibilidade visual.

##### 5. Atividade Prática — Descrição Geral

O estudante deverá:

- Criar o conteúdo principal da página utilizando <main>.
- Inserir uma <section> para exibição de produtos.
- Criar três itens estruturados com:
- Título
- Imagem
- Descrição
- Organizar visualmente usando inline-block.
Problema real simulado: Estruturação da área de produtos de um site institucional.

Habilidade desenvolvida: Organização semântica e estruturação visual.

##### 6. Metodologia Ativa Utilizada

- Aprendizagem baseada em projeto
- Ensino por descoberta
- Experimentação prática
- Elementos de Lemov:
- Modelagem
- Prática guiada
- Verificação de entendimento
- Correção imediata

##### 7. Passo a Passo da Atividade Prática (para os alunos)

- Abra seu projeto.
- Localize o final do cabeçalho.
- Crie a tag <main>.
- Dentro dela, crie uma <section> chamada "Produtos".
- Crie uma lista <ul>.
- Dentro da lista, crie três <li>.
- Em cada item, adicione:
- Título <h2>
- Imagem <img>
- Parágrafo <p>
- No CSS, aplique display: inline-block nos itens.
- Ajuste margens e alinhamentos.
- Salve e teste no navegador.

##### 8. Exemplo ou Demonstração

Estrutura esperada:

Main └── Section (Produtos) └── Lista com 3 itens • Corte de Cabelo • Corte de Barba • Corte Completo

Conceitos reforçados:

- HTML organiza conteúdo.
- CSS organiza visual.
- Semântica melhora estrutura do site.

##### 9. Resultado Esperado

O estudante deverá apresentar:

- Uso correto da tag <main>.
- Uso correto da tag <section>.
- Lista complexa estruturada.
- Três produtos organizados visualmente.
- CSS aplicado corretamente.
O professor verifica:

- Estrutura correta.
