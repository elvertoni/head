### Slide 7

- Para pensarmos juntos...
- Joana é a desenvolvedora responsável por criar um site de inscrição para uma conferência online. Ela precisa criar um formulário que colete informações relevantes dos participantes, como nome, e-mail, data de nascimento e se eles gostariam de receber atualizações por e-mail sobre futuros eventos. Qual tipo de campo de entrada HTML Joana deve usar para perguntar aos participantes se eles gostariam de receber atualizações por e-mail sobre futuros eventos?
- Dialogue com o colega e socialize as ideias com a turma no final!

_2 imagem(ns) no slide._

### Slide 8

- Resposta
- Joana deve usar o tipo de campo de entrada "checkbox" para perguntar aos participantes se eles gostariam de receber atualizações por e-mail sobre futuros eventos. Esse tipo de campo permite que os usuários marquem ou desmarquem a opção, indicando sua preferência.

Questão 1

Qual é o tipo de campo de entrada HTML usado para permitir que os usuários escolham um arquivo para enviar?

a) select

b) upload

c) file

d) browse

Resposta correta: c) file

Comentário: O tipo de campo de entrada "file" é usado para permitir que os usuários escolham um arquivo para enviar. Ele geralmente exibe um botão de navegação e uma caixa de texto para mostrar o nome do arquivo selecionado.

Questão 2

Qual é o tipo de campo de entrada HTML usado para criar um botão que pode ser clicado pelos usuários para enviar o formulário?

a) button

b) submit

c) click

d) push

Resposta correta: b) submit

Comentário: O tipo de campo de entrada "submit" é usado para criar um botão que pode ser clicado pelos usuários para enviar o formulário. Quando clicado, ele envia os dados do formulário ao servidor para processamento.

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Utilizar corretamente campos do tipo checkbox, radio e select (dropdown).
- Agrupar inputs do tipo radio para permitir seleção única.
- Criar listas de seleção para escolha de opções.
- Compreender a importância da hierarquia no CSS.
- Aprimorar o formulário com opções mais avançadas e organizadas.
Produto final esperado:

- Formulário completo com múltiplos tipos de seleção (checkbox, radio e select), organizado e funcional.

###### Navegador Web

- Para que serve: testar comportamento dos campos.

- Como facilita o aprendizado: mostra funcionamento real das seleções.

- Como facilita o aprendizado: feedback imediato.
