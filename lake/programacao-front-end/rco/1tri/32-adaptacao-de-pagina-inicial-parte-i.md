### Slide 9

- Resposta
- Para fazer modificações em um projeto HTML, é importante que você tenha um bom entendimento da estrutura do documento. Se você já tiver um código HTML bem estruturado, é possível fazer pequenas modificações sem grandes impactos. No entanto, se você não estiver confiante, é importante fazer backup do seu código original antes de fazer qualquer alteração.

### Slide 10

- Conceituando
- A modificação de projetos em HTML é um processo fundamental na criação de páginas web. O HTML é uma linguagem de marcação que define a estrutura e o conteúdo de uma página da web, permitindo a adição de imagens, texto, links e outros elementos interativos. Quando se trata de modificar um projeto HTML, existem algumas técnicas importantes que devem ser consideradas.

### Slide 11

- Conceituando
- Em primeiro lugar, é fundamental entender a estrutura do documento HTML. Cada elemento do HTML é definido por uma tag, que indica ao navegador como exibir o conteúdo da página. A modificação de projetos em HTML envolve a adição, remoção ou alteração de tags e outros elementos HTML para criar o layout desejado. É importante ter cuidado ao modificar o código HTML, já que uma pequena alteração pode afetar toda a estrutura da página.
- https://slideplayer.com.br/slide/3284708/11/images/5/Exemplo+Form+GET+%3Chtml%3E.jpg

### Slide 12

- Conceituando
- Outro aspecto importante na modificação de projetos em HTML é a utilização de CSS. O CSS é uma linguagem de folha de estilo que permite controlar a aparência de uma página da web. Ao modificar um projeto em HTML, é comum que sejam necessárias alterações no CSS para ajustar o layout e os estilos da página. A utilização de CSS também permite criar páginas responsivas, que se adaptam a diferentes tamanhos de tela.

- Conceituando

Questão 1

Qual a diferença entre os valores "inline" e "block" da propriedade "display" em HTML?

a) "Inline" cria um elemento em bloco e "block" cria um elemento em linha;

b) "Inline" exibe elementos em uma única linha e "block" exibe elementos em várias linhas;

c) "Inline" não suporta margin e padding, enquanto "block" suporta;

d) "Inline" exibe elementos em várias linhas e "block" exibe elementos em uma única linha.

Resposta correta: c) "Inline" não suporta margin e padding, enquanto "block" suporta.

Questão 2

Qual elemento HTML é considerado um elemento "inline-block"?

a) <p>

b) <ul>

c) <span>

d) <div>

Resposta correta: c) <span>

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Modificar um projeto HTML existente com segurança.
- Compreender a importância de manter uma estrutura organizada antes de realizar alterações.
- Ajustar elementos da página inicial (home) para melhorar layout e consistência visual.
- Aplicar melhorias visuais utilizando CSS (fontes, distribuição de conteúdo, sombras).
- Inserir novos elementos como mapa e vídeo na página.
Produto final esperado:

- Página inicial adaptada e melhor organizada, com novos elementos visuais e conteúdo enriquecido.

##### 2. Ferramentas Recomendadas

###### VS Code ou Editor HTML

- Para que serve: modificar e estruturar o projeto existente.
- Por que é adequado: permite controle total do código.
- Como facilita o aprendizado: possibilita visualizar alterações progressivas.

###### Navegador Web

- Para que serve: testar alterações.
- Por que é adequado: simula o uso real da página.
- Como facilita o aprendizado: permite validação imediata.

###### Editor Online (HTML5 Editor)

- Link: https://html5-editor.net/
- Para que serve: testes rápidos.
- Como facilita o aprendizado: feedback instantâneo.

##### 3. Checklist Inicial

Antes de iniciar a prática, o estudante deve ter:

- Projeto base fornecido (home page inicial)
- Estrutura HTML funcional
- CSS vinculado
- Navegador atualizado
- Conexão com internet
Material de apoio indicado na aula: https://cursos.alura.com.br/course/html5-css3-avancando-css

##### 4. Passo a Passo do Docente (Aula de até 50 minutos)

###### Preparações necessárias

- Garantir que todos tenham o projeto inicial aberto.
- Orientar os alunos a fazer uma cópia de segurança do projeto.

###### Condução da aula

###### Contextualização (5 minutos)

Apresentar cenário:

- Página inicial visualmente incompleta.
- Necessidade de melhoria.
Perguntar:

- O que pode ser melhorado na home?

###### Segurança ao modificar projetos (10 minutos)

Explicar:

- Importância de:
- Backup do código
- Alterações progressivas
- Testes constantes
Reforçar:

- Pequenas mudanças podem impactar o layout.

###### Demonstração do professor (15 minutos)

Demonstrar:

- Alterar fonte da página.
- Melhorar distribuição dos elementos.
- Aplicar sombra (box-shadow).
- Inserir mapa (iframe).
- Inserir vídeo (embed).
Explicar impacto visual das mudanças.

###### Prática guiada (15 minutos)

Alunos devem:

- Ajustar layout da home.
- Modificar CSS.
- Inserir novos elementos.
- Testar visual.

###### Revisão e fechamento (5 minutos)

- Testar página.
- Verificar consistência.
- Ajustar detalhes finais.

###### Pontos de atenção

- Sempre salvar antes de testar.
- Evitar mudanças bruscas.
- Testar cada modificação separadamente.

##### 5. Atividade Prática — Descrição Geral

O estudante deverá:

- Adaptar a página inicial do projeto.
- Melhorar layout e organização.
- Inserir novos elementos:
- Mapa
- Vídeo
- Aplicar melhorias visuais no CSS.
Problema real simulado: Atualização de um site existente para melhorar design e funcionalidade.

Habilidade desenvolvida: Manutenção e evolução de projetos web.

##### 6. Metodologia Ativa Utilizada

- Aprendizagem baseada em projeto
- Refatoração prática
- Ensino por descoberta
- Elementos de Lemov:
- Modelagem
- Prática guiada
- Checagem de compreensão
- Feedback imediato

##### 7. Passo a Passo da Atividade Prática (para os alunos)

- Faça uma cópia do projeto original (backup).
- Abra a página inicial (index.html).
- Ajuste a fonte da página no CSS.
- Organize melhor os elementos visuais.
- Aplique sombra em elementos importantes.
- Insira um mapa usando <iframe>.
- Insira um vídeo incorporado.
- Salve o arquivo.
- Teste no navegador.
- Ajuste layout conforme necessário.
- Finalize melhorias.

##### 8. Exemplo ou Demonstração

Antes:

- Layout simples
- Sem elementos interativos
Depois:

- Melhor distribuição
- Elementos visuais aprimorados
- Mapa e vídeo integrados
Conceitos reforçados:

- HTML estrutura
- CSS melhora aparência
- Evolução de projeto é contínua

##### 9. Resultado Esperado

O estudante deverá apresentar:

- Página inicial adaptada.
- Uso de:
- CSS para melhoria visual
- Inserção de iframe (mapa e vídeo)
- Layout mais organizado.
- Código funcional.
O professor verifica:

- Aplicação correta das modificações.
- Funcionamento dos novos elementos.
- Organização do código.

- Formato: Pasta do projeto contendo:
- index.html
- demais páginas
- style.css
- Entrega: ao final da aula.
- Prazo sugerido: imediato.
