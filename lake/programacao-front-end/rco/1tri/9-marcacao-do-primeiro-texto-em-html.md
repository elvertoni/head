Questão 1

Como marcar um título principal em HTML?

A) <head>Título principal</head>

B) <body>Título principal</body>

C) <h1>Título principal</h1>

D) <title>Título principal</title>

Resposta correta: C) <h1>Título principal</h1>

Questão 2

Como marcar um parágrafo em HTML?

A) <p>Parágrafo</p>

B) <body>Parágrafo</body>

C) <h1>Parágrafo</h1>

D) <head>Parágrafo</head>

Resposta correta: A) <p>Parágrafo</p>

ATIVIDADE PRÁTICA AULA 09

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Compreender o papel do HTML como linguagem de marcação de texto na Web.
- Criar a estrutura básica de uma página HTML simples.
- Marcar textos utilizando tags fundamentais, como título, parágrafo e destaque.
- Relacionar a marcação de texto com a organização e apresentação de conteúdos em websites.
Produto final esperado:

- Uma página HTML simples contendo título, parágrafos e trechos de texto destacados corretamente.

##### 2. Ferramentas Recomendadas

###### Editor HTML Online

- Para que serve: criar e visualizar páginas HTML diretamente no navegador.
- Por que é adequada: dispensa instalação e facilita o início para iniciantes.
- Como facilita o aprendizado: permite visualizar imediatamente o resultado da marcação.
Link sugerido: https://html5-editor.net/

###### Navegador Web (Google Chrome, Edge ou Firefox)

- Para que serve: visualizar o resultado da página HTML.
- Por que é adequada: representa o ambiente real de visualização de páginas web.
- Como facilita o aprendizado: conecta a escrita do HTML com o resultado final.

###### Plataforma Alura

- Para que serve: reforçar o conteúdo com atividades guiadas.
- Por que é adequada: curso introdutório alinhado ao tema HTML e CSS.
- Como facilita o aprendizado: complementa a prática com explicações passo a passo.

##### 3. Checklist Inicial

Antes de iniciar a prática, o estudante deve ter:

- Computador ou notebook
- Navegador web atualizado
- Conexão com a internet
- Acesso a um editor HTML online
- Ambiente: laboratório de informática ou sala multimídia
Link de apoio: https://cursos.alura.com.br/course/html5-css3-primeiros-passos

##### 4. Passo a Passo do Docente (Aula de até 50 minutos)

###### Preparações necessárias

- Testar previamente o editor HTML online.
- Ter um exemplo simples de página HTML para demonstração.
- Verificar acesso à plataforma Alura.

###### Condução da aula

1. Contextualização inicial (5 min)

- Retomar o encerramento do conteúdo de HTTP.
- Utilizar a analogia da evolução das vestimentas e da aparência das páginas web.
2. Demonstração do professor (15 min)

- Apresentar um editor HTML online.
- Mostrar a estrutura básica de um documento HTML.
- Demonstrar:
- Definição de um título
- Criação de parágrafos
- Uso da tag <strong> para destaque
3. Prática guiada dos alunos (20 min)

- Alunos criam sua primeira página HTML.
- Inserem textos simples.
- Aplicam marcações básicas.
4. Discussão e fechamento (10 min)

- Alunos compartilham o resultado.
- Professor reforça a função do HTML e a separação entre estrutura e estilo.

###### Pontos de atenção

- Reforçar que HTML não é linguagem de programação, mas de marcação.
- Evitar introduzir CSS de forma técnica neste momento.

##### 5. Atividade Prática — Descrição Geral

O estudante deverá criar uma página HTML simples, focada exclusivamente na marcação correta de textos.

Problema real simulado: Organizar e apresentar informações textuais em uma página web.

Habilidade desenvolvida: Estruturação básica de conteúdo textual para websites.

##### 6. Metodologia Ativa Utilizada

- Aprendizagem pela prática
- Ensino por descoberta
- Experimentação
- Elementos de Lemov aplicados:
- Estabelecer propósito
- Prática guiada
- Checagem de compreensão
- Feedback imediato

##### 7. Passo a Passo da Atividade Prática (para os alunos)

- Acesse o editor HTML online indicado pelo professor.
- Crie um novo documento HTML.
- Defina um título para a página.
- Escreva pelo menos dois parágrafos de texto.
- Utilize a tag <strong> para destacar uma informação importante.
- Visualize o resultado no navegador.
- Ajuste o texto, se necessário.
- Finalize salvando ou mantendo a página aberta para conferência.

##### 8. Exemplo ou Demonstração

Exemplo de estrutura simples (conceitual):

- Título da página
- Parágrafo explicando o conteúdo
- Parágrafo com uma palavra ou frase em destaque
Explicação: O HTML organiza o conteúdo, enquanto o navegador interpreta e exibe o texto.

##### 9. Resultado Esperado

O estudante deverá apresentar:

- Uma página HTML funcional.
- Uso correto de:
- Título
- Parágrafos
- Destaque com <strong>
- Conteúdo organizado e legível.
O professor verifica o objetivo observando a estrutura e a marcação correta.

##### 10. Formato de Entrega da Atividade

- Formato: link do editor online, print da tela ou arquivo HTML (se aplicável).
- Conteúdo: página HTML com texto marcado.
- Entrega: ao final da aula.
- Prazo sugerido: imediato.

##### 11. Encerramento e Reflexão

O professor encerra com perguntas orientadoras:

- Qual é a função do HTML em uma página web?
- Por que a marcação correta do texto é importante?
- Como essa base será usada nas próximas aulas?
