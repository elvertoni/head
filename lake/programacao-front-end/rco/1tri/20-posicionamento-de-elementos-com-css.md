### Slide 8

- Para pensarmos juntos...
- Uma das técnicas mais comuns de posicionamento é o uso de CSS, que permite definir as propriedades de posicionamento dos elementos. Com CSS, é possível definir o posicionamento absoluto de um elemento em relação a um ponto específico na tela, ou ainda definir o posicionamento relativo em relação a outros elementos na página. Qual é a diferença entre o posicionamento absoluto e o relativo de elementos em HTML?
- 3 minutos
- Conversem e apresentem suas visões

_2 imagem(ns) no slide._

### Slide 9

- Resposta
- O posicionamento absoluto define as coordenadas exatas de um elemento em relação à janela do navegador, enquanto o posicionamento relativo define o posicionamento em relação ao elemento pai.

Questão 1

Qual propriedade CSS é utilizada para definir a posição de um elemento em uma página HTML?

a) margin

b) padding

c) position

d) display

Resposta correta: c) position. A propriedade position é utilizada para definir o posicionamento de um elemento em relação à sua posição inicial na página. Ela permite que o elemento seja posicionado de forma absoluta, relativa, fixa ou estática.

Questão 2

Qual valor da propriedade CSS "display" é utilizado para deixar um elemento fora do fluxo normal do documento HTML?

a) block

b) inline

c) none

d) flex

Resposta correta: c) none. Quando o valor "none" é aplicado à propriedade "display", o elemento é completamente removido do fluxo normal do documento HTML, ou seja, ele não ocupa nenhum espaço na página.

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Compreender como o navegador aplica estilos padrão (margens automáticas).
- Utilizar um arquivo reset.css para remover estilos padrão.
- Diferenciar os posicionamentos static, relative e absolute.
- Aplicar corretamente o posicionamento no cabeçalho da página.
- Organizar visualmente os elementos de forma profissional.
Produto final esperado:

- Página com cabeçalho corretamente posicionado e layout ajustado utilizando posicionamento CSS.

##### 2. Ferramentas Recomendadas

###### VS Code ou Editor HTML Local

- Para que serve: editar múltiplos arquivos (HTML, CSS e reset.css).
- Por que é adequado: permite organização profissional do projeto.
- Como facilita o aprendizado: possibilita compreender estrutura real de desenvolvimento.

###### Navegador Web

- Para que serve: testar alterações visuais.
- Por que é adequado: mostra comportamento real do layout.
- Como facilita o aprendizado: permite observar impacto direto do posicionamento.

###### Arquivo reset.css

- Para que serve: remover estilos automáticos do navegador.
- Por que é adequado: padroniza o layout.
- Como facilita o aprendizado: evita margens inesperadas.

##### 3. Checklist Inicial

Antes de iniciar a prática, o estudante deve ter:

- Projeto com múltiplas páginas
- Cabeçalho já criado
- CSS externo funcionando
- Arquivo reset.css baixado
- Navegador atualizado
- Conexão com internet
Material de apoio indicado na aula: https://cursos.alura.com.br/course/html5-css3-posicionamento-listas-navegacao

##### 4. Passo a Passo do Docente (Aula de até 50 minutos)

###### Preparações necessárias

- Garantir que todos possuam o reset.css.
- Revisar rapidamente conceitos:
- static
- relative
- absolute

###### Condução da aula

###### Contextualização (5 minutos)

Perguntar:

- Por que existe margem branca acima do cabeçalho?
- O navegador adiciona estilos automaticamente?

- Remover margens automáticas.

Explicar importância de padronização.

###### Como funciona o posicionamento (10 minutos)

Explicar:

- Static → padrão do navegador.
- Relative → desloca em relação à posição original.
- Absolute → posiciona em relação ao elemento pai.
Demonstrar exemplos simples.

###### Posicionando o cabeçalho (15 minutos)

Alunos devem:

- Ajustar posição do logo.
- Posicionar menu de navegação.
- Aplicar relative e absolute conforme necessário.
- Organizar visual do cabeçalho.

###### Revisão e testes (10 minutos)

- Verificar alinhamento.
- Conferir se layout não quebrou.
- Ajustar detalhes.

###### Pontos de atenção

- Absolute depende de elemento pai com posição definida.
- Evitar usar posicionamento desnecessário.
- Testar após cada alteração.
