- Para pensarmos juntos...
- Agora vamos falar sobre a “maquiagem” do HTML, ou seja, sobre a parte visual das páginas. ### Slide 8

- Conceituando
- CSS (Cascading Style Sheets) é uma linguagem de estilo utilizada para descrever a apresentação de documentos HTML e XML na web. O CSS permite separar a estrutura do conteúdo (HTML) da apresentação visual, permitindo que os designers controlem a aparência da página da web sem afetar seu conteúdo.

_1 imagem(ns) no slide._

### Slide 9

- Com o CSS, é possível definir estilos como cor de fundo, fonte, tamanho, espaçamento, posicionamento e outros aspectos de design para elementos HTML, incluindo cabeçalhos, parágrafos, tabelas, imagens e outros componentes da página.
- Os estilos CSS são aplicados a elementos HTML específicos através de seletores e regras de estilo.

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Compreender o papel do CSS na construção visual de páginas web.
- Aplicar estilos básicos em elementos HTML, como cores, fontes e tamanhos.
- Separar estrutura (HTML) de apresentação (CSS).
- Modificar visualmente uma página simples já criada anteriormente.
Produto final esperado:

- Página HTML estilizada com CSS aplicado corretamente, alterando cores, fontes e aspectos visuais básicos.

##### 2. Ferramentas Recomendadas

###### Editor HTML Online

- Para que serve: editar HTML e aplicar CSS no mesmo ambiente.
- Por que é adequado: permite visualizar alterações visuais em tempo real.
- Como facilita o aprendizado: feedback imediato ao alterar estilos.
Link sugerido: https://html5-editor.net/

###### Navegador Web (Chrome, Edge ou Firefox)

- Para que serve: visualizar a renderização final da página.
- Por que é adequado: representa o ambiente real de execução.
- Como facilita o aprendizado: possibilita observar impacto visual direto.

###### Plataforma Alura

- Para que serve: reforçar o conteúdo por meio de exercícios guiados.
- Por que é adequada: material alinhado ao tema introdutório de CSS.
- Como facilita o aprendizado: complementa com explicações progressivas.

##### 3. Checklist Inicial

Antes de iniciar a prática, o estudante deve ter:

- Página HTML criada na aula anterior
- Computador ou notebook
- Navegador atualizado
- Conexão com internet
- Acesso ao editor HTML online
Link de apoio: https://cursos.alura.com.br/course/html5-css3-primeiros-passos

##### 4. Passo a Passo do Docente (Aula de até 50 minutos)

###### Preparações necessárias

- Ter disponível o projeto da aula anterior.
- Preparar exemplo de HTML sem estilo e com estilo.
- Testar o editor HTML.

###### Condução da aula

1. Contextualização inicial (5 min)

- Retomar que HTML estrutura, mas não define aparência.
- Utilizar analogia: HTML é a estrutura, CSS é a “maquiagem” visual.
2. Demonstração do professor (15 min)

- Mostrar um HTML simples.
- Aplicar CSS diretamente na página.
- Demonstrar alterações como:
- Cor do texto
- Cor de fundo
- Tamanho da fonte
- Alinhamento
Explicar o conceito de:

- Seletores
- Regras
- Propriedades e valores
3. Prática guiada dos alunos (20 min)

- Alunos aplicam estilos em sua própria página.
- Modificam visual dos textos criados na aula anterior.
4. Revisão e fechamento (10 min)

- Comparar antes e depois.
- Destacar separação entre conteúdo e apresentação.

###### Pontos de atenção

- Reforçar a sintaxe básica do CSS.
- Corrigir erros de digitação e fechamento de chaves.

##### 5. Atividade Prática — Descrição Geral

O estudante deverá modificar visualmente uma página HTML já criada, aplicando CSS para melhorar sua apresentação.

Problema real simulado: Transformar uma página simples em uma página visualmente organizada e agradável.

Habilidade desenvolvida: Aplicação inicial de estilos CSS para prototipação visual.

##### 6. Metodologia Ativa Utilizada

- Aprendizagem baseada na prática
- Experimentação
- Ensino por descoberta
- Elementos de Lemov aplicados:
- Estabelecer propósito
- Modelagem pelo professor
- Prática guiada
- Feedback imediato

##### 7. Passo a Passo da Atividade Prática (para os alunos)

- Abra sua página HTML criada anteriormente.
- Dentro do <head>, crie uma tag <style>.
- Escreva uma regra CSS para alterar:
- Cor do fundo da página.
- Crie outra regra para modificar:
- Cor do título.
- Modifique o tamanho da fonte dos parágrafos.
- Centralize o título.
- Visualize o resultado.
- Ajuste as cores e tamanhos até obter um visual organizado.

##### 8. Exemplo ou Demonstração

Exemplo conceitual de regra CSS:

seletor {

propriedade: valor;

}

Exemplo aplicado:

- Alterar cor do texto
- Definir tamanho da fonte
- Mudar cor de fundo
Explicação: CSS aplica estilos aos elementos HTML por meio de seletores.

##### 9. Resultado Esperado

O estudante deverá apresentar:

- Página HTML com estilos aplicados.
- Uso correto de:
- Seletor
- Propriedade
- Valor
- Diferença clara entre estrutura (HTML) e visual (CSS).
O professor verifica analisando se os estilos foram aplicados corretamente.

##### 10. Formato de Entrega da Atividade

- Formato: link do editor online, print da tela ou arquivo HTML.
- Conteúdo: página com CSS aplicado.
- Entrega: ao final da aula.
- Prazo sugerido: imediato.

##### 11. Encerramento e Reflexão

Perguntas para reflexão:

- Qual é a função do CSS?
- O que acontece se removermos o CSS da página?
- Por que separar estrutura e estilo facilita a manutenção?
