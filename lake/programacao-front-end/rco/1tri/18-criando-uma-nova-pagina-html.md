Questão 1

Qual é a extensão de arquivo usada para páginas HTML?

a) .php

b) .html

c) .css

d) .js

Resposta correta: b) .html

Explicação: A extensão de arquivo para páginas HTML é .html ou .htm, indicando que o arquivo contém código HTML.

Questão 2

O que é um elemento raiz em uma página HTML?

a) O primeiro elemento listado no código HTML

b) O elemento mais importante na página

c) O elemento que envolve todos os outros elementos na página

d) O elemento que define o tamanho e a cor de fundo da página

Resposta correta: c) O elemento que envolve todos os outros elementos na página.

Explicação: O elemento raiz é o elemento HTML, que envolve todos os outros elementos em uma página HTML. Ele é o ponto de partida para a estruturação da página e é necessário para a validação do código HTML.

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Criar uma nova página HTML do zero.
- Estruturar corretamente o documento com <!DOCTYPE>, <html>, <head> e <body>.
- Criar um novo cabeçalho com logo e navegação.
- Organizar links entre páginas (navegação interna).
- Estruturar arquitetura básica de múltiplas páginas.
Produto final esperado:

- Nova página HTML criada e conectada à página inicial por meio de links.

##### 2. Ferramentas Recomendadas

###### VS Code ou Editor HTML Online

- Para que serve: criar novo arquivo HTML e estruturar o código.
- Por que é adequado: permite organização de múltiplos arquivos.
- Como facilita o aprendizado: possibilita visualizar arquitetura de projeto.
Link online sugerido: https://html5-editor.net/

###### Navegador Web

- Para que serve: testar navegação entre páginas.
- Por que é adequado: ambiente real de acesso.
- Como facilita o aprendizado: permite validar funcionamento dos links.

###### Plataforma Alura

- Para que serve: complementar prática com exercícios.
- Por que é adequada: alinhada ao conteúdo da aula.
- Como facilita o aprendizado: reforça construção progressiva.

##### 3. Checklist Inicial

Antes de iniciar a prática, o estudante deve ter:

- Projeto inicial da página anterior
- Arquivo HTML principal funcionando
- CSS externo já criado
- Pasta do projeto organizada
- Navegador atualizado
- Conexão com internet
Material de apoio indicado na aula: https://cursos.alura.com.br/course/html5-css3-posicionamento-listas-navegacao

##### 4. Passo a Passo do Docente (Aula de até 50 minutos)

###### Preparações necessárias

- Solicitar que todos abram o projeto anterior.
- Explicar conceito de múltiplas páginas.
- Demonstrar estrutura inicial de novo arquivo HTML.

###### Condução da aula

###### Contextualização (5 minutos)

Perguntar:

- O que já conseguimos criar com HTML e CSS?
- Um site possui apenas uma página?
Explicar que sites reais possuem várias páginas conectadas.

###### Demonstração do professor (15 minutos)

Demonstrar:

- Criar novo arquivo (ex: produtos.html).
- Estrutura básica do documento HTML.
- Criar <header> com:
- Logo
- Lista de navegação
- Criar links entre:
- index.html
- produtos.html
Explicar:

- Como funciona o atributo href.
- Importância da organização de arquivos.

###### Prática guiada (20 minutos)

Alunos devem:

- Criar nova página.
- Inserir estrutura básica.
- Criar cabeçalho com navegação.
- Testar navegação entre páginas.

###### Revisão e fechamento (10 minutos)

- Testar navegação.
- Verificar estrutura correta.
- Reforçar organização de projeto.

###### Pontos de atenção

- Conferir nome correto dos arquivos.
- Verificar caminhos corretos nos links.
- Garantir que CSS esteja vinculado à nova página.

##### 5. Atividade Prática — Descrição Geral

O estudante deverá:

- Criar uma nova página HTML chamada “produtos”.
- Estruturar o documento corretamente.
- Criar cabeçalho com logo e navegação.
- Criar links que permitam transição entre páginas.
Problema real simulado: Construção inicial de um site com múltiplas páginas.

Habilidade desenvolvida: Arquitetura de navegação e organização de projeto.

##### 6. Metodologia Ativa Utilizada

- Aprendizagem baseada em projeto
- Ensino por descoberta
- Trabalho colaborativo
- Elementos de Lemov:
- Modelagem
- Prática guiada
- Verificação de entendimento
- Feedback imediato

##### 7. Passo a Passo da Atividade Prática (para os alunos)

- Abra a pasta do seu projeto.
- Crie um novo arquivo chamado produtos.html.
- Insira a estrutura básica do HTML.
- Copie o cabeçalho da página principal.
- Adapte o título da nova página.
- Crie lista de navegação com <ul> e <li>.
- Adicione links usando <a href="">.
- Salve o arquivo.
- Abra no navegador.
- Teste a navegação entre páginas.

##### 8. Exemplo ou Demonstração

Estrutura esperada:

Página inicial:

- index.html
Nova página:

- produtos.html
Cabeçalho:

- Logo
- Lista de links
- Início
- Produtos
Conceito reforçado:

- HTML define estrutura.
- CSS mantém identidade visual.
- Navegação conecta páginas.
