### Slide 8

- Em HTML, existem duas principais tags para criar listas:
- A tag <ul> é usada para criar uma lista não ordenada, que consiste em itens marcados com símbolos como bullet points.
- <ul> (lista não ordenada) e <ol> (lista ordenada).
- A tag <ol> é usada em HTML para criar uma lista ordenada, na qual os itens aparecem em uma sequência numerada ou organizada (por exemplo: 1, 2, 3 ou a, b, c). Assim como na <ul>, cada item da lista é definido pela tag <li>.

Questão 1

Qual é a tag HTML utilizada para criar uma lista ordenada?

A) <ol>

B) <li>

C) <ul>

D) <dl>

Resposta correta: A) <ol> - A tag <ol> é utilizada para criar uma lista ordenada, enquanto que a tag <li> é utilizada para criar cada item na lista.

Questão 2

Qual é a tag HTML utilizada para criar uma lista não ordenada?

A) <ul>

B) <li>

C) <ol>

D) <dl>

Resposta correta: A) <ul> - A tag <ul> é utilizada para criar uma lista não ordenada, enquanto que a tag <li> é utilizada para criar cada item na lista.

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Criar listas ordenadas e não ordenadas utilizando as tags <ul>, <ol> e <li>.
- Utilizar o atributo type em listas ordenadas.
- Criar uma nova seção na página HTML para organizar conteúdo.
- Aplicar classes no CSS para estilizar listas.
Produto final esperado:

- Página HTML contendo uma nova seção com lista organizada e estilizada via CSS.

##### 2. Ferramentas Recomendadas

###### Editor HTML (VS Code ou Editor Online)

- Para que serve: editar arquivos HTML e CSS.
- Por que é adequado: permite estruturar conteúdo com listas e aplicar estilos.
- Como facilita o aprendizado: visualização imediata da organização do conteúdo.
Link online sugerido: https://html5-editor.net/

###### Navegador Web

- Para que serve: visualizar o resultado da estrutura criada.
- Por que é adequado: ambiente real de execução.
- Como facilita o aprendizado: permite validar formatação da lista.

###### Plataforma Alura

- Para que serve: reforçar conceitos com atividades guiadas.
- Por que é adequada: alinhada ao conteúdo da aula.
- Como facilita o aprendizado: consolida o entendimento por meio da prática.

##### 3. Checklist Inicial

Antes de iniciar a prática, o estudante deve ter:

- Projeto criado nas aulas anteriores
- Arquivo HTML principal
- Arquivo CSS externo
- Navegador atualizado
- Conexão com internet
Material de apoio indicado na aula: https://cursos.alura.com.br/course/html5-css3-primeiros-passos

##### 4. Passo a Passo do Docente (Aula de até 50 minutos)

###### Preparações necessárias

- Garantir que os alunos tenham o projeto aberto.
- Revisar rapidamente estrutura HTML e CSS.
- Preparar exemplo de lista ordenada e não ordenada.

###### Condução da aula

###### Contextualização (5 minutos)

- Perguntar: Como vocês organizam tarefas no dia a dia?
- Relacionar listas do cotidiano com listas no HTML.
- Explicar que organização de conteúdo é parte da arquitetura de um site.

###### Demonstração do professor (15 minutos)

Apresentar:

- Estrutura de lista não ordenada:
- <ul>
- <li>
- Estrutura de lista ordenada:
- <ol>
- <li>
Mostrar uso do atributo:

- type="1"
- type="A"
- type="a"
- type="i"
Explicar:

- Diferença entre lista ordenada e não ordenada.
- Quando utilizar cada uma.
Demonstrar criação de uma nova seção na página para inserir lista.

###### Prática guiada (20 minutos)

Alunos devem:

- Criar nova seção no site.
- Inserir lista de “Benefícios” ou “Serviços”.
- Aplicar classe CSS para estilizar a lista.
- Ajustar espaçamentos e organização visual.

###### Revisão e fechamento (10 minutos)

- Comparar listas criadas.
- Discutir organização visual.
- Reforçar importância da estrutura semântica.

###### Pontos de atenção

- Verificar fechamento correto das tags.
- Corrigir uso incorreto de <li> fora de listas.
- Garantir uso correto de classe no CSS.

##### 5. Atividade Prática — Descrição Geral

O estudante deverá:

- Criar uma nova seção no site.
- Inserir uma lista não ordenada com pelo menos 4 itens.
- Inserir uma lista ordenada com pelo menos 3 itens.
- Aplicar classe CSS para estilizar a lista.
Problema real simulado: Organizar informações de um site profissional, como benefícios ou serviços.

Habilidade desenvolvida: Estruturação de conteúdo e organização semântica.

##### 6. Metodologia Ativa Utilizada

- Aprendizagem baseada na prática
- Ensino por descoberta
- Colaboração em duplas
- Elementos de Lemov:
- Modelagem
- Prática guiada
- Verificação de entendimento
- Correção imediata

##### 7. Passo a Passo da Atividade Prática (para os alunos)

- Abra seu projeto HTML.
- Crie uma nova <section> no corpo da página.
- Adicione um título para a seção.
- Crie uma lista não ordenada (<ul>).
- Insira pelo menos 4 itens usando <li>.
- Crie uma lista ordenada (<ol>) logo abaixo.
- Utilize o atributo type na lista ordenada.
- No arquivo CSS, crie uma classe para estilizar as listas.
- Aplique espaçamento ou alteração visual simples.
- Salve e visualize no navegador.

##### 8. Exemplo ou Demonstração

Estrutura conceitual esperada:

Lista não ordenada:

- Item A
- Item B
- Item C
Lista ordenada:

- Etapa 1
- Etapa 2
- Etapa 3
Com atributo de tipo:

- Letras maiúsculas
- Letras minúsculas
- Números romanos
Aplicação de classe:

- Centralizar
- Alterar cor
- Ajustar espaçamento

##### 9. Resultado Esperado

O estudante deverá apresentar:

- Nova seção criada corretamente.
- Lista não ordenada funcional.
- Lista ordenada com atributo type.
- Classe aplicada no CSS.
- Código organizado e legível.
O professor verifica observando:

- Estrutura correta das tags.
- Aplicação correta de classe.
- Funcionamento visual adequado.

##### 10. Formato de Entrega da Atividade

- Formato: Arquivo HTML + CSS ou print do projeto.
- Conteúdo: Seção com listas organizadas.
- Entrega: ao final da aula.
- Prazo sugerido: imediato.

Perguntas orientadoras:

- Quando usar lista não ordenada?
- Por que organizar o conteúdo melhora a experiência do usuário?
