### Slide 9

- Resposta
- Miguel deve começar criando uma conta no GitHub, caso ainda não tenha uma. Em seguida, ele pode criar um novo repositório clicando em "New repository" no menu suspenso "+" no canto superior direito da página inicial do GitHub. Ele deve dar um nome ao repositório e, opcionalmente, adicionar uma descrição e escolher se o repositório será público ou privado.

### Slide 10

- Resposta
- Depois de criar o repositório, ele pode seguir as instruções fornecidas pelo GitHub para adicionar seu projeto existente ao repositório usando comandos Git, como 'git init', 'git add', 'git commit' e 'git push'. Assim que seu projeto estiver no repositório do GitHub, ele poderá compartilhar o link com outros desenvolvedores e convidá-los a contribuir ou fornecer feedback.

### Slide 11

- Conceituando
- Compartilhamento de código é uma prática importante no desenvolvimento de software, pois permite que desenvolvedores colaborem e aprendam uns com os outros. Projetos HTML, CSS e JavaScript podem ser facilmente compartilhados e colaborados através de sistemas de controle de versão como o Git e plataformas de hospedagem de código como o GitHub ou outros repositórios similares.

_1 imagem(ns) no slide._

### Slide 12

- Conceituando
- O GitHub é uma plataforma popular de hospedagem de código que utiliza o Git para controle de versão. Ele permite que os desenvolvedores criem repositórios para armazenar e gerenciar projetos, além de colaborar com outros desenvolvedores. O GitHub fornece uma interface gráfica fácil de usar para gerenciar repositórios e colaborar em projetos. Um repositório é uma coleção de arquivos e pastas relacionados a um projeto específico, juntamente com um histórico completo de todas as mudanças feitas nesses arquivos.

_1 imagem(ns) no slide._

### Slide 13

- Conceituando
- Para compartilhar projetos HTML usando o GitHub, os desenvolvedores iniciantes devem primeiro criar uma conta na plataforma e instalar o Git em seus computadores. Em seguida, eles podem criar um repositório no GitHub, cloná-lo em suas máquinas locais e adicionar seus arquivos de projeto ao repositório. Depois disso, eles podem fazer 'commit' das mudanças e fazer 'push' para o repositório remoto no GitHub. Isso torna o projeto acessível a outros desenvolvedores, que podem visualizar, fazer 'fork' (copiar) e contribuir para o projeto.

Questão 1

O que é o GitHub?

a) Um editor de texto para desenvolvimento web.

b) Um sistema operacional baseado em nuvem.

c) Uma plataforma de hospedagem de código e colaboração que utiliza o Git.

d) Um serviço de hospedagem de sites.

Questão 2

O que é o GitHub Pages?

a) Uma ferramenta para desenvolver páginas da web com tecnologias web modernas.

b) Um serviço de hospedagem de sites gratuito, oferecido pelo GitHub, para hospedar projetos estáticos diretamente de um repositório GitHub.

c) Um serviço de e-mail fornecido pelo GitHub.

d) Um sistema de gerenciamento de conteúdo (CMS) fornecido pelo GitHub.

Resposta correta: b) Um serviço de hospedagem de sites gratuito, oferecido pelo GitHub, para hospedar projetos estáticos diretamente de um repositório GitHub.

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Criar uma conta no GitHub (caso ainda não possua).
- Criar um repositório para armazenar seu projeto web.
- Publicar os arquivos do projeto HTML no GitHub.
- Compartilhar o link do repositório com outras pessoas.
- Publicar a página utilizando GitHub Pages.
- Compreender a importância do versionamento e compartilhamento de projetos.

###### Produto Final Esperado

Um projeto HTML publicado em um repositório GitHub e disponibilizado online através do GitHub Pages.

##### 2. Ferramentas Recomendadas

###### GitHub

Para que serve: hospedagem e compartilhamento de código.

Por que é adequado: é uma das plataformas mais utilizadas no mercado de tecnologia.

Como facilita o aprendizado: permite armazenar projetos, criar portfólio e colaborar com outros desenvolvedores.

Site: https://github.com

###### Git

Para que serve: controle de versão dos arquivos do projeto.

Por que é adequado: registra alterações realizadas no projeto.

Como facilita o aprendizado: ajuda a compreender o fluxo de trabalho profissional.

Site: https://git-scm.com

###### VS Code

Para que serve: edição dos arquivos do projeto.

Por que é adequado: possui integração com Git e GitHub.

Como facilita o aprendizado: permite gerenciar o projeto em um único ambiente.

Site: https://code.visualstudio.com

###### GitHub Pages

Para que serve: publicação gratuita de páginas HTML.

Por que é adequado: transforma o repositório em um site acessível pela internet.

Como facilita o aprendizado: permite compartilhar projetos reais com colegas e professores.

##### 5. Atividade Prática — Descrição Geral

O estudante deverá publicar o projeto desenvolvido nas aulas anteriores utilizando GitHub e GitHub Pages.

A atividade consiste em:

- Criar um repositório.
- Fazer upload do projeto.
- Organizar os arquivos.
- Ativar GitHub Pages.
- Compartilhar o link gerado.

###### Problema Real Simulado

Entrega de um projeto web para um cliente ou apresentação de portfólio profissional.

###### Habilidade Desenvolvida

Versionamento, hospedagem e compartilhamento de projetos web.

##### 7. Passo a Passo da Atividade Prática (para os alunos)

###### Etapa 1 – Criar o Repositório

- Acesse o GitHub.
- Faça login.
- Clique em New Repository.
- Defina um nome para o projeto.
- Crie o repositório.

###### Etapa 2 – Enviar o Projeto

- Abra o repositório criado.
- Clique em Add File.
- Selecione Upload Files.
- Envie:
- index.html
- style.css
- pasta de imagens
- Salve as alterações.

###### Etapa 3 – Verificar Arquivos

- Confirme que todos os arquivos foram enviados.
- Verifique se o projeto mantém a mesma estrutura utilizada localmente.

###### Etapa 4 – Ativar GitHub Pages

- Abra Settings.
- Acesse Pages.
- Escolha a branch principal.
- Salve as configurações.

###### Etapa 5 – Testar

- Aguarde alguns minutos.
- Abra o link gerado.
- Teste a navegação.
- Verifique imagens, textos e estilos.
