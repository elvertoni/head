### Slide 11

- Conceituando
- A aplicação de gradientes em páginas HTML refere-se ao uso de transições suaves entre duas ou mais cores em elementos da página, como planos de fundo, botões e outros componentes visuais. Os gradientes são uma técnica de design moderna e atraente que podem melhorar a estética e a experiência do usuário de um site.

_1 imagem(ns) no slide._

### Slide 12

- Conceituando
- Em CSS, os gradientes são geralmente aplicados como imagens de fundo usando a propriedade background-image. Existem dois tipos principais de gradientes: lineares e radiais. Os gradientes lineares são criados com a função linear-gradient(), que permite especificar a direção, as cores e a progressão do gradiente em uma linha reta. Os gradientes radiais são criados com a função radial-gradient(), que produz um gradiente que se irradia a partir de um ponto central em direção às bordas do elemento.

_1 imagem(ns) no slide._

- Conceituando
- Ao aplicar gradientes em páginas HTML, os desenvolvedores podem criar designs visualmente interessantes e dinâmicos, melhorando a experiência do usuário e destacando áreas importantes da página. Além disso, como os gradientes podem ser criados diretamente com CSS, isso pode reduzir a necessidade de imagens adicionais, diminuindo o tempo de carregamento da página e otimizando a performance do site.

Questão 1

Como você aplica um gradiente linear como plano de fundo de um elemento em CSS?

a) background-image: linear-gradient(direction, color1, color2);

b) background: linear-gradient(direction, color1, color2);

c) background-color: gradient-linear(direction, color1, color2);

d) background: gradient(direction, color1, color2);

Comentário: A resposta correta é a alternativa "a". Você aplica um gradiente linear como plano de fundo de um elemento em CSS usando a propriedade background-image com a função linear-gradient().

Questão 2

Qual pseudoelemento CSS é usado para inserir conteúdo antes de um elemento?

a) ::before

b) ::after

c) ::first-letter

d) ::first-line

Comentário: A resposta correta é a alternativa "a". O pseudoelemento ::before é usado para inserir conteúdo antes de um elemento.

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Compreender o conceito de gradientes no CSS.
- Aplicar gradientes lineares e radiais em elementos HTML.
- Utilizar gradientes para melhorar o design visual de páginas web.
- Diferenciar o uso de cores sólidas e gradientes.
- Criar interfaces mais modernas e atrativas utilizando CSS.
Produto final esperado:

- Página HTML estilizada com gradientes aplicados em botões, cabeçalhos e áreas de destaque.

##### 2. Ferramentas Recomendadas

###### VS Code ou Editor HTML

- Para que serve: editar HTML e CSS do projeto.
- Por que é adequado: permite visualizar rapidamente alterações visuais.
- Como facilita o aprendizado: possibilita testar diferentes combinações de gradientes.

###### Navegador Web

- Para que serve: visualizar o resultado final da estilização.
- Por que é adequado: mostra a aparência real da página.
- Como facilita o aprendizado: permite comparar efeitos e combinações de cores.

###### Gerador de Gradientes CSS

- Link: https://cssgradient.io/
- Para que serve: criar gradientes visuais rapidamente.
- Como facilita o aprendizado: ajuda o estudante a compreender direção e transição de cores.
