### Slide 12

- Conceituando
- Aprenda o básico de HTML e CSS: Dominar o básico de HTML e CSS é essencial para criar um site funcional e atraente. HTML é a linguagem de marcação usada para estruturar o conteúdo de uma página, enquanto CSS é a linguagem de estilo usada para controlar a aparência dos elementos HTML. Focar em aprender as principais tags e propriedades de cada linguagem ajudará a construir uma base sólida para projetos futuros.

_1 imagem(ns) no slide._

### Slide 13

- Conceituando
- Mantenha o código organizado e limpo: Escrever código HTML e CSS de maneira organizada e consistente facilita a manutenção e atualização do site no futuro. Isso inclui usar indentação adequada, comentários para explicar o propósito de blocos de código e nomes descritivos para classes e IDs. Além disso, separar o CSS do HTML em um arquivo externo (como style.css) é uma boa prática para manter o código mais organizado e fácil de entender.

Questão 1

Qual é a estrutura básica de um documento HTML?

a) <!DOCTYPE html> <html> <head> <title> </head> <body> </body> </html>

b) <html> <header> <title> </header> <body> </body> </html>

c) <html> <head> <title> </head> <content> </content> </html>

d) <!DOCTYPE html> <html> <head> <title> </title> <body> </body> </head> </html>

Comentário: A resposta correta é a alternativa "a". A estrutura básica de um documento HTML inclui a declaração do tipo de documento (<!DOCTYPE html>), seguida pelas tags <html>, <head> e <body>. A tag <head> contém informações sobre o documento, como o título, enquanto a tag <body> contém o conteúdo da página.

Questão 2

Qual das seguintes tags HTML é usada para criar um link para outra página ou recurso?

a) <a>

b) <link>

c) <href>

d) <url>

Comentário: A resposta correta é a alternativa "a". A tag <a> é usada para criar um link para outra página ou recurso na web. O atributo "href" dentro da tag <a> especifica o destino do link.
