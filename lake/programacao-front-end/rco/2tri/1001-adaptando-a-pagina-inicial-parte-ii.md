### Slide 9

- Resposta
- Para posicionar imagens e vídeos corretamente em uma página em HTML, é importante entender o modelo de caixa do CSS. Cada elemento HTML é considerado uma caixa e é possível manipular o tamanho e o posicionamento dessas caixas usando CSS.

_1 imagem(ns) no slide._

### Slide 10

- Conceituando
- Os aspectos em páginas HTML referem-se aos elementos que compõem a aparência e a funcionalidade de uma página da web. Uma página HTML pode conter vários aspectos, como texto, imagens, vídeos, links, formulários e outros elementos interativos. Para criar uma página HTML eficiente e atraente, é importante considerar cada um desses aspectos e utilizá-los de maneira estratégica.

_1 imagem(ns) no slide._

### Slide 11

- Conceituando
- O aspecto mais básico de uma página HTML é o texto. É possível formatar o texto usando as tags HTML para criar títulos, parágrafos, listas e outros elementos de texto. Além disso, é possível aplicar estilos ao texto usando CSS para alterar a fonte, a cor e outras características do texto.

_1 imagem(ns) no slide._

### Slide 12

- Conceituando
- As imagens e vídeos são outro aspecto importante em páginas HTML. As imagens podem ser incluídas usando a tag <img> e podem ser ajustadas para diferentes tamanhos e alinhamentos usando CSS. Os vídeos podem ser incorporados à página usando a tag <video> e também podem ser estilizados usando CSS. Além disso, os links permitem que os usuários naveguem entre diferentes páginas da web e podem ser criados usando a tag <a>.

_1 imagem(ns) no slide._

### Slide 13

- Conceituando
- Os formulários são um aspecto crucial em páginas HTML, pois permitem que os usuários interajam com a página e enviem informações para o servidor. Os formulários podem conter elementos como campos de texto, botões de rádio, caixas de seleção e botões de envio.
- É possível estilizar os formulários usando CSS para criar uma aparência mais atraente e consistente. Em resumo, entender e utilizar cada um desses aspectos em páginas HTML é fundamental para criar uma experiência de usuário eficiente e agradável.

Questão 1

Qual é a melhor maneira de incluir um arquivo de CSS em um documento HTML?

a) Usando a tag <script>

b) Usando a tag <style>

c) Usando a tag <link>

d) Usando a tag <meta>

Resposta correta: c) Usando a tag <link>. A tag <link> é a melhor maneira de incluir um arquivo de CSS em um documento HTML. Ela é usada para definir a relação entre o documento HTML atual e um arquivo externo, como um arquivo de CSS. A tag <script> é usada para incluir scripts em um documento HTML, a tag <style> é usada para incluir estilos diretamente no documento HTML e a tag <meta> é usada para incluir metadados no documento HTML.

Questão 2

Qual é a propriedade CSS usada para definir a cor do texto?

a) font-size

b) color

c) background-color

d) padding

Resposta correta: b) color. A propriedade color é usada para definir a cor do texto em um elemento HTML. A propriedade font-size é usada para definir o tamanho da fonte, a propriedade background-color é usada para definir a cor de fundo do elemento e a propriedade padding é usada para definir o espaçamento interno do elemento.
