### Slide 12

- Conceituando
- O sistema de grid é uma estrutura de layout que divide uma página em colunas e linhas, facilitando a organização do conteúdo e proporcionando uma aparência consistente em diferentes dispositivos e tamanhos de tela. No CSS, o layout de grid pode ser implementado usando a propriedade display: grid; e outras propriedades relacionadas, como grid-template-columns e grid-template-rows. Além disso, existem frameworks CSS populares, como Bootstrap e Foundation, que oferecem sistemas de grid prontos para uso, simplificando ainda mais o processo de criação de layouts responsivos e adaptáveis.

Questão 1

Qual propriedade CSS é usada para criar um contêiner de grid em um projeto HTML?

a) grid-layout

b) display: grid;

c) grid-template

d) grid-rows

Resposta correta: b) display: grid;

Comentário: A propriedade CSS display: grid; é usada para criar um contêiner de grid em um projeto HTML. Essa propriedade permite dividir o layout em colunas e linhas, facilitando a organização e a criação de um design responsivo.

Questão 2

Como você pode importar uma fonte do Google Fonts para usar em seu projeto HTML?

a) Usando a tag <link>

b) Usando a propriedade CSS font-family

c) Copiando a fonte para a pasta do projeto

d) Usando a propriedade CSS font-source

Resposta correta: a) Usando a tag <link>

Comentário: Para importar uma fonte do Google Fonts para usar em seu projeto HTML, você pode usar a tag <link> no cabeçalho do arquivo HTML. O Google Fonts fornece o link apropriado para a fonte escolhida, e depois de adicioná-lo ao seu arquivo HTML, você pode aplicar a fonte usando a propriedade CSS font-family.

##### 1. Objetivo da Aula Prática

Ao final da aula prática, o estudante será capaz de:

- Criar layouts organizados utilizando CSS Grid.
- Aplicar fontes personalizadas em páginas HTML.
- Ajustar tamanho, peso e estilo das fontes utilizando CSS.
- Organizar visualmente os elementos da página de forma responsiva e profissional.
- Melhorar a aparência e a experiência visual do projeto.
Produto final esperado:

- Página HTML organizada com CSS Grid e estilizada utilizando fontes personalizadas.

- Como facilita o aprendizado: ajuda na personalização visual da página.
